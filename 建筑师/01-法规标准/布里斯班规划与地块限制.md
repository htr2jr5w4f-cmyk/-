# 布里斯班规划与地块限制

适用州：QLD（Brisbane City Council 辖区）｜资料核对日期：2026-11-20｜状态：大部分待证实

## 摘要
本文是布里斯班建独立住宅的规划层面框架：Brisbane City Plan 2014 中的 Dwelling house code 和 Dwelling house (small lot) code、什么情况下需要开发许可（development approval）、洪水和其他 overlay 怎么查，以及 City Plan 与 QDC MP1.1/1.2（以及 2026 年新出的 Queensland Housing Code）的关系。
对省钱的用处：买地或设计前先查清 overlay 和规则，可以避免交了设计费才发现要做开发申请（DA）、抬高地板或改设计。
**重要说明**：本次资料核对中 brisbane.qld.gov.au 无法直接打开，且搜索额度在撰写本文前已用完，因此本文**只有少数要点有官方来源**，其余内容是根据一般认知整理的框架，均标「待证实」，必须由后续检索或业主向市政府/certifier 核实后才能作为依据。本文不写任何具体退让、高度、覆盖率数字。

## 1. 已有官方来源的要点
- **Queensland Housing Code（QHC）将取代 QDC MP1.1/MP1.2**：过渡期 2026-09-01 至 2029-09-01；各地方政府可在过渡期内修订 planning scheme 说明 QHC 如何适用，到期未修订则 QHC 自动适用 [S1][S2]。原 MP1.1/1.2 相关条文在某地 planning scheme 中继续有效，直到该 scheme 修订或 2029-09-01（以较早者为准）[S2]。
- **布里斯班市政府曾就 QHC 草案提交正式意见**（2025-07 公开文件）[S3]——说明市政府与州政府在退让等规则上可能有不同立场，具体内容待证实。
- **布里斯班曾推出「More Homes, Sooner – Low-medium density residential design」City Plan 修订**，有公开的修订对照表（Schedule of amendments）[S4]。修订内容、是否已生效、是否影响 Dwelling house code：**待证实**。
- **地方政府可指定 flood hazard area 和 bushfire prone area**（Building Regulation 2021 第 7、8 条），在 flood hazard area 内建房适用 QDC MP3.5 [S5][S6]。
- **布里斯班属 Wind Region B**（非气旋区，但须能抵抗减弱的热带气旋）[S7]——这是建筑规范层面的要求，见 `NCC现行版本与住宅要求.md`。

## 2. Brisbane City Plan 2014 中与独立住宅相关的部分（待证实）
以下为框架，需逐条到 City Plan 在线版核对：
- **Dwelling house code**：适用于一般地块上的独立住宅，规定建筑高度、退让、场地覆盖率、车库/车道、外观等的 acceptable outcomes——**待证实**。
- **Dwelling house (small lot) code**：适用于小地块（面积门槛待证实）上的独立住宅——**待证实**。
- **评估类别**：一般情况下，在 Low density residential 等分区内建独立住宅属于 accepted development（不需要开发许可，只需建筑许可）；若不满足 accepted development 的条件，或受某些 overlay 影响，可能变为 code assessable，需要向市政府提交开发申请——**待证实**，具体以 City Plan 的 assessment benchmarks 表为准。
- **City Plan 可以变更 QDC 的退让规则**：在布里斯班，City Plan 中的 Dwelling house code 等对部分 QDC MP1.1/1.2 事项（如退让、高度）有替代条文（alternative provisions），此时由 certifier 按 City Plan 评估，如不符合需向市政府申请「concurrence agency」意见或开发许可——**待证实**（机制需核对 Building Act 1975 和 Planning Regulation 2017 原文）。

## 3. 需要开发许可的常见触发条件（待证实）
| 触发条件 | 可能后果 | 状态 |
|---|---|---|
| Traditional building character overlay（1946 年前房屋）/ Heritage overlay | 拆除、迁移或新建可能需开发许可；对外观、高度有额外要求 | 待证实 |
| Flood overlay | 最低地板高度、建筑形式（如架空）要求；可能影响造价 | 待证实 |
| Bushfire overlay | 可能需按 AS 3959 进行 BAL 评估，影响材料成本 | 待证实 |
| Acid sulfate soils overlay | 开挖、填土需管理方案 | 待证实 |
| Landslide / steep land overlay | 可能需岩土报告，影响基础和挖方 | 待证实 |
| 不满足 Dwelling house code 的 acceptable outcomes | 由 accepted 变为 code assessable，需 DA | 待证实 |

## 4. 洪水信息怎么查（待证实）
- **Flood Awareness Map**：布里斯班市政府在线地图，可按地址查看河流、溪流、暴雨、风暴潮等洪水可能性——工具名称和功能待证实。
- **FloodWise Property Report**：按地址生成的免费物业洪水报告，通常包含洪水水位、建议最低地板高度等信息——**报告名称、内容和是否收费均待证实**。
- 省钱提示（原则性）：洪水 overlay 会直接影响地板高度、楼板形式和保险成本，**买地前**查报告最划算。

## 5. 与 QDC MP1.1/1.2 和 QHC 的关系
- 法律层面：MP1.1（小于 450 m² 地块）/ MP1.2（450 m² 及以上地块）是州级独立住宅设计与选址标准，现已由 QHC（QDC Parts 1.1 and 1.2，2026-09-01 版）取代，第 1 章、第 2 章对应同样的 450 m² 分界 [S1][S2]。
- 布里斯班实际适用哪套规则：取决于 City Plan 是否已按 QHC 修订——**待确认**。2029-09-01 之前，旧安排可能继续有效 [S2]。
- 实操建议：设计开始前请 building certifier 书面说明你的地块适用的退让、高度和覆盖率规则来自哪里（City Plan / QHC / 旧 MP1.1–1.2）。

## 6. 待查清单（后续检索时逐项核对）
1. City Plan 2014 当前版本号和生效日期；Dwelling house code 和 Dwelling house (small lot) code 的现行条文（brisbane.qld.gov.au 的 City Plan 在线版）。
2. 「More Homes, Sooner」修订是否已生效、对独立住宅的影响 [S4]。
3. 布里斯班是否已按 QHC 修订 City Plan。
4. Flood Awareness Map 和 FloodWise Property Report 的官方页面、内容和收费。
5. Bushfire、acid sulfate soils、landslide/steep land、character、heritage overlay 的触发条件。
6. 布里斯班是否 opt-in QDC MP4.2（雨水箱）。

## 7. 需要业主决定的事项
1. 买地前是否先付费做规划/洪水/土壤尽职调查（建议在签约前或合同的冷静期/条件期内完成）。
2. 若地块有 character 或 flood overlay，是否接受开发申请的时间和费用，或换地。
