# 布里斯班规划与地块限制

适用州：QLD（Brisbane City Council 辖区）｜资料核对日期：2026-11-20｜状态：大部分已核实（第二轮已核对布里斯班市政府原文），具体数值待证实

## 摘要
本文说明在布里斯班建独立住宅时规划层面的规则。
- **什么时候需要开发许可**：位于 accepted development 分区、满足 Dwelling house code（小地块适用 Dwelling house (small lot) code）acceptable outcomes 的新房不需要规划许可。地块受 Flood、Bushfire、Traditional building character、Heritage、Landslide 等 13 种 overlay 之一影响时，变为 code assessable，需要提交开发申请（DA）[S1]。
- **建筑许可**：所有住宅都需要 [S1]。
- **退让规则**：市政府仍指引按 QDC MP1.1 / MP1.2 执行；小于 450 m² 的地块，City Plan 的 small lot code 优先 [S2]。
- **洪水**：用 Flood Awareness Map 查看，可下载 FloodWise Property Report，报告给出最低可居住楼面标高等技术数据 [S3]。
对省钱的用处：买地或开始设计前先查 overlay 和洪水报告，能提前知道是否需要做开发申请、是否要抬高楼面，避免设计返工和额外费用。

> 核对方式说明：第二轮已直接读取 brisbane.qld.gov.au 原文。City Plan 条文所在的 cityplan.brisbane.qld.gov.au 不在放行名单，Dwelling house code 的具体条文数值（退让、高度、覆盖率）未能读取，仍待证实。

## 1. City Plan 当前版本（已核实）

- v37.00 包含 **「More Homes, Sooner – Low-medium density residential design」修订**，内容是修改 Low-medium density residential 分区条文（2026-08-18 通过）[S4]。它针对低中密度住宅分区，对 Low density residential 分区独立住宅的影响需在 City Plan 中核对（待确认）。
- 上一版 v36.00/2026 于 2026-06-12 生效 [S4]。
- 条文在线查阅：City Plan online，https://cityplan.brisbane.qld.gov.au/eplan [S5]。

## 2. 新建独立住宅需要哪些许可（已核实）[S1]
- **City Plan 的定义**：dwelling house 指一户使用的住宅，包括一栋住宅及附属建筑，或者两栋住宅（其中一栋为 secondary dwelling）及附属建筑。dual occupancy、multiple dwelling 等不属于 dwelling house。
- **不需要规划许可**：新房属于 accepted development，或者属于 Planning Regulation 2017 Schedule 6 规定不得设为需评估的情形。accepted development 的条件是：地块在 accepted development 分区，并通过自评满足以下 acceptable outcomes：
  - **Dwelling house code**；小地块改用 **Dwelling house (small lot) code**；
  - 以及其他适用的 code。
  - 具体情形见 City Plan **Table 5.3.4.1 Prescribed accepted development**。
  - 这种情况下开工无需市政府书面文件。
- **需要规划许可（code assessable）**：新房受以下任一 overlay 影响时：
  - Airport environs overlay（仅 ANEF 子类）
  - Biodiversity areas overlay
  - **Bushfire overlay**
  - Coastal hazard overlay
  - Commercial character building overlay
  - **Flood overlay**
  - **Heritage overlay**
  - **Landslide overlay**（即陡坡、滑坡风险）
  - Pre-1911 overlay
  - **Traditional building character overlay**
  - Significant landscape tree overlay
  - Waterway corridors overlay
  - Wetlands overlay
- 部分 overlay（例如 Heritage、Wetlands）**无论是否满足 acceptable outcomes 都必须申请规划许可**。
- 拆除或迁移 Traditional building character overlay 内 **1946 年或以前**建成的房屋（或其一部分），可能需要规划许可。
- **建筑许可**：所有住宅都是 Class 1a，都需要 certifier 签发建筑许可。
- **省钱提示（市政府原文）**：把以后要建的棚子、车库、车棚一起写进同一份建筑申请，可以省去以后单独申请的费用 [S1]。
- 新房的开发申请可能适用 **RiskSMART** 快速评估流程 [S1]。
- certifier 向市政府在线提交建筑认证文件的费用为 **$78.80**（市政府页面，日期未标明）[S1]。

## 3. 退让和选址：City Plan、QDC MP1.1/1.2 与 QHC 的关系（已核实）
- 市政府「Building near the boundary」页面 [S2]：
  - **标准地块**：450 m² 及以上，退让查 QDC **MP1.2**。
  - **小地块**：小于 450 m²；**后地块（rear lot）小于 600 m² 即算小地块**。City Plan 的 **Dwelling house (small lot) code** 规定了选址条文，并且「**City Plan's small lot code prevails over the QDC**」；QDC 的对应文件是 MP1.1。
  - 不符合 QDC acceptable solutions 时，按 performance criteria 评估。私人 certifier 是评估主管机关，市政府作为 referral agency 提供意见，即「request for a referral agency response（QDC siting variation）」。
  - 邻居同意也不能代替市政府的审批。
- **QHC**：QDC MP1.1 / MP1.2 现已改为 Queensland Housing Code 的 Chapter 1 / Chapter 2（2026-08-14）。过渡期 2026-09-01 至 2029-09-01 内，只有 planning scheme 修订写明 QHC 如何适用后才适用；否则继续适用原 MP1.1/1.2 或 scheme 中的替代条文 [S6][S7]。
- **布里斯班现状**：市政府页面仍按 MP1.1/1.2 指引。Major amendment package L（小地块住宅、附属住宅、传统建筑特色）注明市政府正在审阅意见，并考虑 QHC 等法规变化，时间表待定 [S8]。**截至 2026-11-20，没有看到布里斯班已采用 QHC。**
- 小地块车库示例（Dwelling house (small lot) code 解释指引 01/2017）[S9]：
  - 双车位车棚宽度至少 5.5 m，双车库内宽至少 5.7 m（或与 QDC MP1.2 A8 一致）；
  - 双车库门比同一建筑的其他部分再后退 1 m 或以上，即可视为满足 AO13.3。
  - 该指引「current as at October 2019」，现行有效性待确认。
- **Dwelling house code 本身的退让、高度、覆盖率数值：待证实**，需在 City Plan online 中查阅。

## 4. 洪水信息（已核实）[S3]
- **Flood Information Online** 是市政府的洪水信息中心，其中有：
  - **Flood Awareness Map**（https://fam.brisbane.qld.gov.au/ ）：输入地址、lot plan 或 suburb，可查看河流、溪流、风暴潮等各类洪水的可能性。
  - **Technical FloodWise Property Report**：从地图或「I am in construction or development」入口生成，约 20 秒下载。
- **FloodWise Property Report 内容**：
  - 洪水概要图；
  - 2011 年 1 月和 2022 年 2 月的历史洪水位；
  - 航拍图（City Plan 采用的河流、溪流、风暴潮综合 1% AEP 范围，**不显示 overland flow**）；
  - 地面标高分析；
  - 0.2%、1%、2%、5%、20% AEP 的洪水位；
  - **最低可居住楼面标高（minimum habitable floor level）**；
  - 适用的河流、溪流、overland flow、海岸灾害 overlay；
  - 物业开发标记，例如是否在 overland flow path 内。
  - 数据依据 City Plan 已采用的洪水规划信息。
- 报告没有显示河流、溪流、风暴潮洪水位，**不代表没有洪水风险**，仍可能有 overland flow，要看报告中的开发标记。
- 对报告中的洪水位有异议的，可以向市政府书面申请复核，需提供认证测量标高、竣工图等证据。
- **是否收费**：页面未提及费用，生成流程中也没有付费步骤，但页面没有明说免费，待确认。
- 省钱提示：买地前下载报告。最低可居住楼面标高直接决定是否要抬高楼面或采用架空结构。

## 5. 其他 overlay 与场地限制
| 项目 | 已核实内容 | 来源 |
|---|---|---|
| Bushfire overlay | 新房在 Bushfire overlay 内为 code assessable。市政府雨水箱页面称 Bushfire overlay code 适用于独立住宅以外的开发，独立住宅仅在 Ferny Grove and Upper Kedron 邻里规划区按该 code 的 section D 检查。两页说法需对照 City Plan 原文（待确认）。NCC 层面见 H7D4 及昆州变体 QLD H7D4(3) | [S1][S10] |
| Landslide overlay（陡坡）| 新房在 Landslide overlay 内为 code assessable | [S1] |
| Character / Heritage | 布里斯班的特色房屋主要指 **1946 年底前**建成的房屋，1911 年前的房屋有特别规定。Pre-1911 building overlay 要求保留 1911 年前的房屋；州级遗产由昆州政府管理（Queensland Heritage Register）| [S1][S11] |
| 填土和开挖 | 改变地面标高不超过 1 m 一般不需要规划许可，但位于 neighbourhood plan 区域或受 overlay 影响的除外；为建造建筑物而填挖超过 1 m 需要建筑许可 | [S12] |
| Acid sulfate soils | 市政府新房页面的 code assessable overlay 清单中**没有**酸性硫酸盐土；City Plan 是否有相关 overlay 及其对填挖的触发条件，待证实 | [S1] |
| 雨水箱 | 布里斯班不在 QDC MP4.2 的 opt-in 名单中，不强制安装。自愿安装时：离边界 450 mm 以内、含支架高于 2.4 m、长于 5 m、埋地超过 1 m，或附着于建筑且距另一建筑小于 900 mm 的，需要建筑许可；接入室内需要管道许可 | [S10][S13] |

## 6. 仍待查清单
1. Dwelling house code 和 Dwelling house (small lot) code 的现行条文数值，以及 Table 5.3.4.1（需访问 cityplan.brisbane.qld.gov.au）。
2. More Homes, Sooner（v37.00）对 Low density residential 分区独立住宅有无影响。
3. Acid sulfate soils overlay 的触发条件。
4. FloodWise Property Report 是否收费。
5. 布里斯班采用 QHC 的时间表（关注 Major amendment package L）。

## 7. 需要业主决定的事项
1. 签约买地前，是否先查 City Plan online 的 overlay 并下载 FloodWise 报告（建议在合同条件期内完成）。
2. 地块如果有 Flood、Character、Bushfire、Landslide 等 overlay，是接受开发申请（DA）的时间和费用，还是换地。
3. 设计不符合 QDC 或 small lot code 的退让要求时，是否请 certifier 申请 referral agency response（会有额外时间和费用），还是调整设计。
