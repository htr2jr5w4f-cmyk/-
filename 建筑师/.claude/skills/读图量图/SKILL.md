# 读图量图

## 依据文件（先读）
- 使用说明：`06-技能清单/读图量图工具使用说明.md`（用法、口径、限制、与计算表的衔接）
- 脚本：`06-技能清单/脚本/dxf算量.py`、`06-技能清单/脚本/pdf图纸量尺.py`
- 下游：`05-工具与模板/工程量计算表.xlsx`、`.claude/skills/工程量计算/SKILL.md`、`.claude/skills/看图出方案/SKILL.md`

## 步骤
1. **确认文件类型和环境**
   - 依赖：`pip install ezdxf pymupdf openpyxl`（缺什么装什么）。
   - 第一次在新环境使用时，先跑 `python3 06-技能清单/脚本/测试数据/运行测试.py`，全部通过再用于真实图纸。
   - DWG：ezdxf 不能读，请业主向设计方要 DXF，或用 ODA File Converter / AutoCAD「另存为 DXF」转换；转换后用一条已知尺寸核对单位。
2. **先看图，定口径**（不看图不量）
   - PDF：`python3 pdf图纸量尺.py 信息 图纸.pdf` 看每页纸张、是否扫描件；`渲染 --页 N --dpi 150` 出 PNG 后用 Read 工具逐页看图签（比例、纸张、图号、版次）、图例、墙体画法（单线/双线）。
   - DXF：先 `python3 dxf算量.py 图纸.dxf` 不加过滤，看有哪些图层、单位是否正确（`$INSUNITS=0` 时脚本按 mm 假设并警告）。
   - 写下口径：墙按中心线还是外包线、slab 面积是否含门廊/车库、门窗以门窗表为准。
3. **量取**
   - DXF：`python3 dxf算量.py 图纸.dxf 结果.xlsx --图层 "*WALL*" "*DOOR*" "*WIN*"`；需要块内线长（如门扇弧）时加 `--展开块`；单位不对时加 `--单位 mm`。
   - PDF：优先两点校准：用「文字」子命令找到一个大尺寸（如总长 20000）的位置，渲染 PNG 读出尺寸线两端坐标，`量尺 --校准 x1,y1,x2,y2,20 --像素dpi 150 --区域 …`；再用 `--比例 1:100 [--纸张 A1]` 量一次，两者应一致（差异 >1% 要查原因：缩印、纸张写错、比例写错）。
   - 用 `--颜色`、`--最小线宽`、`--图层` 把墙线与填充图案、家具、尺寸线分开。
4. **核对**（每个数字都要过）
   - 至少一个量取值与图上标注尺寸对比（DXF 看「尺寸标注」表，PDF 看「文字」）。
   - 双线墙的线长 ≈ 2 × 墙长；闭合面积合计可能有嵌套重复，看明细表逐个确认。
   - 块数量与门窗表、灯具表逐项对数；对不上的列入问题清单（RFI）。
5. **填入计算表**：按使用说明第六节把长度、面积、数量填到 `工程量计算表.xlsx` 黄色格，备注写来源和口径，再按「工程量计算」技能算采购量。
6. **交付时说明**：列出用了哪个脚本、哪些图层/区域、比例或校准依据、口径，以及「量取值仅供估算，施工以标注尺寸和详图为准」。

## 不做的事
- 不把扫描件、截图上量出的数当作精确值；必须注明「按扫描件估量」。
- 不在图纸注明 do not scale 且有标注尺寸时用量取值替代标注值。
- 不编造比例或纸张；图签看不清时用两点校准，并在结果里写明校准用的尺寸。
