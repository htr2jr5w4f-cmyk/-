# 装修平面出图

> **出的是概念草图**：只用于和业主讨论房间组合、估算隔墙和门的数量。**正式设计和报批图纸必须由合资格的设计人员完成**（室内设计师、建筑设计人员；涉及消防、机电、结构的由相应工程师），并经 landlord 和 certifier 审查。对外不要把草图称为设计图或施工图。

## 依据文件（先读）
- 脚本：`06-技能清单/脚本/装修平面出图.py`（参数说明见文件开头注释）
- 测试：`06-技能清单/脚本/测试数据/装修平面出图/`（示例清单 JSON / CSV 和 `运行装修平面测试.py`，52 项）
- 法规数值：`01-法规标准/商业装修法规与审批.md` 第 2 节（Table D2D18 人数）、第 3.2 节（D2D8 疏散宽度、D2D9 门宽、D3D25 开门方向、D3D26 门锁）、第 3.3 节（E4 应急照明）、第 3.5 节（F4D4 卫生设施）
- 疏散距离：`01-法规标准/高层建筑-NCC第一卷要点.md` 第 5 节（D2D5、D2D6）
- 下游：「读图量图」技能（`dxf算量.py` 读回面积）、「看图出方案」技能（商业装修方案）

## 步骤
1. **整理房间清单**：写成 JSON 或 CSV（格式见脚本注释和测试样例）。每间写名称、类型（前台、办公区、会议室、经理室、茶水间、卫生间、库房、设备间、打印区、其他）、面积或长宽；需要时加「条带」（下侧 / 上侧 / 单侧）指定放在哪一边。租户区外轮廓写在 JSON 的「租户区」里，或 CSV 加一行「类型=租户区」，或用 `--宽 --深`。
2. **运行**：
   ```
   python3 06-技能清单/脚本/装修平面出图.py 清单.json -o 输出/方案A [--走道宽 1.5] [--下侧进深 4.5] [--余量并入 办公区]
   ```
   常用参数：`--最小走道宽`（默认 1.0 m，D2D8）、`--门宽`（默认 0.92 m）、`--隔墙厚`（默认 0.1 m，算走道净宽用）、`--人均面积`（默认 10 m²/人，D2D18 办公）、`--布局 双侧|单侧`、`--严格`（有不合格项时退出码 1）。
3. **看校核**（终端和 `_校核.json`）：
   - 「不合格」必须先解决：总面积超出、房间放不下、走道净宽不够、房间没门、门宽小于 0.75 m。
   - 「提示」要人工判断：最远行走距离（只算到租户入口门，NCC D2D5 的疏散距离要算到楼宇的出口）、湿区位置（要对 base building 给排水立管）、余量面积、房间过窄。
4. **看图**：用「读图量图」技能的 `pdf图纸量尺.py 渲染` 出 PNG 检查；房间太窄、门位置不合理时调整清单顺序、「条带」或 `--下侧进深` 再出一版。几种方案各出一版并列比较。
5. **读回核对**：`python3 06-技能清单/脚本/dxf算量.py 方案A.dxf 方案A_算量.xlsx`。「房间边界」图层的闭合面积逐间等于排布面积；「隔墙」图层线长是隔墙中心线长度（单线，可直接用于估龙骨和石膏板，两面封板按 ×2 算面积）；「门」图层块数 = 房间数 + 1（租户入口）。
6. **交给设计**：把草图、校核结果和清单一起交给设计人员，作为 brief 的附件；同时列出缺的资料（lease、fit-out guide、base building 图纸、消防系统图等，见「看图出方案」技能）。

## 输出说明
- DXF（mm）：外轮廓、隔墙、门、房间名、面积标注、疏散通道示意 6 个图层，另加 房间边界（每间一条闭合多段线）、尺寸、图签。
- PDF：A3 横向，自动选比例（1:50 / 1:100 / 1:200…），PDF 图层名与 DXF 相同，可用 `pdf图纸量尺.py --比例 1:100 --图层 房间边界` 量面积。
- 图签写明「概念草图，正式设计须由合资格的设计人员完成」。

## 限制（务必知道）
1. **只会条带式排布**：一条直走道贯通租户区，房间沿走道一侧或两侧排开，每侧进深统一；不会做 L 形、环形走道、房间套房间，也不避让柱子、核心筒、窗位和楼宇公共走道位置。真实楼层平面不是矩形时不能用。
2. **不知道 base building 条件**：给排水立管、喷淋和烟感布置、空调分区、楼板荷载、窗户和遮阳都不考虑。湿区、重物（档案密集架）位置一律要按 base building 图纸调整。
3. **校核只是初筛，不是合规判断**：只查面积、走道净宽（D2D8）、门数量和门宽（D2D9）；疏散距离（D2D5）、出口数量和间距（D2D3、D2D6）、开门方向和门锁（D3D25、D3D26）、无障碍（D4、AS 1428.1）、卫生设施数量（F4D4，通常靠楼宇核心筒卫生间）、应急照明和出口标志（E4）、防火分隔都不查，须由设计人员和 certifier 确认。改变疏散布局的隔墙按需要 building approval 处理（见法规文件第 1 节）。
4. **门是示意**：每间一扇，固定放在走道墙上；门宽当作净宽检查，实际门扇规格、五金、开启方向以设计和门五金表为准。
5. **房间形状由面积 ÷ 条带进深决定**：给了长宽的房间会被改成条带进深下的等面积矩形（脚本会提示）；排布面积取整到 10 mm，可能和需求差约 0.05 m²。
6. **数值依据**：最小走道宽 1.0 m、门洞 750 mm、办公 10 m²/人是 NCC 2022 Volume One 的数值（法规文件已读原文）；昆州 2027-05-01 起改用 NCC 2025，届时要重新核对并改脚本开头的常量。
