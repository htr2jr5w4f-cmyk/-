# 买地尽职调查清单

适用州：QLD（布里斯班）｜资料核对日期：2026-11-20｜状态：部分待证实（法定披露、规划、洪水、印花税已对照原文核实；Urban Utilities、BYDA、Energex/NBN 仍待证实）

## 摘要
这份清单用于在布里斯班签买地合同前、或在合同条件期（finance / building & pest / due diligence 条件）内逐项核查。土地上的隐藏问题会直接变成建造成本，例如洪水、地下管线、反应性土壤、坡度、规划限制。买前查清楚，是整个项目最便宜的省钱环节。每一项都注明了去哪里查、来源是什么。法律问题请让你的 conveyancer 或律师确认，本清单不构成法律意见。

**使用方法**：每项填「结果 / 日期 / 文件保存位置」。出现红旗（🚩）时，先停下来，咨询律师、工程师或 certifier，再决定是否继续。

## 1. 合同与法定披露

| # | 检查项 | 怎么查 / 看什么 | 结果 | 来源 |
|---|---|---|---|---|
| 1.1 | 卖方是否提供了 Seller Disclosure Statement（Form 2）和规定的证书 | Property Law Act 2023 自 2025-08-01 起施行卖方披露制度。卖方（或其代理）须在买方签约**前**提供完整的披露声明和规定证书；卖方不遵守时（即使是无意的），买方可能有权在交割前任何时候终止合同（具体条件以法律为准，问律师）。🚩 签约前没收到 | | [S1][S2] |
| 1.2 | 合同里的条件条款（finance、due diligence、soil test 等）和期限 | 让 conveyancer 确认，条件期是否够你完成本清单 | | 待证实（无官方模板来源，按律师意见） |
| 1.3 | 产权查册：所有人、mortgage、caveat、easement、covenant | 由 conveyancer 做 title search。easement 上建筑一般需要额外审批（见 4.2）| | [S9] |
| 1.4 | 开发商 covenant / 设计指引（新区常见） | 外立面材料、屋面颜色、围栏等要求会增加造价 | | 待证实（各开发商不同） |

## 2. 规划与分区（Brisbane City Plan 2014）

| # | 检查项 | 怎么查 / 看什么 | 结果 | 来源 |
|---|---|---|---|---|
| 2.1 | 分区 zone、overlay、neighbourhood plan | 用 Brisbane City Council 的 City Plan 在线地图查地址。overlay（重要植被、水道、传统建筑特色等）可能让住宅从「无需规划审批」变成「需 DA」| | [S3] |
| 2.2 | 建一栋住宅是否属于 accepted development（不需要规划审批） | Council 指引：查 City Plan Table 5.3.4.1 Prescribed accepted development。落在 code assessable overlay（如 Flood、Bushfire、Landslide、Heritage、Traditional building character、Waterway corridors、Biodiversity areas 等）中且不满足 acceptable outcomes 时，需要申请规划审批；Heritage、Wetlands 等 overlay 无论是否满足都要申请 | | [S3] |
| 2.3 | 「Traditional building character」等 overlay | 会限制外观或拆除，增加设计成本 | | [S3] |
| 2.4 | 周边已批 DA 和在审 DA | Council 的 Development.i 系统 | | 待证实（未核对页面）|

## 3. 洪水、坡度与自然条件

| # | 检查项 | 怎么查 / 看什么 | 结果 | 来源 |
|---|---|---|---|---|
| 3.1 | Flood Awareness Map | 免费，按地址查河流、溪流、暴雨、overland flow 等洪水可能性 | | [S4] |
| 3.2 | FloodWise Property Report | 下载技术报告，看历史洪水位、各发生概率（AEP）的洪水位、**最低居住层地板标高**，以及 overland flow 等 property development flags（航拍图不显示 overland flow）。🚩 有 overland flow 标记时，找 RPEQ 工程师确认最低地板标高（这是第一轮搜索摘要中的 council 建议，本次在页面正文没有找到，待证实）| | [S4][S5] |
| 3.3 | 洪水区内建筑的额外要求 | Council 的 flood-resilient design 要求会抬高地板标高或增加材料成本 | | [S6] |
| 3.4 | 坡度与挡土 | 请测量员出等高线测量；坡地会增加挡土墙、切填和 slab/桩的成本 | | 待证实（无官方页面引用；按测量报告）|
| 3.5 | 土壤反应性分级（AS 2870-2011：A、S、M、H1/H2、E、P；H1/H2 细分待证实）| 买前做 soil test，或至少写进合同条件。QBCC 资料：场地调查须由工程师或持牌土壤测试员做；H、E、P 类需要更复杂的设计（plumbing 许可也要 drainage articulation 设计）。P 类（异常场地）要工程师专门设计 | | [S7][S11] |
| 3.6 | 大树（含邻地）位置 | 黏土地上树木是常见沉降原因，影响基础设计 | | [S7] |

## 4. 地下设施与接驳

| # | 检查项 | 怎么查 / 看什么 | 结果 | 来源 |
|---|---|---|---|---|
| 4.1 | 污水 / 供水管线位置（是否穿过地块） | 查 Urban Utilities 资产图；Before You Dig Australia（BYDA）| | [S9]；BYDA 待证实（未核对页面）|
| 4.2 | 是否需要 Build Over Asset（BOA）转介 | Urban Utilities：设计不符合 QDC MP1.4 的 acceptable solutions 时需要转介。不允许在压力供水管上建房；在注册 easement 上或越入 easement 的建筑须获批准。🚩 污水管从地块中间穿过 | | [S9] |
| 4.3 | 水、污水接驳点是否已到地块 | 新住宅接驳要走 Urban Utilities 的标准接驳申请 | | [S8] |
| 4.4 | 电力、NBN 是否已到红线 | 向 Energex 和 NBN 查询 | | 待证实（未核对 Energex/NBN 页面）|
| 4.5 | 雨水排放点（legal point of discharge） | 雨水和屋面水管不归 Urban Utilities 管，由 council 负责 | | [S9] |

## 5. 费用与税

| # | 检查项 | 怎么查 / 看什么 | 结果 | 来源 |
|---|---|---|---|---|
| 5.1 | 印花税（transfer duty）及首套空地优惠 | QRO 页面：自 2025-05-01 起，住宅空地可能不用缴印花税（全额优惠）。条件包括：以个人身份购买；从未领过此优惠；从未在任何地方拥有过住宅权益；年满 18 岁；按市价购买；**交割后 2 年内**建好首套住宅并入住（不能延期）；只建 1 栋住宅。2026-08-01 及以后的交易要求是澳洲公民、永久居民或特定外国退休人士；2026-10-22 及以后的交易，地上若有建筑须为「eligible building」（例如花园棚）。**规则近期多次变化，签约前务必用 QRO 页面核对** | | [S10] |
| 5.2 | Infrastructure charges 是否可能产生 | 仅建一栋住宅、按 building approval 进行时一般不收；需要 DA 或分割地块时可能收。以书面通知为准 | | [S8] |
| 5.3 | Council rates、水费 | 查卖方提供的通知或 council | | 待证实 |

## 红旗汇总（任一项出现都先暂停）
- 没收到卖方披露文件就被催签约 [S1]
- 地块在 overland flow 路径上，或 FloodWise 报告显示需要大幅抬高地板 [S4]
- 污水管或压力供水管穿过可建区域 [S9]
- 土壤分级为 H2、E 或 P [S7]
- overlay 导致必须申请 DA，而你的时间或预算没有留出这部分 [S3]
