# 看图出方案示例

适用州：QLD｜资料核对日期：2026-11-21｜状态：示例（全部图纸参数为假设）；引用规范部分已核原文，其余见文末待证实

## 摘要
本文用一套**假设的**简单单层住宅（200 m² 平板基础、砖贴面、金属屋面）演示「看图出方案」的完整 5 部分输出：施工步骤、用料、注意事项、工期、工地管理。所有数量都用公式推算，写出计算过程，可以直接对照 `工程量计算表.xlsx` 的「住宅」工作表复算。本文**不写价格**，也**不填损耗系数、包装单位和工期天数**（这些必须按供应商资料和分包商报价填写）。用途：拿到真实图纸时，照这个格式把假设值换成图纸值即可。

> ⚠ **假设示例图纸参数**：下表所有数值都是为演示虚构的，不代表任何真实项目，也不是设计建议。真实项目一律以结构工程师图纸、土壤报告和审批图为准。

## 1. 施工步骤

按 `住宅施工工序与用料总表.md` 的 27 道工序排列，本例要点如下（🔒 = 法定检查，Building Regulation 2021 (Qld) s44(1)(b)；class 1a 的开挖、slab 浇筑前和最终阶段只能由 building certifier 签检查证书，s46 [S3]）：

1. 开工前：BA、Home Warranty 保险、施工版图纸、RFI 清单回复。
2. 场地建立 → 测量放线。
3. 场地开挖、地梁沟槽 → 地下排水 / 污水预埋。
4. 🔒 开挖检查（s44(1)(b)(i)）。
5. 白蚁管理 → 防潮膜 → slab 钢筋网和地梁 trench mesh。
6. 🔒 Slab 浇筑前检查（s44(1)(b)(iii)）。
7. 浇筑 slab，湿养护 7 天 [S1]。
8. 墙架 → 屋架。
9. 🔒 框架检查（s44(1)(b)(iv)/(v)，按 bracing 方式定在覆面前或后）。
10. 金属屋面（sarking、泛水、天沟、落水管）；外门窗；砖贴面。
11. 水电粗装 → 保温 → 石膏板 → 湿区防水 → 墙地砖 → 细木作 → 涂料 → 水电终装。
12. 外部工程 → 清洁自检。
13. 🔒 最终检查（s44(1)(b)(vii)）→ 实际完工、交付。

## 2. 用料（工程量计算过程）

通用公式：**采购包装数 = ROUNDUP(净工程量 × (1 + 损耗率 k) ÷ 每包装数量 P, 0)**。k 和 P 按供应商书面资料填写，本例不填。

| # | 项目 | 计算过程 | 净工程量 | 规格 / 依据 |
|---|---|---|---|---|
| R1 | 场地开挖 | 220 m² × 0.20 m | **44.0 m³** | 外运另乘松方系数（按土方承包商） |
| R2 | 地梁沟槽开挖 | (60 + 40) m × 0.30 m × (0.45 − 0.10) m | **10.5 m³** | 沟槽深按板下梁深计 |
| R3 | Slab 板面混凝土 | 200 m² × 0.10 m | 20.0 m³ | |
| R4 | 边梁（板下） | 60 m × 0.30 m × (0.45 − 0.10) m | 6.3 m³ | |
| R5 | 内梁（板下） | 40 m × 0.30 m × (0.45 − 0.10) m | 4.2 m³ | |
| — | **Slab 混凝土合计** | 20.0 + 6.3 + 4.2 | **30.5 m³** | 等级按结构图；Housing Provisions 4.2.10 最低为 N20，最大骨料 20 mm，名义坍落度 100 mm [S1] |
| R7 | Slab 钢筋网 | = slab 面积 | **200 m²**（加搭接用量） | 假设 SL72；搭接按结构图或 Table 4.2.11b [S1] |
| R8 | 地梁 trench mesh | 100 m × 1 条 | **100 m** | 假设 3-L11TM；可按 Table 4.2.11a 换成钢筋 [S1] |
| R9 | 防潮膜 | 200 + 60 × 0.65 + 40 × 0.70 = 200 + 39 + 28 | **267 m²**（加 ≥200 mm 搭接用量） | 边梁附加 0.65 m = 内侧板下梁深 0.35 + 外侧延至地面 0.30（假设）+ 梁底 0.30 − 梁宽 0.30；内梁附加 0.70 m = 2 × 0.35。0.2 mm 中等抗冲击，须延伸到梁下至地面 [S1] |
| R10 | 框架墙长度 | 60 + 45 | **105 m** | 木材等级和截面按结构图（如 MGP10 90×45，等级名称待证实） |

| R12 | 立柱 | ROUNDUP(105 ÷ 0.45) + 30 + 20 × 2 = 234 + 30 + 40 | **304 根** | 105 ÷ 0.45 = 233.3，向上取整为 234 |
| R13 | 金属屋面 | 水平投影 (20 + 2 × 0.6) × (10 + 2 × 0.6) = 21.2 × 11.2 = 237.44 m²；坡度系数 = 1 / cos 22.5° = 1.0824；237.44 × 1.0824 | **257.0 m²** | AS 1562.1 或 Housing Provisions Part 7.2（风等级不超过 N3）[S2] |
| R14 | 外墙（砖贴面）净面积 | 60 m × 2.4 m − 30 m² | **114.0 m²** | 砖数 = 114 × 每 m² 块数（按砖厂资料）；拉结件 AS 2699.1 [S4] |
| R15 | 石膏板 | 45 × 2.4 × 2 + 58.8 × 2.4 − 70 + 185 = 216 + 141.12 − 70 + 185 | **472.12 m²** | 湿区用防潮板另列 |
| R16 | 地砖 | = 25 m² | **25 m²** | |
| R17 | 墙砖 | 20 × 2.1 − 3 | **39 m²** | |
| R18 | 湿区防水 | 20 + 6 × 1.8 + 25 × 0.15 = 20 + 10.8 + 3.75 | **34.55 m²** | AS 3740 或 Part 10.2 [S5]；防水膜 AS/NZS 4858；地面坡度 ≥1:80 [S5] |
| R19 | 内墙和天花涂料（涂刷面积） | 墙面 = 216 + 141.12 − 70 − 39（墙砖）= 248.12 m²；(248.12 + 185) × 2 遍 | **866.24 m²**（涂刷面积，含 2 遍） | 每桶可涂面积按制造商覆盖率 |

## 3. 注意事项（本例要点）

| 工序 | 技术要点 / 检查点 | 常见错误 | WHS |
|---|---|---|---|
| 开挖 | Class M 场地（假设）按 AS 2870 / Housing Provisions Section 4 设计；Section 4 有适用条件 [S2] | 沟槽积水、松土未清就预约检查 | 开挖边坡和地下管线；挖掘前查管线图 |
| 防潮膜 | 0.2 mm、标记清楚、搭接 ≥200 mm、穿管处套封、破损补封、延伸到梁下至地面 [S1] | 用无标记的薄膜；钢筋马凳刺穿未修补 | — |
| 钢筋 | 保护层（对土 40 mm、对膜 30 mm、室内 20 mm、外露 40 mm），马凳间距 ≤800 mm，钢筋清洁 [S1] | 钢筋网踩塌、保护层不足 | 钢筋头加保护帽 |
| 浇筑 | 不加水；振捣；湿养护 7 天 [S1] | 浇后不养护导致开裂 | 泵车和混凝土车的交通管理 |
| 框架 / 屋架 | 按结构图的 bracing 和 tie-down；昆州结构木材树种要求 [S2] | 漏装系件；桁架临时支撑不足 | 高处作业（WHS Reg s306C、s306D，见 CLAUDE.md）|
| 屋面 | 最小坡度、支撑间距、固定间距、金属相容性按 Part 7.2 [S6] | 不同金属混用导致腐蚀 | 屋面边缘防护 |
| 砖贴面 | 拉结件、DPC、泄水孔、空腔清洁 [S4] | 砂浆落入空腔堵塞泄水孔 | 脚手架 |
| 湿区 | 防水范围按 Part 10.2；坡度 ≥1:80 [S5] | 坡度不足积水；墙地交接处漏涂 | — |
| 全程 | 每个 🔒 节点取得检查证书后才进入下一步 [S3] | 没等证书就浇筑或封墙 | 造价 ≥$250,000 时属于 construction project，须有 principal contractor 和 WHS management plan [S7] |

## 4. 工期

本例**不填工期天数**（须按分包商报价和产量确定），只给逻辑关系和计算方法。把下表抄进 `施工进度计划模板.xlsx` 的「住宅进度」工作表（已预置同一套工序编号），填工期后自动算出最早开始 / 完成和甘特图。

- 逻辑主线（本例的关键路径候选）：R01 审批 → R02 场地建立 → R03 放线 → R04 开挖 → R05 排水预埋 / R06 🔒 开挖检查 → R07 slab 准备 → R08 🔒 浇筑前检查 → R09 浇筑养护 → R10 墙架 → R11 屋架 → R12 🔒 框架检查 → R13 屋面 → R16 水电粗装 → R17 保温 → R18 石膏板 → R19 防水 → R20 瓷砖 → R22 涂料 → R23 终装 → R25 清洁自检 → R26 🔒 最终检查 → R27 交付。
- 并行支线：R12 → R14 门窗 → R15 砖贴面 → R18（石膏板须等砖贴面完成，按本例逻辑）；R15 → R24 外部工程 → R25。
- 计算方法：ES = max(紧前工序 EF + lag)；EF = ES + 工期。若 R15 支线的 EF 晚于 R17，则关键路径改走门窗—砖贴面支线。
- 必须列入的等待时间：检查预约等待（作为 lag）；slab 湿养护 7 天 [S1]；桁架、门窗的工厂交货期（向供应商要书面交货期）；雨天。

## 5. 工地管理

| 项目 | 本例方案 |
|---|---|
| 组织架构 | Builder（持 QBCC 执照，负责人）→ 工地主管（每日在场，负责质量、安全、检查预约）→ 各分包：土方、水管工、混凝土、木工、屋面、门窗、砌筑、电工、保温、石膏板、防水、瓷砖、细木作 / 橱柜、油漆、外部工程 |
| 分包计划 | 按第 4 节逻辑，每个分包在进度表上有进场 / 退场时间；分包合同写明范围、工期、质量标准和 WHS 要求 |
| 场地布置（假设地块临街一侧为入口） | 入口设临时车道保护和工地标识；临时厕所和垃圾箱靠近入口；砖托盘和框架木材堆放在不影响混凝土泵车和桁架吊装的位置；桁架送货日安排吊装车位；材料堆放不压地下排水管 |
| 文件和记录 | 工地日报；检查证书（Form 16 等，见 `05-工具与模板/分阶段施工检查清单.md`）；混凝土送货单；防水和电气合规证明；variation（`变更单variation模板.md`）；与业主的沟通记录（`与builder沟通记录模板.md`）；照片存档（尤其封墙前的管线） |
| 质量管理 | 每道工序按 `住宅施工工序与用料总表.md` 的检查点自检，再预约法定检查 |
| 安全管理 | 入职培训；高风险作业（如高处、开挖）有 SWMS [S7]；造价达到 $250,000 时按 construction project 管理 [S7] |
| 与 certifier / council 配合 | 开工前确认检查阶段和预约方式；每个 🔒 节点提前预约，取得证书后再进入下一步 [S3]；最终检查前收齐证书 |
