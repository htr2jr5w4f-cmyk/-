# 住宅施工工序与用料总表

适用州：QLD（规范为全国 NCC 2022；⚠ 州差异已标出）｜资料核对日期：2026-11-21｜状态：部分待证实

## 摘要
本表按昆州 Class 1a 独立住宅（slab-on-ground 平板基础 + 框架 + 砖贴面或轻质外墙 + 金属或瓦屋面）从开工到交付的顺序，列出每道工序的主要材料（名称与规格类别）、依据的标准或 NCC 条款、检查点。规格名称只写澳洲通用叫法，并标来源；本次打开 NCC 原文核对过的标「已核」，没找到原文依据的标「待证实」。用途：看图时逐行对照，既是施工步骤清单，也是采购清单的骨架；具体型号、等级和尺寸一律以结构图和 general notes 为准。
本表按 NCC 2022 编写（昆州现行版本）。NCC 2025 在昆州 2027-05-01 起实施，届时需按新版复核（见 `01-法规标准/NCC现行版本与住宅要求.md`）。

**图例**：🔒 法定检查节点（Building Regulation 2021 (Qld) s44）｜✅ 已核（本次打开原文）｜❓ 待证实

## 二、规格名称速查（澳洲通用叫法）

| 叫法 | 含义 | 来源 / 状态 |
|---|---|---|
| SL62、SL72、SL82、SL92 | 方格钢筋网（square mesh）：「SL62」= 6 mm 钢筋、200 mm 间距；数字越大钢筋越粗 | Housing Provisions Part 4.2 说明文字和 Table 4.2.14 ✅ [S1] |
| L8TM、L11TM、L12TM（如 3-L11TM） | Trench mesh：「3-L11TM」= 3 根直径 11 mm 的纵向钢筋 | Housing Provisions Part 4.2 说明文字 ✅ [S1] |
| N10、N12、N16（如 6-N12） | 钢筋：「6-N12」= 6 根直径 12 mm 的钢筋 | Housing Provisions Part 4.2 说明文字 ✅ [S1]；「N」字母代表的钢筋延性等级含义见 AS/NZS 4671 ❓ |
| N20 | 28 天强度不低于 20 MPa 的混凝土 | Housing Provisions 4.2.10 ✅ [S1] |
| 0.2 mm 防潮膜（Medium / High impact resistance） | Slab 下聚乙烯膜，标记写明抗冲击等级 | Housing Provisions 4.2.8 ✅ [S1] |
| MGP10、MGP12、MGP15 | 机械分级结构松木的应力等级 | ❓ 待证实（应出自 AS/NZS 1748 和 AS 1684 跨度表，本次未打开原文） |
| 90×45、70×35 等 | 木材截面尺寸（mm） | ❓ 常用尺寸以结构图和 AS 1684 跨度表为准 |
| BMT | 金属屋面板的基材厚度（base metal thickness） | Housing Provisions Table 7.2.4 表头为「Sheet roofing base metal thickness (mm)」✅ [S10]；缩写「BMT」为行业常用说法 ❓ |
| N1–N6、C1–C4 | 风等级（wind class） | Housing Provisions Part 7.2 提到 wind class 不超过 N3 的适用条件 ✅ [S2]；完整分级见 AS 4055-2021 ✅（引用标准）[S5] |
| Class A、S、M、H1、H2、E、P | 场地分类（site classification） | AS 2870 ✅（H1D4 提到 Class A、S、M）[S2] |
