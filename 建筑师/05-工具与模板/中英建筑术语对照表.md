# 中英建筑术语对照表

## 摘要
本表供业主（说中文）和我们（持牌 builder 角色）与澳洲的 certifier、council、分包商、供应商、银行用英文沟通时查用。共 18 类、约 480 条，每条写英文、中文和简短解释（澳洲用法）。凡是 NCC 2022 Schedule 1 Definitions、QBCC Act 1991、QBCC New Home Construction Contract（2023 年 7 月版）、BIF Act 2017、Building Regulation 2021 有定义的，都按原文意译并标出处；其余标「通用」，是行业通用用法，不是法定定义。带 ★ 的是澳洲特有或与其他英语国家用法不同的词，写邮件和看合同时最容易误解。对 builder 的用处：同一个词在合同、法规和工地口语里意思可能不同（例如 Form 4、Form 7、lock-up），用错会导致付款、延期或检查出问题。

适用州：QLD（NCC 定义为全国）｜资料核对日期：2026-11-21｜状态：部分待证实（标出处的定义已读原文；标「通用」的为行业用法；个别项标「待证实」）

---

## 使用说明
- **出处标记**：[S1] NCC 2022 Schedule 1 定义；[S2] QBCC Act Schedule 1B；[S3] QBCC Act Schedule 2 和 Part 4A；[S4] QBCC New Home Construction Contract（下称 NHC），GC = General Conditions；[S5] BIF Act；[S6] Building Regulation 2021；[S7]–[S9] Brisbane City Council 页面；[S10] 本库已核实文件。没有编号、标「通用」的，是行业通用用法。
- **NCC 版本**：昆州现行 NCC 2022，NCC 2025 自 2027-05-01 起在昆州生效（见 CLAUDE.md 第五节）。下面的 NCC 定义取自 NCC 2022 Volume Two 的 Schedule 1（Volume One 和 Housing Provisions 共用同一套定义，个别词按卷不同，表中注明）。2027 年后以 NCC 2025 定义为准，届时要复核。
- **★** = 澳洲特有用法，或与美国、英国用法不同。
- **⚠ 州差异**：表中注明的词在其他州含义或法定名称不同。
- 解释里的数字只写有来源的；没有来源的不写。

## 1. 法规审批（Regulation & Approvals）

| 英文 | 中文 | 解释（澳洲用法）与出处 |
|---|---|---|
| National Construction Code (NCC) | 国家建筑规范 | 全国统一的建筑技术规范，分 Volume One（Class 2–9）、Volume Two（Class 1、10）、Volume Three（Plumbing Code）和 Housing Provisions。昆州通过 Building Act 1975 采用 [S10] |
| Building Code of Australia (BCA) | 澳洲建筑规范 | NCC Volume One 和 Two 的旧称和俗称，工地和报告里仍常说 "BCA compliance"。通用 |
| Plumbing Code of Australia (PCA) | 澳洲给排水规范 | NCC Volume Three。通用 |
| ABCB Housing Provisions ★ | 住宅条款 | NCC 2022 起把 Class 1/10 的 Deemed-to-Satisfy 做法集中写在这份文件里。通用 |
| Performance Requirement | 性能要求 | 「规定 Performance Solution 或 Deemed-to-Satisfy Solution 必须达到的性能水平的要求」[S1] |
| Deemed-to-Satisfy Provisions (DTS) ★ | 视同满足条款 | 「被视为满足 Performance Requirements 的条款」[S1]。照做即合规，最省事 |
| Deemed-to-Satisfy Solution | 视同满足方案 | 「满足 Deemed-to-Satisfy Provisions 的方法」[S1] |
| Performance Solution ★ | 性能方案 | 「用 Deemed-to-Satisfy Solution 以外的方法满足 Performance Requirements」[S1]。旧称 alternative solution；需要专家论证，certifier 批准 |
| Required | 规定需要的 | NCC 中特指「为满足 Performance Requirement 或 DTS 条款所需要的」[S1]，例如 required exit |
| Classification (Class 1a, 10a …) ★ | 建筑类别 | NCC 按用途分 Class 1–10。独立住宅为 Class 1a，车库、棚为 Class 10a，公寓为 Class 2，办公为 Class 5。通用（定义见 NCC Part A6） |
| Queensland Development Code (QDC) ★ | 昆州发展规范 | 昆州对 NCC 的补充（如边界退让 MP1.1/1.2、雨水箱 MP4.2）[S10] |
| Queensland Housing Code (QHC) ★ | 昆州住宅规范 | 2026-08-14 发布，即现行 QDC MP1.1 和 MP1.2；布里斯班截至 2026-11 未见采用 [S10] |
| Building Act 1975 (Qld) | 昆州建筑法 | 建筑审批、certifier、检查、证书的主法 [S10] |
| Building Regulation 2021 (Qld) | 昆州建筑条例 | 规定法定检查阶段（s44）、约检通知（s48）等 [S6] |
| Planning Act 2016 (Qld) | 昆州规划法 | 开发审批（DA）的主法 [S10] |
| Brisbane City Plan 2014 ★ | 布里斯班城市规划 | BCC 的 planning scheme；现行 v37.00（2026-09-18 生效）[S10] |
| Development application (DA) | 开发申请 | 向 council 申请规划审批。通用 |
| Material change of use (MCU) | 用途重大变更 | 需要规划审批的一类开发，例如在地块上新建多户住宅。通用 |
| Accepted development / code assessable / impact assessable | 免审 / 按规范审 / 影响评估 | 规划审批的三个层级；impact assessable 公示期至少 15 个工作日（Planning Act s53）[S10] |
| Overlay ★ | 叠加图层 | City Plan 中的洪水、特色风貌、山火、坡地等限制图层。通用 |
| Siting variation / boundary relaxation ★ | 退界变更 | 不符合 QDC 退界的可接受方案时，交 council 作为 referral agency 评估 [S10] |
| Building approval (BA) / building development approval | 建筑审批 | 建筑工程开工前须取得，由 building certifier 批准 [S10] |
| Building certifier / private certifier ★ | 建筑审批员（私营） | 昆州由持 BSA 执照的私营或 council 审批员批准和检查。注意不要叫 "building inspector" 或 "surveyor"（其他州叫 building surveyor，⚠ 州差异） |
| Assessment manager | 评估主管 | 受理和决定开发申请的机构（council 或 certifier）。通用 |
| Referral agency | 转介机构 | 对申请有建议或决定权的其他机构，如消防部门 [S10] |
| Competent person | 合格人员 | 可协助 certifier 检查或出具设计、检查证书的专业人员（如 RPEQ 工程师）[S6][S10] |
| RPEQ ★ | 昆州注册专业工程师 | Registered Professional Engineer of Queensland，由 BPEQ 注册；结构设计和 Form 15 一般由 RPEQ 签。通用 |
| Form 15 ★ | 设计合规证书 | Compliance certificate for building design or specification（competent person 出具）[S10] |
| Form 16 ★ | 检查证书 | Inspection certificate，certifier 对各法定阶段出具 [S10] |
| Form 21 ★ | 最终检查证书 | Final inspection certificate，Class 1a 和 Class 10 用；certifier 在 5 个工作日内给业主 [S10] |
| Form 11 ★ | 入住证书 | Certificate/interim certificate of occupancy，Class 2–9 用；独立 Class 1a 不适用 [S10] |
| Form 12 ★ | 部分检查证书（合格人员） | Aspect Inspection Certificate (Appointed Competent Person) [S10] |
| Form 43 ★ | 部分证书（QBCC 持牌人） | Aspect Certificate (QBCC Licensee)，如防水、白蚁处理 [S10] |
| Form 18 / Form 56 | 已委托 certifier 的通知 | 分别通知业主和 council 已委托 private certifier [S10] |
| Stage (of assessable building work) | 法定检查阶段 | Building Regulation s44 规定的检查节点；独立 Class 1a 有开挖、基础、底板、框架（三选一）、完工等 [S6] |
| Notice for inspection | 约检通知 | builder 在某阶段完成时须通知 certifier，可书面或口头（Reg s48）[S6] |
| Certificate of inspection | 检查证书 | 检查合格后由检查人员给 builder（Reg s53）；拿到前不得开始下一阶段（s49）[S6] |
| Noncompliance notice | 不合规通知 | certifier 检查不合格时用 approved form 发给 builder，写明哪里不合规（Reg s54）[S6] |
| Infrastructure charges ★ | 基础设施费 | council 按开发类型收取；布里斯班独立住宅金额见 CLAUDE.md 第五节 [S10] |
| QBCC ★ | 昆州建筑委员会 | Queensland Building and Construction Commission，管执照、Home Warranty、缺陷投诉 [S10] |
| Owner builder permit ★ | 业主自建许可 | 工程值超过 $11,000（含 GST）须申请 [S10] |
| Regulated amount | 法定金额门槛 | $3,300 或条例规定的更高金额 [S2]；超过即须执照、书面合同等 |

## 2. 合同付款（Contracts & Payment）

| 英文 | 中文 | 解释（澳洲用法）与出处 |
|---|---|---|
| Domestic building contract ★ | 住宅建造合同 | 实施住宅建造工作的合同；**不包括** builder 与分包商之间的合同（Sch 1B s3(2)(a)）[S2] |
| Domestic building work | 住宅建造工作 | 定义见 Sch 1B s4 [S2] |
| Regulated contract / level 1 / level 2 ★ | 受管制合同 | Sch 1B s5–7 定义，金额不同适用的规定不同 [S2] |
| Building contract (Part 4A) | 建造合同（第 4A 部分） | QBCC Act Part 4A 的 building contract **不含** domestic building contract；builder 与分包商的合同属于这里 [S3][S10] |
| Subcontract (Part 4A) | 分包合同 | 双方都是 building contractor，且分包方承担上游合同的全部或部分工作（s67D）[S3] |
| Building owner | 业主 | 「为其进行住宅建造工作的人」[S2] |
| Resident owner ★ | 自住业主 | 个人，并打算完工时或完工后 6 个月内入住 [S2]；BIF Act 第 3 章不适用于有 resident owner 的住宅合同（s61）[S5] |
| Contract price | 合同价 | 住宅合同中应付的总额，含 builder 代付给他人的款项，但不含业主直接付给他人的接驳费、审批费（Sch 1B s2）[S2]；NHC 中含固定价部分、PC 和 PS 金额，含 GST [S4] |
| Fixed Price Component | 固定价部分 | 合同价中 builder 须为之完成全部工作的金额，PC 和 PS 除外 [S4] |
| Prime cost item (PC item / PC sum) ★ | 暂定材料项 | 签约时尚未选定或价格未知、合同中留有合理供货金额的项目（如洁具、灯具）[S2]；实际超支或节省加减 builder markup（GC 4.8–4.9）[S4] |
| Provisional sum (PS) ★ | 暂定金额 | 对某项服务费用的估计，只适用于 builder 尽合理查询后仍无法给出确定金额的服务，可含材料（Sch 1B s10）[S2]。常见于岩石开挖、土方 |
| PC + PS over 20% ★ | PC/PS 超 20% | PC 和 PS 合计超过合同价 20% 的，builder 开工前须书面说明每项理由，否则无权收款（GC 4.2）[S4] |
| Markup / margin | 加价 / 利润率 | markup 按成本加价，margin 按售价计算利润，两者不同。PC/PS 调整时按合同列明的 markup 加减 [S4] |
| Cost plus contract ★ | 成本加酬金合同 | 签约时即使不计 PC 和 PS 也无法准确算出 builder 应得金额的合同 [S2]；没有 Home Warranty 未完工保障 [S10] |
| Deposit | 定金 | 合同价 ≥$20,000 的上限 5%（Sch 1B s33）[S10] |
| Cooling-off period ★ | 冷静期 | 业主收到签字合同全套和 Consumer Building Guide 后 5 个工作日（s35–38）[S4][S10] |
| Consumer Building Guide ★ | 消费者建房指南 | QBCC 发布，builder 须在业主签约前提供（s18）[S4] |
| Commencement Notice (NHC Form 1) | 开工通知 | builder 开工后 10 个工作日内交业主（GC 17.2、s16）[S4] |
| Business Day ★ | 工作日 | NHC：不是周六、周日，也不是昆州公众假期、特别假日或银行假日 [S4] |
| Finance Date | 融资确认日 | 业主须在该日前给 builder 支付能力的书面证据；未写明的为合同日后 10 个工作日（GC 1.1(k)、5.1）[S4] |
| Starting Date | 开工期限日 | 取合同所写日期、certifier 批准图纸后 10 个工作日、业主完成融资证明后 10 个工作日三者中最晚者 [S4] |
| Progress payment | 进度款 | 合同价的一部分，不含定金 [S2]；BIF Act 中含最终付款和里程碑付款（s64）[S5] |
| Progress claim (NHC Form 3) ★ | 进度款申请 | 住宅合同中 builder 每完成一个阶段提交；须附 Form 4 和相关检查证书（GC 19.1(c)(d)）[S4] |
| Notice of Dispute of Progress Claim (NHC Form 4) ★ | 进度款异议通知 | 业主在收到申请 5 个工作日内用它说明理由（GC 19.1(h)）。注意：给排水的 Form 4 是另一回事（notifiable work 登记）[S4][S10] |
| Base / Frame / Enclosed / Fixing / Practical Completion Stage ★ | 五个付款阶段 | NHC 的付款阶段（Schedule Item 8A Option A）[S4]，定义见第 4、5、13 节 |
| Lock-up (stage) ★ ⚠ | 封闭阶段（俗称） | 行业俗称，外墙、屋面、外门窗装好可上锁。QBCC NHC 不用此词，对应 **Enclosed Stage** [S4]；其他州合同（如维州）用 lock-up 作法定阶段名（⚠ 州差异，条款待证实） |
| Payment claim (BIF Act) | 付款申请 | 书面文件：说明工作、申请金额、要求付款；写有 "invoice" 即视为要求付款（s68）[S5] |
| Payment schedule (BIF Act) ★ | 付款答复表 | 回应付款申请的书面文件：注明对应申请、拟付金额，少付的写明全部理由（s69）；须在合同期限和 15 个工作日中较早者内给出（s76）[S5] |
| Reference date | 申请基准日 | 合同规定可申请进度款的日期；合同未规定的为首次施工当月最后一天及以后每月最后一天（s67）[S5] |
| Supporting statement ★ | 分包付款声明 | 总包向业主提付款申请时须附，声明分包商已付清，或列出未付的分包商、金额和理由（s75(7)(9)）[S5] |
| Due date | 到期日 | 按合同；合同未约定的，付款申请后 10 个工作日（s73）[S5] |
| Pay when paid ★ | 背靠背付款 | 「上游付了才付下游」的条款，无效（s74）[S5] |
| Adjudication ★ | 裁决 | BIF Act 的快速付款争议程序，经 QBCC Adjudication Registry 申请 [S5][S10] |
| New reasons (adjudication) | 新理由 | 裁决答辩中不得加入 payment schedule 没写的扣款理由（s82(4)）[S5] |
| Variation ★ | 变更 | Part 4A：对建造工作的增加或删减 [S3]；住宅合同须先书面、业主书面同意后才能开工（Sch 1B s40）[S2] |
| Variation Document (NHC Form 5) ★ | 变更单 | 须写明描述、请求日期、预计延误、价格变化或计算方法、何时付款或扣减（Sch 1B s41；GC 21.3）[S2][S4] |
| Extension of time (EOT) ★ | 工期延长 | 住宅合同中只能因不可预见且非 builder 可控、业主造成、或合规变更的延误申请；须在知道原因和程度后 10 个工作日内书面提出、业主书面批准（Sch 1B s42）[S2] |
| Extension of Time Claim and Owner's Response (NHC Form 2) ★ | 延期申请及业主答复 | 业主须在 10 个工作日内答复，否则视为有争议（GC 23.4）[S4] |
| Date for Practical Completion | 约定完工日 | 合同 Schedule Item 7 所写或计算的日期，含经批准的延期 [S4] |
| Liquidated damages (LDs) ★ | 约定违约金 | 未按期实际完工时按合同日费率赔付；Schedule 留空的默认 $50/天，只能从 PC 阶段款中扣（GC 24）[S4] |
| Interest on overdue payments | 逾期利息 | NHC：RBA 现金利率目标加 6%（GC 20）[S4] |
| Retention amount | 保留金 | Part 4A：合同价中可暂扣、用于保证整改缺陷或履约的金额（s67C）[S3]；QBCC 住宅合同没有设保留金 [S10] |
| Security | 履约担保 | 银行保函、保险担保或现金形式。分包合同实际完工前保留金加担保合计不超过分包价 5%（s67L），完工后不超过 2.5%（s67N）[S3] |
| Defects liability period (DLP) ★ | 缺陷责任期 | NHC 为实际完工后 12 个月（GC 29.1）[S4]；Part 4A 合同未写明期限的，法定为 12 个月（s67NA）[S3] |
| Set-off | 抵扣 | 用保留金或担保抵扣对方欠款，须在知道权利后 28 天内书面通知（s67J）[S3] |
| Direction (Part 4A) | 指示 | 含指令、批准、通知、要求等；口头指示后 3 个工作日内须补书面（s67I）[S3] |
| Substantial breach | 重大违约 | NHC GC 26.3（业主）和 26.4（builder）列举，是发违约通知、终止合同的前提 [S4] |
| Statutory warranties | 法定保证 | Sch 1B s19 规定写入受管制合同的保证，如工艺合格、材料合适 [S2][S4] |

## 3. 场地土方（Site & Earthworks）

| 英文 | 中文 | 解释（澳洲用法）与出处 |
|---|---|---|
| Site | 场地 | 「地块上建筑所在或将要建造的部分」[S1] |
| Allotment / lot | 地块 | 产权地块；RP 号、lot/plan 号标识。通用 |
| Sitework | 场地工程 | 「场地上或周边的工作，包括土方，为建筑的建造、改建、拆除或移除做准备或与之相关」[S1] |
| Foundation | 地基（土） | NCC：「支承建筑的地面（土层）」[S1]。注意与 footing（基础构件）区分 |
| Foundations data ★ | 地基资料 | builder 设计基础和估算基础费用所需的场地资料（Sch 1B s8）[S2]；资料不足导致的额外基础费，builder 一般不能向业主追加（GC 21.11）[S4] |
| Site classification (A, S, M, H1, H2, E, P) ★ | 场地分类 | 按 AS 2870 的土壤反应性分类，由岩土工程师出报告；Housing Provisions Section 4 只适用于 A、S、M 类 [S10] |
| Geotechnical report / soil test | 岩土报告 / 土壤测试 | 给出场地分类和地基承载力。通用 |
| Contour survey / detail survey | 地形测量 | 等高线、现有构筑物、树木、标高。通用 |
| Identification survey ★ | 界址确认测量 | 由注册测量师确认边界位置。通用 |
| Set-out ★ | 放线 | 在地面标出建筑位置和标高；NHC 把 "set out of the Works and survey if necessary" 列为合同工作内容（GC 1.1(bb)(iv)）[S4] |
| Boundary peg | 界桩 | 测量师钉的边界标记。通用 |
| Reduced level (RL) / benchmark ★ | 标高 / 水准点 | 澳洲图纸标高写作 RL，基于 AHD（澳洲高程基准）或场地假定水准点。通用 |
| Finished ground level (FGL) | 完成地面标高 | 「施工和园林完成后基础旁的地面标高」[S1] |
| Cut and fill | 挖填方 | 坡地平整。通用 |
| Site cut ★ | 场地开挖 | 住宅 slab 前把场地挖平。通用 |
| Batter | 放坡 | 挖填方边坡。通用 |
| Controlled fill | 受控填土 | 「分层铺放、用压实设备（如振动板）在规定含水量范围内压实到规定密实度的材料」[S1] |
| Rolled fill | 碾压填土 | 「分层铺放、用挖掘机反复碾压压实的材料」[S1] |
| Spoil | 弃土 | 挖出的土。通用 |
