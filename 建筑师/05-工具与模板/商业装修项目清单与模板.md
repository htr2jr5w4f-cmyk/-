# 商业装修项目清单与模板

适用州：QLD（布里斯班）｜资料核对日期：2026-11-21｜状态：部分待证实（法定项已核对原文并标【法定】和条款号；其余为管理清单和行业惯例）

## 摘要
本文是商业装修（办公、零售、餐饮、诊所）可以直接复制填写的五套清单：①接项目前的资料清单；②审批清单；③工序进度模板（工序、前置关系、关键路径）；④现场管理清单；⑤交付文件清单。法定要求标【法定】并注明条款；依据和解释见 `01-法规标准/商业装修法规与审批.md` 和 `02-建造流程/商业装修施工工序与工法.md`。
对省钱的用处：开工前把资料和审批一次收齐，可以避免最常见的停工和返工；进度模板把消防、certification、食品执照等「开业前最后一关」放到关键路径上提前安排，避免租金在等证期间白付。

## 4. 现场管理清单

### 4.1 开工前（一次性）
- ☐ 施工计划（工作时间、货梯时段、材料路线、垃圾路线）提交楼宇管理处
- ☐ 合同价 ≥ $250,000：指定 principal contractor，编 WHS management plan【法定】（WHS Reg s 292、293）
- ☐ SWMS 登记：高处 >2 m、扰动石棉、带电设施附近、需临时支撑的结构改动、移动机械区域等 high risk construction work【法定】（s 291）
- ☐ 石棉登记册已取得并交底【法定】（s 450）
- ☐ 分包执照核对（QBCC 各工种、fire protection、mechanical services、电工执照）
- ☐ 保险证明（contract works、public liability、workers' compensation）
- ☐ 疏散计划：施工人员纳入楼宇 fire and evacuation plan；不得堵塞疏散路线和 final exit 外 2 m【法定】（BFSR s 7、8）
- ☐ 施工区围挡、防尘隔断、公共区保护、回风口防尘

### 4.2 每日
- ☐ 签到、安全交底（toolbox talk）
- ☐ 消防隔离：开始时登记、结束时恢复并确认（行业惯例）
- ☐ Hot works permit：作业前检查、作业后巡查
- ☐ 疏散通道、出口畅通；有人在内时疏散门不上锁【法定】（BFSR s 11）
- ☐ 货梯预约和保护；公共区清洁
- ☐ 施工日志：人员、工序、天气、事故、访客、指令

### 4.3 每周
- ☐ 进度会（对照第 3 节模板，更新关键路径）
- ☐ RFI、变更（variation）、NCR 登记更新
- ☐ 与楼宇管理处、landlord 代表沟通会
- ☐ 工地检查（安全、质量、清洁）

### 4.4 质量检查点（ITP 摘要）
| 节点 | 检查内容 | 签字 |
|---|---|---|
| 放线 | 门洞、疏散宽度（D2D8 ≥1 m 一般）、门宽（D2D9 ≥750 mm 一般）、开启方向（D3D25） | |
| 龙骨 | 间距 ≤600 mm、track 固定 ≤600 mm 且距端 ≤100 mm、防火墙到板底、deflection head（Red Book 3） | |
| 隐蔽验收 | 机电、加固、隔声棉、防火封堵和标识 | |
| 吊顶封顶前 | 喷淋、风管、电缆、检修口 | |
| 饰面材料 | Spec 7 测试报告（墙顶 Group、地面 CHF） | |
| 机电 | J7 照明功率、应急照明覆盖、空调平衡 | |
| 消防 | 测试记录、设施清单和位置图 | |
| 完成面 | QBCC Standards and Tolerances Guide（1.5 m、漫射光） | |
