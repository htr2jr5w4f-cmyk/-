# 合同签约前检查清单

适用州：QLD｜资料核对日期：2026-11-20｜状态：部分待证实

## 摘要
在昆州，住宅建造合同受 Queensland Building and Construction Commission Act 1991 (Qld)（以下简称 QBCC Act）Schedule 1B 约束。这份清单把签约前必须核对的事项逐条列出：执照、定金、冷静期、home warranty、PC/PS、variations、进度款、延期（EOT）、practical completion 与 defects liability。每项都附 QBCC 或 legislation.qld.gov.au 的来源链接。签约前把合同交给熟悉建筑合同的律师审阅；需要注意，审阅合同的方式可能影响冷静期权利（见第 3 项）。

**用法**：逐项打勾，并在「合同条款位置」一栏写下合同中对应条款的编号，方便日后查找。

---

## 1. 执照核查

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | 在 QBCC 登记册（Search a register）按执照号、姓名或公司名查询 builder，点「licensee's full history」查看完整历史 | | [S1][S2] |
| ☐ | 执照类别覆盖本工程（新建住宅）；如果是公司签约，个人和公司的执照都要查 | | [S2] |
| ☐ | 查有无 infringement notice、整改指令（direction to rectify）、纪律处分 | | [S2] |
| ☐ | 查不到记录时：不要签约，联系 QBCC（139 333） | | [S1] |
| ☐ | 查 QBCC 的 excluded individuals 名单 | | [S1] |
| ☐ | 合同上的执照号、公司名、ABN 与登记册一致 | | [S3] |

## 2. 合同形式与定金

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | 合同为书面，双方签字并注明日期（超过 $3,300 的住宅建造工作须书面合同，并符合 Schedule 1B） | | [S4][S10] |
| ☐ | 合同价 ≥ $20,000 时，builder 在签约前给了 QBCC Consumer Building Guide | | [S5][S6] |
| ☐ | **定金不超过上限**：合同价 ≥ $20,000 时上限 5%；$3,301–$19,999 时 10%；≤ $3,300 时 20%（场外定制或预制超过合同价 50% 的例外，按 QBCC 页面核对）。超付定金可能影响 home warranty 对定金退款的保障 | | [S5] |
| ☐ | 开工前，除定金外不支付任何进度款 | | [S7][S10] |
| ☐ | 合同类型确认：QBCC New Home Construction Contract、HIA、Master Builders 或 builder 自拟合同，记下版本号和日期 | | [S3] |

## 3. 冷静期（cooling-off）

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | 冷静期一般为 **5 个工作日**（QBCC Act Schedule 1B s35） | | [S8][S10] |
| ☐ | 冷静期从收到**完整签字合同副本**（含图纸和规格）的次日起算；合同价 ≥ $20,000 时还要收到 Consumer Building Guide | | [S8] |
| ☐ | 退出方式：给 builder 书面签字通知，注明依据 Schedule 1B s35 退出 | | [S8] |
| ☐ | 退出成本：通常为 $100 加 builder 退出前合理发生的实际支出 | | [S8] |
| ☐ | ⚠ 不享有冷静期的情形：此前就同一场地签过条款基本相同的合同；或签约前已取得执业律师的正式法律意见（或告诉过 builder 你已取得）。是否先找律师，要权衡这一点 | | [S8] |

## 4. Home warranty（Queensland Home Warranty Scheme）

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | 超过 $3,300 的住宅建造工作一般须投保 Queensland Home Warranty Scheme | | [S9] |
| ☐ | 保费由持牌总承包商向业主收取后交给 QBCC，期限为签约后 10 个工作日内或开工前，以较早者为准 | | [S11] |
| ☐ | 收到 QBCC 的保险证明（Certificate / notice of cover）。没收到时，联系 QBCC 或做 insurance search 核实 | | [S11] |
| ☐ | 了解保障期：结构缺陷 6 年 6 个月（工期超过 6 个月时可延长）；非结构缺陷 6 个月，须在实质完工后 7 个月内索赔（以 QBCC 现行页面为准） | | [S12] |

## 5. PC（prime cost）/ PS（provisional sum）

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | 每个 PC/PS 项都有描述、成本构成（含 builder margin）和含 GST 金额 | | [S13] |
| ☐ | PC/PS 合计（含 margin）超过合同价 20% 时，builder 须在开工前书面说明每项列为 PC/PS 的理由，否则不能就此请款（QBCC NHC 一般条款；以所签版本为准） | | [S13] |
| ☐ | 用『成本估算表.xlsx → 报价比较』算 PC/PS 占比，并判断额度是否现实（例如瓷砖 PC 是否够你想要的产品） | | — |
| ☐ | 了解超支和节省如何结算：实际超出 allowance 时，业主付差额加 margin；低于时，按合同扣减 | | [S13] |
| ☐ | 自己要选的 PC 产品，在合同规定时间前书面通知 builder，避免延误 | | [S13] |

## 6. Variations（变更）

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | 合同写明：变更须书面提出，并在变更工作开始前由业主书面同意 | | [S14][S10] |
| ☐ | 书面变更须写明：变更内容、请求日期、预计延误、价格变化或计算方法 | | [S14] |
| ☐ | Builder 不得在变更工作开始前要求支付变更款 | | [S14] |
| ☐ | 合同里的变更单格式（QBCC 合同为 Form 4 或 Form 5，视合同类型而定）——使用本目录的《变更单variation模板.md》 | | [S14] |
| ☐ | Builder 加收变更 margin 的比例写在合同里 | | 待证实（各合同不同）|

## 7. 进度款

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | 阶段与比例写清。QBCC NHC Option A 为：定金 5%、Base 15%、Frame 20%、Enclosed 25%、Fixing 20%、Practical Completion 15% | | [S3] |
| ☐ | 每个阶段的定义（例如 Enclosed = 外墙覆面已固定、屋面已固定）写在合同里 | | [S7] |
| ☐ | 付款期限与争议程序：QBCC 模板合同要求业主在收到请款后 5 个工作日内支付无争议部分，或用书面争议通知说明理由 | | [S3] |
| ☐ | 进度款只能对应已完成的工作；不接受「提前付款换折扣」 | | [S10] |
| ☐ | 把阶段和比例录入『成本估算表.xlsx → 付款进度』 | | — |

## 8. 工期与延期（EOT）

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | 合同写明开工日期和 practical completion 日期（或工期天数），以及其中已预留的雨天、周末和公众假期 | | [S7] |
| ☐ | EOT 只限：不可合理预见且非 builder 可控的延误、业主造成的延误、符合 Schedule 1B s40 并经业主书面同意的变更造成的延误 | | [S15][S10] |
| ☐ | Builder 须在知道（或应当知道）延误后 10 个工作日内书面提出 EOT；业主须在 10 个工作日内书面同意或说明拒绝理由（以合同为准） | | [S15] |
| ☐ | Liquidated damages（延误违约金）每日金额已填写，不是空白或 $0 | | [S15] |

## 9. Practical completion 与 defects liability

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | Practical completion 的定义：按合同、图纸、规格和全部法定要求完成，只剩不会不合理影响入住的轻微缺陷或遗漏（Schedule 1B s1） | | [S3][S10] |
| ☐ | Builder 须提前 5 个工作日书面通知预计的 practical completion 日期（QBCC NHC） | | [S7] |
| ☐ | PC 请款须附 Defects Document 和 Certificate of Practical Completion（QBCC 模板 Form 6、Form 7 或同类文件） | | [S3] |
| ☐ | Defects liability period：QBCC 资料显示一般为 practical completion 起 12 个月。业主须在期限内书面通知缺陷 | | [S16] |
| ☐ | 法定保修（statutory warranties）不因合同沉默而消失：结构缺陷 6 年、其他 1 年（QBCC 资料表述，以现行法律为准） | | [S16] |
| ☐ | Final certificate（Form 21）在最后付款前交给业主（QBCC 建议；部分合同把它列为强制条件） | | [S17] |

## 10. 签约当天

- ☐ 拿到完整签字副本（合同、图纸、规格、PC/PS 明细、Consumer Building Guide）
- ☐ 记下冷静期截止日（5 个工作日，不含周末和昆州公众假期）[S8]
- ☐ 定金按合同上限支付，并保留付款凭证 [S5]
- ☐ 10 个工作日内跟进 home warranty 证明 [S11]
