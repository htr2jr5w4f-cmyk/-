# 合同签约前检查清单

适用州：QLD｜资料核对日期：2026-11-20｜状态：已核实（2026-11-20 对照 QBCC Act 原文、QBCC 2023 年 7 月版合同和 QBCC 官网核对；个别项另有标注）

## 摘要
在昆州，住宅建造合同受 Queensland Building and Construction Commission Act 1991 (Qld)（以下简称 QBCC Act）Schedule 1B 约束。这份清单把签约前必须核对的事项逐条列出：执照、定金、冷静期、home warranty、PC/PS、variations、进度款、延期（EOT）、practical completion 与 defects liability。每项都附 QBCC 或 legislation.qld.gov.au 的来源链接。签约前把合同交给熟悉建筑合同的律师审阅；需要注意，审阅合同的方式可能影响冷静期权利（见第 3 项）。

**用法**：逐项打勾，并在「合同条款位置」一栏写下合同中对应条款的编号，方便日后查找。

## 2. 合同形式与定金

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | 合同为书面，双方签字并注明日期。合同价超过 $3,300 即为 regulated contract；不满足书面、签字、注明日期这一条的合同不生效（Sch 1B s13(5)、s14(10)）| | [S4][S10] |
| ☐ | Level 2 合同（≥ $20,000）的必备内容（Sch 1B s14）：双方名称（builder 名称与执照一致）、执照号、工作描述、图纸规格（含满足开发审批所需的全部图纸）、合同价或计算方法、开工日期、practical completion 日期、法定保修声明、醒目的冷静期提示；固定总价须写在合同 schedule 第一页显眼位置 | | [S10] |
| ☐ | 签约后 5 个工作日内收到完整签字合同副本（含图纸和规格）（Sch 1B s15）| | [S10] |
| ☐ | 合同价 ≥ $20,000 时，builder 在业主签约**前**给了 QBCC Consumer Building Guide（Sch 1B s18）| | [S6][S10] |
| ☐ | **定金不超过上限**（Sch 1B s33；QBCC Regulation 2018 s45 规定 level 2 门槛为 $20,000）：合同价 ≥ $20,000 时 5%；$3,301–$19,999 时 10%；场外工作超过合同价 50% 时最多 20%。≤ $3,300 的工作不属于 regulated contract，QBCC 指引的上限是 20%。超付的部分，在 home warranty 退定金索赔中无法追回 | | [S5][S10][S18] |
| ☐ | **定金已包含 home warranty 保费**：s33(3) 规定开工前支付的保险保费也算定金；QBCC 也说明保费应包含在定金之内。Builder 不应在 5% 之外另收保费 | | [S10][S11] |
| ☐ | 开工前，除定金外不支付任何款项；进度款须与现场工作进度直接相关且相称（Sch 1B s34；QBCC 举例：现场完成至少 50% 前，不能收到合同价的 50%（含定金））| | [S5][S10] |
| ☐ | 合同类型确认：QBCC New Home Construction Contract、HIA、Master Builders 或 builder 自拟合同，记下版本号和日期 | | [S3] |

## 3. 冷静期（cooling-off）

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | 冷静期为 **5 个工作日**（Sch 1B s35）。工作日不含周六、周日和昆州公众、特别、银行假日（NHC 合同定义）| | [S7][S8][S10] |
| ☐ | 冷静期从收到签字合同副本的次日起算（s35(1)）；level 2 合同如果签约前没收到 Consumer Building Guide，则从收到 Guide 的次日起算（s35(2)）。QBCC 说明：builder 晚交这些文件，冷静期就相应延后 | | [S8][S10] |
| ☐ | 退出方式：给 builder 书面签字的 withdrawal notice，写明退出合同及所依据的条款（s35），亲手交付、留在合同地址或按合同送达方式送达（s37）| | [S8][S10] |
| ☐ | 退出成本：builder 退出前合理发生的实际支出；按 s35(1) 退出的再加 $100（s38）| | [S8][S10] |
| ☐ | ⚠ 不享有冷静期的情形（s36）：此前就同一住宅或土地签过条款和服务基本相同的合同；或签约前已取得执业律师的正式（付费）法律意见，或告诉过 builder 你已取得。是否先找律师，要权衡这一点 | | [S8][S10] |

## 4. Home warranty（Queensland Home Warranty Scheme）

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | 超过 $3,300（含材料、人工和 GST）的住宅建造工作须投保 Queensland Home Warranty Scheme；由 builder 代业主投保 | | [S9][S11] |
| ☐ | 保费由持牌总承包商向业主收取后交给 QBCC，期限为签约后 10 个工作日内或开工前，以较早者为准（QBCC Act s68B(2)）| | [S10][S11] |
| ☐ | 收到 QBCC 的保险证明（Certificate / notice of cover）。没收到时，联系 QBCC 或做 insurance search 核实 | | [S11] |
| ☐ | 了解保障期：结构缺陷须在保障开始日起 6 年 6 个月内发现，并在发现后 3 个月内索赔（工期超过 6 个月时保障期可延长）；非结构缺陷须在实质完工后 6 个月内发现，并在实质完工后 7 个月内索赔。保障开始日为交保费、签约、开工三者中最早的一天 | | [S11][S12] |

## 5. PC（prime cost）/ PS（provisional sum）

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | 每个 PC/PS 项都有描述、成本构成（含 builder margin）和含 GST 金额 | | [S13] |
| ☐ | PC/PS 合计（含 markup）超过合同价 20% 时，builder 须在开工前书面说明每项列为 PC/PS 的理由；未说明前，builder 无权收取**任何**合同款项（QBCC NHC 一般条款 Condition 4.2，2023 年 7 月版）| | [S7] |
| ☐ | 用『成本估算表.xlsx → 报价比较』算 PC/PS 占比，并判断额度是否现实（例如瓷砖 PC 是否够你想要的产品） | | — |
| ☐ | 了解超支和节省如何结算：实际超出估算时，业主付差额加 markup；低于估算时，builder 从合同价中扣除差额加 markup（NHC Condition 4.8、4.9）。Builder 保证 PC/PS 是以合理的谨慎和技能、根据签约时可合理获得的信息（含场地性质和位置）计算的（Sch 1B s26(2)）| | [S7][S10] |
| ☐ | 自己要选的 PC 产品，在合同规定时间前书面通知 builder，避免延误 | | [S13] |

## 6. Variations（变更）

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | 合同写明：变更须书面；业主书面同意前，builder 不得开始变更工作（Sch 1B s40(5)）；builder 须在双方同意后 5 个工作日内、或变更工作开始前（以较早者为准）把书面变更交给业主（s40(2)）| | [S14][S10] |
| ☐ | 书面变更须（Sch 1B s41(2)）：清楚可读；描述变更；写明请求日期；有延误时写明 builder 的合理预计延误期；写明价格变化或计算方法；价格增加时写明何时支付；价格减少时写明何时扣减 | | [S10][S14] |
| ☐ | 变更增加的价款不得在变更工作开始前要求支付（Sch 1B s41(3)）| | [S10][S14] |
| ☐ | 合同里的变更单格式：QBCC New Home Construction Contract 用 **Form 5 – Variation Document**（Condition 21.2）；其他 QBCC 合同可能是 Form 4，QBCC 页面称「通常是 Form 4 或 Form 5，视合同类型而定」。可用本目录的《变更单variation模板.md》核对漏项 | | [S7][S14] |
| ☐ | Builder 加收变更 margin 的比例写在合同里 | | 待证实（各合同不同）|

## 7. 进度款

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | 阶段与比例写清。QBCC NHC Schedule Item 8A Option A 为：定金 5%、Base 15%（不含定金）、Frame 20%、Enclosed 25%、Fixing 20%、Practical Completion 15%；Option B 由双方自定 | | [S3] |
| ☐ | 每个阶段的定义写在合同里。NHC 一般条款第 1 条例子：Enclosed = 外墙覆面已固定，屋面已固定（soffit 可未完成），结构楼板已铺，外门外窗已安装（可临时）| | [S7] |
| ☐ | 付款期限与争议程序：NHC Condition 19 要求业主在收到请款（Form 3 Progress Claim）后 5 个工作日内支付无争议部分，或用 Form 4 Notice of Dispute of Progress Claim 说明理由；PC 阶段款在 Form 7 条件满足后立即支付 | | [S7] |
| ☐ | 进度款只能对应已完成的工作；不接受「提前付款换折扣」 | | [S10] |
| ☐ | 把阶段和比例录入『成本估算表.xlsx → 付款进度』 | | — |

## 8. 工期与延期（EOT）

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | 合同写明开工日期和 practical completion 日期（或工期天数），以及其中已预留的雨天、周末和公众假期 | | [S7] |
| ☐ | EOT 只限（Sch 1B s42(1)）：不可合理预见且非 builder 合理可控的延误；业主造成的延误；符合 s40 的变更造成的延误 | | [S10][S15] |
| ☐ | Builder 须在知道（或应当知道）延误原因和程度后 10 个工作日内书面提出 EOT，并须业主书面批准（s42(1)）；批准后 5 个工作日内 builder 须给业主签字副本（s42(3)）。NHC 合同还要求业主在收到 Form 2 后 10 个工作日内书面同意或说明拒绝理由，否则视为有争议（Condition 23.4）| | [S7][S10] |
| ☐ | Liquidated damages（延误违约金）每日金额已填写，不是空白或 $0 | | [S15] |

## 9. Practical completion 与 defects liability

| ☐ | 检查项 | 合同条款位置 | 来源 |
|---|---|---|---|
| ☐ | Practical completion 的定义：按合同（含图纸、规格）和全部法定要求完成，只剩不会不合理影响入住的轻微缺陷或遗漏（Sch 1B s1；NHC 一般条款第 1 条）| | [S7][S10] |
| ☐ | Builder 须提前 5 个工作日书面通知预计的 practical completion 日期（NHC Condition 28.1）| | [S7] |
| ☐ | PC 请款须附 Form 6 Defects Document 和 Form 7 Certificate of Practical Completion（或同类文件）（NHC Condition 19、28）| | [S7] |
| ☐ | Defects liability period：NHC Condition 29.1 为 practical completion 日起 12 个月；业主发现后须尽快书面通知（29.2），builder 须在通知后 20 个工作日内整改（29.3）。QBCC 指南也说一般为 12 个月 | | [S7][S15][S16] |
| ☐ | 法定保修（statutory warranties）的诉讼期限（Sch 1B s29）：结构缺陷 6 年、其他 1 年，从工程完工起算；在期限最后 6 个月内才显现的违约，可在期限届满后再延 6 个月起诉 | | [S10] |
| ☐ | Final certificate（Form 21）在最后付款前交给业主（QBCC 建议）。由 builder 委托 certifier 的，builder 须尽快把每份检查证书副本交给业主（Sch 1B s17）| | [S10][S17] |

## 10. 签约当天

- ☐ 拿到完整签字副本（合同、图纸、规格、PC/PS 明细、Consumer Building Guide）
- ☐ 记下冷静期截止日（5 个工作日，不含周末和昆州公众、特别、银行假日）[S7][S8]
- ☐ 定金（含 home warranty 保费）不超过上限，并保留付款凭证 [S5][S10]
- ☐ 10 个工作日内跟进 home warranty 证明 [S11]

## 核对记录（2026-11-20 第二轮，对照官方原文）
- [S10] 链接：原写「act-1991-098 待证实」，核对：该编号确为 Queensland Building and Construction Commission Act 1991，已改为 whole-Act 链接。
- 定金：原写「≤ $3,300 时 20%」与 5%/10% 并列为法定上限，核对原文：Sch 1B s33 只规定 level 1 合同 10%、level 2 合同 5%、场外工作 >50% 时 20%；≤ $3,300 不属 regulated contract，20% 是 QBCC 指引数字。$20,000 门槛来自 QBCC Regulation 2018 s45（≥ $20,000）。
- 原文没有写到、本次新增：定金包含开工前支付的保险保费（s33(3)）。
- 冷静期：5 个工作日核实（s35）。原写「从收到完整签字合同副本（含图纸规格）及 Guide 的次日起算」，核对原文：s35(1) 从收到签字合同副本的次日起算；level 2 合同如果签约前没收到 Guide，则从收到 Guide 的次日起算（s35(2)）。「含图纸规格」是 QBCC 页面表述。退出成本：原写「通常为 $100 加支出」，核对原文：$100 只适用于按 s35(1) 退出的情形（s38(8)）。
- Home warranty 交费时限：10 个工作日或开工前（以较早者为准）核实，条款为 QBCC Act s68B(2)。保障期：原写「结构缺陷 6 年 6 个月」，核对 QBCC 页面为「6 年 6 个月内发现 + 发现后 3 个月内索赔」，已补全。
- Variation：书面要求核实（s40）。原写内容少了 s41(2)(f)(g)，即「增加时写明何时支付、减少时写明何时扣减」，已补。原写「变更单为 Form 4 或 Form 5」，核对 NHC 合同：Form 5 = Variation Document，Form 4 = Notice of Dispute of Progress Claim。
- EOT：s42 核实；新增 s42(3)「批准后 5 个工作日内给签字副本」。
- PC/PS 20%：核实为 NHC Condition 4.2，新增「未说明前无权收取任何合同款项」。
- Defects liability：原写「QBCC 资料显示一般 12 个月」，核对 NHC Condition 29.1 为 12 个月，29.3 为 20 个工作日内整改。法定保修：原写「QBCC 资料表述 6 年/1 年」，核对原文为 Sch 1B s29(3)，并补充最后 6 个月可延 6 个月。
