# 看图出方案工作流程

适用州：QLD（规范部分为全国 NCC）｜资料核对日期：2026-11-21｜状态：部分待证实

## 摘要
本文是拿到一套澳洲图纸（住宅 Class 1a 或高层 Class 2/5/7a 等）后的标准工作流程：先核对图纸是否齐全、列出要问的问题，再系统读图，最后产出 5 部分方案：施工步骤、用料（工程量）、注意事项、工期、工地管理。每部分都写明「从图纸哪里读出来、怎么推出来」。配套工具：`工程量计算表.xlsx`、`施工进度计划模板.xlsx`、`住宅施工工序与用料总表.md`、`看图出方案示例.md`。对省钱的作用：开工前把图纸缺项和冲突问清楚，是减少 variation（变更）和返工的最便宜办法。
本文按 NCC 2022 编写（昆州现行版本；NCC 2025 在昆州的实施日期见 `01-法规标准/NCC现行版本与住宅要求.md`）。

---

## 第 0 步：图纸缺什么就要问什么（先做这一步）

拿到图纸后，先不要算量。先对照下表逐项打勾，缺的、看不清的、互相矛盾的，全部写进「问题清单（RFI）」，发给业主 / 设计师 / 工程师书面回复。

| ☐ | 缺什么或看到什么 | 要问谁 | 要问的问题 | 为什么要问 |
|---|---|---|---|---|
| ☐ | 没有土壤报告（site classification） | 业主 / 岩土工程师 | 场地分类是 A / S / M / H1 / H2 / E / P 哪一类？有没有填土？ | 基础设计依据 AS 2870；NCC Housing Provisions Section 4 只适用于 Class A、S、M 场地等条件 [S2] |
| ☐ | 没有测量图（contour / detail survey） | 测量师 | 现状标高、AHD 基准、边界、现有管线和树木位置？ | 定 FFL（完成地面标高）、算挖填方 |
| ☐ | 结构图没有 general notes（结构说明） | 结构工程师（RPEQ） | 混凝土强度、保护层、钢筋等级、搭接、风等级、设计荷载？ | 没有这些无法订料，也无法通过检查 |
| ☐ | 没有风等级（wind classification，如 N2/N3） | 结构工程师 / 设计师 | 风等级？ | 框架、屋面固定、门窗等级都取决于它 [S2] |
| ☐ | 没有能效报告（NatHERS / Whole of Home） | 能效评估师 | 保温 R 值、窗户 U 值 / SHGC、天花灯具、遮阳等要求？ | 这些要求会改变用料，必须写进采购清单 |
| ☐ | 没有水力图（hydraulic） | 水力设计 / 持牌水管工 | 污水接驳点、雨水排放点、热水系统、管径？ | 决定地下管预埋（浇 slab 之前） |
| ☐ | 没有电气图 | 电工 / 设计师 | 配电箱位置、回路、烟雾报警器位置（互联光电式）？ | 粗装必须在封板前完成 |
| ☐ | 没有 BA（building approval）文件和条件 | building certifier | 审批编号、审批条件、要求的检查阶段？ | 审批写明的检查阶段是法定检查节点之一 [S8] |
| ☐ | 门窗表缺尺寸或缺性能等级 | 设计师 / 门窗厂 | 尺寸、开启方式、玻璃类型、风压等级？ | 外墙门窗按 AS 2047，玻璃按 AS 1288 [S6] |
| ☐ | 没有装修表（finishes schedule） | 业主 / 设计师 | 地面、墙面、天花用什么材料？哪些是 PC / PS 项？ | 影响瓷砖、防水、涂料的数量 |
| ☐ | 建筑图与结构图尺寸 / 标高不一致 | 设计师 + 工程师 | 以哪张为准？ | 不问清楚就施工，返工费用归属会有争议 |
| ☐ | 图纸版本（revision）不一致 | 设计师 | 哪一版是「施工版（for construction）」？ | 只能按审批版和施工版施工 |
| ☐ | 地块有 overlay（洪水、斜坡、bushfire 等） | 设计师 / council | 最低地板标高？是否需要按 AS 3959 建造？ | 影响基础、标高和外墙材料；AS 3959 为 NCC 引用标准 [S7] |
| ☐ | 高层：缺消防工程报告、立面工程资料、岩土报告、基坑支护设计、机电设计 | 各专业顾问 | 结构体系、桩型、支护方式、降水要求、消防系统清单？ | 高层的施工步骤和工期都由这些决定 |

> 图纸不全时的做法：缺的部分在方案里标「待图纸」，用假设值先算，并在方案首页列出全部假设。不要把假设当成事实写进合同或报价。

## 第 1 步：图纸清单核对

| 图纸 / 文件 | 住宅 | 高层 | 从中读出什么 |
|---|---|---|---|
| 建筑图（平面、立面、剖面、详图、门窗表、装修表） | 必需 | 必需 | 面积、墙长、高度、开洞、做法 |
| 结构图（基础、楼板、框架、屋架、general notes） | 必需 | 必需 | 构件尺寸、配筋、混凝土等级、连接 |
| 水力图（给水、污水、雨水、热水） | 必需 | 必需（含消防给水） | 管线走向、预埋位置、接驳点 |
| 电气图 | 必需 | 必需（含应急照明、消防报警） | 回路、配电、预埋 |
| 能效报告（NatHERS 证书和图纸标注） | 必需 | Section J 报告 | 保温、玻璃、遮阳、设备要求 |
| 土壤报告（site classification） | 必需 | 岩土勘察报告 | 场地分类、承载力、地下水 |
| 测量图（detail / contour survey） | 必需 | 必需 | 标高、边界、现状 |
| BA 文件（审批决定、审批图、条件） | 必需 | 必需（DA 条件 + BA） | 法定检查阶段、条件 |
| 消防工程报告 / 立面 / 机电 / 电梯 / 基坑支护设计 | 一般不需要 | 必需 | 各系统范围、施工顺序要求 |

## 第 2 步：读图要点

| 读什么 | 在哪里看 | 读出来干什么 |
|---|---|---|
| 图例（legend）和符号 | 每张图的图例栏、首页 | 弄懂墙体类型、材料填充、管线符号，避免看错 |
| 比例（scale） | 图签栏 | 量尺寸只用标注尺寸；只有缺标注时才按比例量，并标「按比例量取，待确认」 |
| 标高 RL / FFL / AHD | 剖面、立面、场地图 | 算挖填方、地板高度、层高、楼梯级数 |
| 轴线（grid） | 平面、结构图 | 高层按轴线分区算量、排流水段 |
| 剖面（section） | 建筑和结构剖面 | 墙高、屋面坡度、板厚、构造层次 |
| 详图索引（detail callout） | 平面上的圆圈编号 | 找到对应详图，读做法和材料 |
| 结构说明（general notes） | 结构图第一页 | 混凝土强度等级、钢筋保护层、搭接、钢材和木材等级、施工要求、检查要求 |
| 门窗表（window / door schedule） | 建筑图 | 洞口尺寸和数量（外墙扣减面积）、玻璃要求 |
| 装修表（finishes schedule） | 建筑图 / 室内设计 | 每个房间的地面、墙面、天花材料，算瓷砖、涂料、防水 |
| 图签和版本 | 每张图 | 确认是否为审批版 / 施工版 |

读图顺序建议：图签和版本 → 结构说明 → 场地图和测量图 → 平面 → 剖面和立面 → 详图 → 门窗表和装修表 → 水电和能效。边读边在图上标问题，统一写进第 0 步的问题清单。

## 第 3 步：产出 5 部分方案（每部分怎么从图纸推出来）

### 3.1 施工步骤
- **怎么推**：按「地下 → 地上 → 封闭 → 内部 → 收尾」排序；每一层构件找到图纸上的做法，再对应标准。
- 住宅：工序清单和每步依据见 `住宅施工工序与用料总表.md`。
- 必须标出**法定检查节点**。昆州 single detached class 1a 新建住宅的法定检查阶段（Building Regulation 2021 s44(1)(b)）：开挖后、浇筑基础 / slab 混凝土前；基础模板和钢筋就位后、浇筑前；slab 模板和钢筋就位后、浇筑前；框架阶段（按 bracing 是否由覆面板构成，在覆面前或覆面后检查）；采用配筋砌体时灌芯前；全部完工时 [S8]。另外 BA 写明的检查阶段也是法定阶段 [S8]。
- class 1a 的开挖阶段、基础 / slab 浇筑前阶段和最终阶段，只能由 building certifier 签发检查证书（s46）[S8]。
- 高层（Class 2 等）没有 s44(1)(b) 那样的固定清单，法定检查阶段以 BA 中写明的为准 [S8]；结构、消防、机电的专项检查和见证点按各专业顾问的检查与试验计划（ITP）执行。

### 3.2 用料（工程量）
- **怎么推**：每个工程量 = 图纸几何尺寸 × 构造做法；数量 → 加损耗 → 按包装单位向上取整。用 `工程量计算表.xlsx`。
- 尺寸来源：面积和墙长看平面；高度看剖面；板厚、梁尺寸、配筋看结构图；门窗扣减看门窗表；瓷砖和涂料范围看装修表。
- 规格来源：结构图 general notes（混凝土等级、钢筋、钢网型号）、NCC 引用标准、能效报告（保温 R 值）。
- 损耗系数和包装单位**向供应商要书面数据**，或按规范 / 制造商安装说明填写，不要凭印象。

### 3.3 注意事项
- **怎么推**：每道工序对照三类：①规范硬性要求（例如防潮膜 0.2 mm、搭接不少于 200 mm、保护层、湿区地面坡度不小于 1:80 等，见 [S1][S3]）；②图纸上的特殊做法（详图）；③WHS 风险（高处作业、开挖、吊装、混凝土泵送等）。
- WHS：工程造价 $250,000 及以上的为「construction project」，须有 principal contractor 并编制 WHS management plan（WHS Regulation 2011 (Qld) s292、s293、s309）[S9]；高风险施工作业须有 SWMS（s291、s299）[S9]；工人须完成一般施工入职培训（s316）[S9]。

### 3.4 工期
- **怎么推**：先列工序和逻辑关系（紧前工序），再按工程量 ÷ 班组产量估工期，最后排网络。用 `施工进度计划模板.xlsx`。
- 产量（每天能做多少）要向分包商要，或用自己过往项目记录；本知识库不提供未经来源的产量数字。
- 必须把**法定检查等待时间**、混凝土养护（Housing Provisions 要求 slab 及边缘湿养护 7 天 [S1]）、材料交货期、天气因素列进去。

### 3.5 工地管理
- **怎么推**：从场地图（边界、入口、退让、邻居、树木）推场地布置；从工序推分包计划；从法定检查推文件记录。
- 内容：组织架构（项目经理、工地主管、WHS 负责人）；分包计划（每个工种的进场、退场时间）；场地布置（围挡、入口、材料堆放、垃圾箱、临时厕所和用电；高层加塔吊、施工电梯、卸料平台）；文件记录（日报、检查证书、ITP、variation、事故记录）；与 certifier 和 council 的配合（预约检查、提交证书）。

## 第 4 步：输出大纲

### 4.1 住宅（Class 1a）输出大纲
1. 项目概况：地址、图纸清单和版本、场地分类、风等级、能效等级、全部假设。
2. 问题清单（RFI）及回复状态。
3. 施工步骤：按 `住宅施工工序与用料总表.md` 的顺序，标出法定检查节点 🔒。
4. 用料：工程量计算表（场地开挖、slab 混凝土、钢筋网、防潮膜、框架、屋面、外墙、石膏板、瓷砖、防水、涂料、踢脚线和线条），每项写计算过程、损耗系数来源、采购数量。
5. 注意事项：按工序列技术要点、常见错误、检查点、WHS 风险。
6. 工期：工序表 + 逻辑关系 + 甘特图 + 检查节点 + 天气 / 交货风险。
7. 工地管理：组织、分包、场地布置图、文件和记录、检查预约流程。
8. 附件：工程量计算表、进度计划表、检查证书清单。

### 4.2 高层（Class 2 / 5 / 7a 等）输出大纲
1. 项目概况：建筑分类（NCC Volume One）、层数、结构体系、桩型、地下室层数、全部假设。
2. 设计资料和问题清单：岩土、基坑支护、结构、消防工程、立面、机电、电梯、Section J。
3. 施工步骤（分阶段）：场地建立 → 降水与支护 → 桩基 → 开挖 → 筏板 / 桩帽 → 地下室结构与防水 → 核心筒与标准层（含后张拉）→ 立面与幕墙 → 屋面 → 机电、消防、电梯 → 内装 → 调试与认证 → 交付。结构依据 NCC Volume One B1D4 所列标准（如 AS 3600、AS 2159、AS 4100）[S6]。
4. 用料：按构件分类（桩、楼板、墙、柱、梁）的混凝土 m³、模板 m²、钢筋 t（含钢量由结构工程师提供）、后张钢绞线、砌体 / 轻质墙、幕墙、防水。
5. 注意事项：基坑和临近建筑、塔吊吊装、高处作业、模板支撑与回撑、后张拉安全、立面防火、防水。
6. 工期：分区流水、标准层循环（每层天数 × 层数）、关键路径（通常是结构 → 立面 → 机电调试）、法定和专项检查。
7. 工地管理：组织架构、WHS management plan [S9]、场地布置（塔吊位置和覆盖、施工电梯、卸料平台、材料堆场、交通管理）、分包包划分、质量 ITP、文件控制。
8. 附件：工程量计算表（高层工作表）、进度计划（高层工作表）、场地布置图。
