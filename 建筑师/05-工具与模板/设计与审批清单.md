# 设计与审批清单

适用州：QLD（布里斯班）｜资料核对日期：2026-11-20｜状态：部分待证实（council、QBCC、Business Queensland 内容已对照原文核实；QDC 原文和 Urban Utilities 内容仍待证实）

## 摘要
这份清单覆盖从设计到开工前的审批路径：先判断要不要规划审批（DA），再选 building certifier，取得 building approval，最后办 plumbing 和 drainage 许可与接驳。昆州的独立住宅（class 1a）通常由私人 building certifier 审批；只有落在 code assessable overlay 等情形下，才需要先向 Brisbane City Council 申请 DA。路径判断对了，可以省下几个月的时间和不必要的顾问费。每项都附了来源链接。

---

## 1. 设计前准备

| # | 检查项 | 说明 | 完成 | 来源 |
|---|---|---|---|---|
| 1.1 | 拿到测量图（等高线、边界、管线） | 设计和 siting 的基础 | ☐ | 待证实（行业惯例）|
| 1.2 | 土壤测试与场地分级报告（AS 2870-2011） | 结构工程师设计 slab 的依据。H、E、P 类场地申请 plumbing 许可时还需要 drainage articulation 设计 | ☐ | [S10][S11] |
| 1.3 | FloodWise Property Report（最低居住层地板标高） | 决定地板标高和 slab 或架空方案 | ☐ | [S6] |
| 1.4 | 查 Urban Utilities 管线、是否需要 Build Over Asset 转介 | 设计时就避开管线，比事后申请 BOA 便宜 | ☐ | [S12] |

## 2. 规划审批（DA）判断

| # | 判断问题 | 是 → | 否 → | 来源 |
|---|---|---|---|---|
| 2.1 | 地块在 City Plan 中是否属于 accepted development 的分区，且满足相关 code 的条件（先查 Table 5.3.4.1 Prescribed accepted development）？ | 一般不需要规划审批，进入 2.3 | 可能需要 DA，进入 2.2 | [S1] |
| 2.2 | 是否落在 code assessable overlay 中？Council 页面列出：Airport environs（仅 ANEF）、Biodiversity areas、Bushfire、Coastal hazard、Commercial character building、Flood、Heritage、Landslide、Pre-1911、Traditional building character、Significant landscape tree、Waterway corridors、Wetlands | 不满足相关 code 的 acceptable outcomes 时，需要向 council 提交 development application；**Heritage overlay 和 Wetlands overlay 等不论是否满足 acceptable outcomes，都要申请规划审批** | 请 certifier 或规划顾问书面确认 | [S1] |
| 2.3 | 设计是否满足 QDC MP 1.1（地块 < 450 m²）或 MP 1.2（地块 ≥ 450 m²）的 siting 要求，如边界退让？ | 由 certifier 按 building assessment 处理 | 需要向 council 申请 referral agency response（QDC siting variation），会增加时间和费用 | [S2][S3] |
| 2.4 | 是否需要 Urban Utilities BOA 转介，或在 easement 上建造？ | 走 BOA 转介 | — | [S12] |

> ⚠ 州差异：本表只适用于昆州。昆州 DA 由 Planning Act 2016 体系和各 council 的 planning scheme 决定；新州、维州的审批路径完全不同，不要套用。
> 待确认：QDC MP 1.1 / 1.2 的现行版本、边界退让具体数字，以及 Planning Regulation 2017 中的现行转介条目，本次没有直接核对到原文，以 housing.qld.gov.au 现行版本为准 [S2]。

**省钱提示**：设计时尽量满足 acceptable solutions（退让、高度、覆盖率），能避免 siting variation 和 DA，这是最合法、最直接的省钱方式。

## 3. 选择 building certifier

| # | 检查项 | 说明 | 完成 | 来源 |
|---|---|---|---|---|
| 3.1 | 决定由谁委托 certifier | 通常由 builder 代业主委托，但业主可以自己直接委托。合同里要写清由谁负责。QBCC 指出：业主直接委托，可以降低拿不到 final certificate（Form 21）的风险 | ☐ | [S4][S5] |
| 3.2 | 在 QBCC 登记册核查 certifier 执照和认证历史 | | ☐ | [S4][S13] |
| 3.3 | 书面委托协议，写明费用 | 私人 certifier 的委托须书面并写明费用 | ☐ | [S5] |
| 3.4 | 问清包含哪些检查节点、另加检查怎么收费 | 额外检查的收费按委托协议约定（「业主要求的额外检查由业主付费」本次没有在官方页面核实到，待证实）| ☐ | 待证实 |
| 3.5 | 确认 certifier 与设计、施工无利益冲突 | Certifier 不得设计该建筑，也不得施工 | ☐ | [S5] |

**比价要点**：至少问 2–3 家 certifier，按「费用 + 包含检查次数 + 响应速度」比较。费用以书面报价为准，本清单不提供价格。

## 6. 开工前最后确认
- ☐ Building approval、plumbing permit 都已书面取得
- ☐ Home warranty 保费已由 builder 交给 QBCC（期限：签约后 10 个工作日内，或开工前，以较早者为准——QBCC Act s68B(2)），业主已收到保险证明 [S17]
- ☐ Certifier 的检查节点已列入《分阶段施工检查清单》
