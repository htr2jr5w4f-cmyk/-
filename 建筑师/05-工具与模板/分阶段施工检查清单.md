# 分阶段施工检查清单

适用州：QLD｜资料核对日期：2026-11-20｜状态：已核实（法定检查阶段已对照 Building Regulation 2021 原文；少数施工细节仍标「待证实」）

## 摘要
这份清单按施工顺序列出 8 个节点：site set-out、地基开挖、slab 浇筑前、框架、锁闭（lock-up / enclosed）、防水、fixing、practical completion。每个节点都标明是否属于 Building Regulation 2021 (Qld) 规定的**法定检查节点**（由 building certifier 检查，并出具 Form 16 inspection certificate）。业主可以自费另请独立检查员做补充检查，但这不能代替法定检查。法定检查保证的是「符合 building approval」，不等于工艺质量完美。所以每个节点也列出了业主自己可以看的要点，并对应合同的进度款阶段，用来决定什么时候付款。

**图例**：🔒 = 法定检查节点（certifier）｜🔧 = plumbing 检查（council）｜👁 = 非法定节点，建议业主或独立检查员查看｜💰 = 对应进度款阶段（以 QBCC NHC Option A 为例 [S5]）

---

## 法定检查节点概览（class 1a 独立住宅）

Building Regulation 2021 (Qld) s44(1)(b) 为新建独立 class 1a 住宅规定了以下检查阶段；Business Queensland 把它们归纳为 **5 个阶段**：excavation、footings、slab、frame、final [S1][S2]。其中 footings 和 slab 两个阶段写的是「如果建筑有 footings / 有 slab」，所以一栋只有 slab、没有单独 footings 的房子，实际是 4 次检查。

| 节点 | 法定？ | 依据（Building Regulation 2021）|
|---|---|---|
| ① Excavation：地基开挖后、浇筑 footing 或 slab 混凝土前 | 🔒 是 | s44(1)(b)(i) [S2] |
| ② Footings：如有 footings，模板和钢筋就位后、浇筑前 | 🔒 是（如有）| s44(1)(b)(ii) [S2] |
| ③ Slab：如有 slab，模板和钢筋就位后、浇筑前 | 🔒 是（如有）| s44(1)(b)(iii) [S2] |
| ④ Frame：bracing 由 cladding/lining 构成的，在其固定后检查；不是的，在 cladding/lining 固定前检查；配筋砌体框架在灌芯前检查 | 🔒 是 | s44(1)(b)(iv)–(vi) [S2] |
| ⑤ Final：全部工作完成时（核查未完项，收集白蚁、湿区防水膜、玻璃、烟雾报警器、能效等证书）| 🔒 是 | s44(1)(b)(vii) [S1][S2] |
| Building approval 中另外写明的检查阶段 | 🔒 是 | s44(1)(a) [S2] |
| Lock-up / enclosed、fixing、防水 | 不是 certifier 阶段检查（防水另需 aspect 证书）| [S2][S16] |

- 每个阶段完工后，builder 须通知 certifier（notice for inspection，s48；可用 Form 58）。取得该阶段的检查证书（Form 16）、证明其符合 building approval 之前，**不得开始下一阶段**（s49）[S2][S3]。
- class 1a 的 excavation、footings、slab、final 阶段，只能由 building certifier 签发检查证书（s46）；frame 阶段可以由 certifier 指定的 competent person 检查 [S2]。
- Local government 可以通过决议，豁免某地区某类 class 1a 建筑的某个检查阶段（s45）。你的 building approval 上列出的检查阶段，以 certifier 为准 [S2]。

## 1. Site set-out（定位放线）👁
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | 测量员定位，房屋位置与 approved site plan 一致（边界退让、标高） | [S7] |
| ☐ | 地板标高满足 FloodWise 报告或 approval 的最低要求 | [S8] |
| ☐ | 场地临时围栏、泥沙控制、临时厕所到位 | 待证实（council 施工期要求未核对）|
| ☐ | Urban Utilities 管线位置已标出，满足 BOA 条件（如有） | [S9] |

## 2. 地基开挖 🔒
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | Certifier 已完成 excavation 阶段检查（混凝土浇筑前，s44(1)(b)(i)），拿到 Form 16 | [S1][S2] |
| ☐ | 开挖深度、承载层与工程师图纸和土壤报告（AS 2870-2011 分级）一致 | [S10] |
| ☐ | 遇到岩石或软土时：builder 书面通知；涉及 PS 的，按合同核算并保留记录 | [S11] |
| ☐ | 拍照记录（含卷尺读数） | — |

## 3. Slab 浇筑前 🔒 🔧
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | Certifier 已完成 footings（如有）和 slab 阶段检查（模板和钢筋就位后、浇筑前，s44(1)(b)(ii)(iii)），拿到 Form 16 | [S2][S3] |
| ☐ | 结构工程师检查（若合同或设计要求）| 待证实（按工程师图纸要求）|
| ☐ | 地下给排水管线已经 council 检查（plumbing rough-in / 地下排水）| [S12] |
| ☐ | 白蚁防护按设计安装。如果用 slab 本身作屏障，须按 AS 2870 和 AS 3600 施工 | [S13] |
| ☐ | 防潮膜、钢筋保护层、钢筋垫块到位（看图纸）| [S10] |
| 💰 | **Base 阶段**（QBCC NHC Option A：15%，不含定金）：NHC 定义为 footings、base brickwork、stumps/piers、slab 或 bearers/joists/flooring 已完成，可以立墙 | [S5][S6] |

## 4. 框架 🔒
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | Frame 阶段检查通过，拿到 Form 16。注意检查时点取决于 bracing 方式（s44(1)(b)(iv)–(vi)）| [S1][S2] |
| ☐ | 屋架、tie-down、支撑与 truss/框架设计一致（看工程师和厂家文件）| 待证实（具体要求见设计文件）|
| ☐ | 门窗洞口尺寸、位置与图纸一致（这时改最便宜，之后是 variation）| [S14] |
| ☐ | 电气、给排水 rough-in 位置按你确认的平面图 | — |
| 💰 | **Frame 阶段**（QBCC NHC Option A：20%）：NHC 定义为 building frame 完成、可供 certifier 检查 | [S5][S6] |

## 5. 锁闭 lock-up / Enclosed 👁
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | QBCC NHC 定义的 Enclosed：外墙覆面已固定；屋面已固定（soffit 可未完成）；结构楼板已铺；外门、外窗已安装（可临时）| [S6] |
| ☐ | 屋面、天沟、落水管完成，无明显渗漏 | — |
| ☐ | 门窗安装，玻璃规格符合能效设计（NCC 2022 / QDC 4.1）| [S15] |
| ☐ | 墙体隔热、wall wrap 在封板前可见，拍照留证 | — |
| 💰 | **Enclosed 阶段**（QBCC NHC Option A：25%）| [S5] |

## 6. 防水 👁（需合规证书）
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | 湿区防水由持牌人员施工；防水工作超过 $3,300 时须出具防水证书：**Form 43 – Aspect Certificate (QBCC Licensee)** 或 **Form 12 – Aspect Inspection Certificate (Appointed Competent Person)**，视情况而定 [S3][S16] |
| ☐ | 贴砖前拍照：膜层上翻高度、阴角、地漏周边 | 待证实（具体尺寸以 NCC 2022 / AS 3740 适用版本为准）|
| ☐ | 淋浴区地面坡向地漏（QDC 4.5 也涉及向地漏找坡）| [S15] |

## 7. Fixing 👁
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | NHC 定义的 Fixing：内墙衬板、门套线、cornice、踢脚、房门、浴缸、淋浴底盘、湿区瓷砖、固定层架和橱柜已安装固定 | [S6] |
| ☐ | PC 项目（瓷砖、洁具、电器）与你书面选定的一致；有差额的，按合同结算 | [S11] |
| ☐ | 墙面平整度、门窗开关：参考 QBCC Standards and Tolerances Guide | [S17] |
| 💰 | **Fixing 阶段**（QBCC NHC Option A：20%）| [S5] |

## 8. Practical completion（PC）🔒（最终）🔧
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | Builder 提前 5 个工作日书面通知预计 PC 日期（NHC Condition 28.1）| [S6] |
| ☐ | 和 builder 一起做 PC 检查，填写 Defects Document（Form 6；双方签字，列明同意的缺陷、整改日期、有争议的项目）| [S4][S6] |
| ☐ | Certifier 完成 final 阶段检查（只能由 building certifier 签，s46）；final inspection certificate（Form 21）已签发 | [S2][S3][S18] |
| ☐ | Plumbing 最终检查通过，取得合规证书 | [S12] |
| ☐ | 各类证书齐全（见《交付验收清单》）| [S18] |
| 💰 | **Practical Completion 阶段**（QBCC NHC Option A：15%）：须附 Defects Document 和 Certificate of Practical Completion | [S5] |

## 省钱与风险提示
- 改动越早越便宜：框架阶段之前核对门窗洞口、插座、灯位，能避免后期 variation [S14]。
- 可以自费请持牌 building inspector 代你检查（QBCC 说明费用由业主承担）[S4]；关键节点建议安排在 slab 浇筑前、框架、PC 前（待证实：节点建议为一般做法，非官方要求）。
- 不要因为「赶工」同意 builder 跳过 certifier 检查：Building Regulation 2021 s49 不允许在取得检查证书前进入下一阶段 [S2]。

## 核对记录（2026-11-20 第二轮，对照官方原文）
- 法定检查阶段的条款号：原写「Building Regulation 2021 s47」，核对原文为 **s44(1)(b)**；「只能由 building certifier 签证书」是 **s46**（适用于 excavation、footings、slab、final 四个阶段），不是 s47。
- 阶段数量：原写「待证实：4 还是 5」，核对原文为 5 个：excavation、footings（如有）、slab（如有）、frame（按 bracing 方式细分时点）、final。另加 building approval 写明的阶段；local government 可按 s45 豁免。
- 「不得进入下一阶段」：核实为 s49；检查通知为 s48。
- 防水证书：Form 43 / Form 12 核实（QBCC 页面），并补全表格名称（Business Queensland 表格页）。
- 进度款阶段定义：Base、Frame、Enclosed、Fixing 已按 NHC 一般条款第 1 条原文补全。
- 原写「独立检查员费用由你支付 [S19]」，核对：QBCC 的 Practical completion inspection 页面写明可自费请 building inspector，来源改为 [S4]；节点建议标「待证实」。
