# 分阶段施工检查清单

适用州：QLD｜资料核对日期：2026-11-20｜状态：部分待证实

## 摘要
这份清单按施工顺序列出 8 个节点：site set-out、地基开挖、slab 浇筑前、框架、锁闭（lock-up / enclosed）、防水、fixing、practical completion。每个节点都标明是否属于 Building Regulation 2021 (Qld) 规定的**法定检查节点**（由 building certifier 检查，并出具 Form 16 inspection certificate）。业主可以自费另请独立检查员做补充检查，但这不能代替法定检查。法定检查保证的是「符合 building approval」，不等于工艺质量完美。所以每个节点也列出了业主自己可以看的要点，并对应合同的进度款阶段，用来决定什么时候付款。

**图例**：🔒 = 法定检查节点（certifier）｜🔧 = plumbing 检查（council）｜👁 = 非法定节点，建议业主或独立检查员查看｜💰 = 对应进度款阶段（以 QBCC NHC Option A 为例 [S5]）

---

## 法定检查节点概览（class 1a 独立住宅）

| 节点 | 法定？ | 依据 |
|---|---|---|
| 地基开挖后、浇筑 footing 或 slab 混凝土前 | 🔒 是 | Building Regulation 2021 s47（搜索摘要）[S1][S2] |
| Footing / slab：模板和钢筋就位后、浇筑前 | 🔒 是 | [S1][S2] |
| 框架 frame | 🔒 是 | [S1][S2] |
| 最终 final（核查未完项，收集各类证书）| 🔒 是 | [S1][S2] |
| Lock-up / enclosed、fixing、防水 | 非 certifier 阶段检查节点（防水另需合规证书） | [S2][S6] |

- 每个阶段完工后，builder 须通知 certifier；在取得该阶段的 inspection certificate（Form 16）、证明其符合 building approval 之前，**不得开始下一阶段** [S2][S3]。
- class 1a 的开挖阶段和 footing/slab 阶段，只能由 building certifier 签发检查证书，不能由 competent person 签发 [S2]。
- 待证实：Business Queensland 页面写的是「5 个检查阶段」，本次只核对到开挖、footing/slab、框架、最终 4 项；第 5 项（可能是把开挖和 footing 分开，或其他情形）要按 Building Regulation 2021 原文和 Business Queensland「Stages of a building inspection」页面核实 [S1][S2]。

## 1. Site set-out（定位放线）👁
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | 测量员定位，房屋位置与 approved site plan 一致（边界退让、标高） | [S7] |
| ☐ | 地板标高满足 FloodWise 报告或 approval 的最低要求 | [S8] |
| ☐ | 场地临时围栏、泥沙控制、临时厕所到位 | 待证实（council 施工期要求未核对）|
| ☐ | Urban Utilities 管线位置已标出，满足 BOA 条件（如有） | [S9] |

## 2. 地基开挖 🔒
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | Certifier 已完成开挖检查（混凝土浇筑前） | [S1][S2] |
| ☐ | 开挖深度、承载层与工程师图纸和土壤报告（AS 2870-2011 分级）一致 | [S10] |
| ☐ | 遇到岩石或软土时：builder 书面通知；涉及 PS 的，按合同核算并保留记录 | [S11] |
| ☐ | 拍照记录（含卷尺读数） | — |

## 3. Slab 浇筑前 🔒 🔧
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | Certifier 已完成 slab 检查（模板和钢筋就位后、浇筑前），拿到 Form 16 | [S2][S3] |
| ☐ | 结构工程师检查（若合同或设计要求）| 待证实（按工程师图纸要求）|
| ☐ | 地下给排水管线已经 council 检查（plumbing rough-in / 地下排水）| [S12] |
| ☐ | 白蚁防护按设计安装。如果用 slab 本身作屏障，须按 AS 2870 和 AS 3600 施工 | [S13] |
| ☐ | 防潮膜、钢筋保护层、钢筋垫块到位（看图纸）| [S10] |
| 💰 | **Base 阶段**（QBCC NHC Option A：15%）在 slab 完成后请款 | [S5] |

## 4. 框架 🔒
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | Certifier 框架检查通过，拿到 Form 16 | [S1][S2] |
| ☐ | 屋架、tie-down、支撑与 truss/框架设计一致（看工程师和厂家文件）| 待证实（具体要求见设计文件）|
| ☐ | 门窗洞口尺寸、位置与图纸一致（这时改最便宜，之后是 variation）| [S14] |
| ☐ | 电气、给排水 rough-in 位置按你确认的平面图 | — |
| 💰 | **Frame 阶段**（QBCC NHC Option A：20%）| [S5] |

## 5. 锁闭 lock-up / Enclosed 👁
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | QBCC NHC 定义的 Enclosed：外墙覆面已固定，屋面已固定（soffit 可未完成）| [S6] |
| ☐ | 屋面、天沟、落水管完成，无明显渗漏 | — |
| ☐ | 门窗安装，玻璃规格符合能效设计（NCC 2022 / QDC 4.1）| [S15] |
| ☐ | 墙体隔热、wall wrap 在封板前可见，拍照留证 | — |
| 💰 | **Enclosed 阶段**（QBCC NHC Option A：25%）| [S5] |

## 6. 防水 👁（需合规证书）
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | 湿区防水由持牌人员施工；防水工作超过 $3,300 时须出具防水证书（Form 43 或 Form 12，视情况而定）| [S16] |
| ☐ | 贴砖前拍照：膜层上翻高度、阴角、地漏周边 | 待证实（具体尺寸以 NCC 2022 / AS 3740 适用版本为准）|
| ☐ | 淋浴区地面坡向地漏（QDC 4.5 也涉及向地漏找坡）| [S15] |

## 7. Fixing 👁
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | 内门、踢脚、橱柜、台面、楼梯等安装完成（具体定义以合同为准）| [S6] |
| ☐ | PC 项目（瓷砖、洁具、电器）与你书面选定的一致；有差额的，按合同结算 | [S11] |
| ☐ | 墙面平整度、门窗开关：参考 QBCC Standards and Tolerances Guide | [S17] |
| 💰 | **Fixing 阶段**（QBCC NHC Option A：20%）| [S5] |

## 8. Practical completion（PC）🔒（最终）🔧
| ☐ | 检查点 | 来源 |
|---|---|---|
| ☐ | Builder 提前 5 个工作日书面通知预计 PC 日期 | [S6] |
| ☐ | 和 builder 一起做 PC 检查，填写 Defects Document（双方签字，列明同意的缺陷、整改日期、有争议的项目）| [S4][S5] |
| ☐ | Certifier 最终检查完成；final inspection certificate（Form 21）已签发 | [S3][S18] |
| ☐ | Plumbing 最终检查通过，取得合规证书 | [S12] |
| ☐ | 各类证书齐全（见《交付验收清单》）| [S18] |
| 💰 | **Practical Completion 阶段**（QBCC NHC Option A：15%）：须附 Defects Document 和 Certificate of Practical Completion | [S5] |

---

## 省钱与风险提示
- 改动越早越便宜：框架阶段之前核对门窗洞口、插座、灯位，能避免后期 variation [S14]。
- 独立检查员是自愿的补充检查，费用由你支付；关键节点建议安排在 slab 浇筑前、框架、PC 前 [S19]。
- 不要因为「赶工」同意 builder 跳过 certifier 检查：法规不允许在取得检查证书前进入下一阶段 [S2]。
