# 建材价格数据库说明

## 摘要
本文说明《建材价格数据库.csv》是什么、怎么用、怎么更新。2026-11-21 这一轮按规则（只用 curl 抓公开页面，遵守 robots.txt，不绕过人机验证，不调用网站内部接口）尝试从 Bunnings、Reece、Tradelink 官网采集布里斯班常用建材的零售标价，**结果一条价格都没能取得**：Bunnings 全站被 Cloudflare 人机验证拦截，Tradelink 跳转到未放行的域名，Reece 的产品页能打开，但价格由前端脚本加载，页面里没有价格 [S1][S2][S3]。所以数据库现在是一份**有产品页 URL 的采集清单**，价格栏全部空着并写明「取不到」和原因，没有编任何价格。等能取到价格时，用文末脚本一键重抓，或在浏览器里人工抄录后填入。

适用州：QLD（布里斯班）｜资料核对日期：2026-11-21｜状态：部分待证实（价格全部取不到；Reece 产品规格多数取自站点地图，未逐页打开核对）

## 一、数据库是什么
- 文件：`03-成本与省钱/建材价格数据库.csv`（UTF-8，带表头，49 行）。
- 字段：材料名称、品类、规格、单位、价格_含GST_AUD、零售商、产品页URL、采集日期、门店或地区、采集状态、备注。
- 组成：
  - Bunnings 30 行：覆盖任务要求的全部品类（结构木材、钢筋网、钢筋、防潮膜、袋装混凝土、石膏板、纤维水泥板、保温棉、sarking、钉和螺钉、防水膜、瓷砖胶、填缝剂、PVC 管、铜管/PEX、TPS 电线、灯具开关、内门、内外墙漆、屋面板、排水沟、落水管）。规格是**估价时要找的目标规格**，没有产品页 URL，因为整个网站打不开 [S1]。
  - Tradelink 6 行：水管、防水、屋面排水类，同样没有产品页 [S2]。
  - Reece 13 行：从 Reece 公开的产品站点地图里找到的真实产品页（DN100 DWV 管、DN90 雨水管、铜管、PEX 管、Quad 排水沟、落水管、液体防水膜、开关、筒灯、屋面密封胶），URL 可直接打开，价格取不到 [S3][S4]。
- **零售标价，不是 trade 价或批发价**：本库只收零售商网站对公众显示的价格（含 GST）。持证 builder 用 trade 账户（如 Bunnings PowerPass、Reece 和 Tradelink 的 trade 账户）拿到的价格通常不同，批量报价也不同，具体差多少没有公开数据——待证实。估价时，零售价只能当上限参考或核对 PC 金额，正式报价以供应商书面报价为准。

## 二、价格会变，必须写采集日期
- 每条记录都有「采集日期」。零售价随促销、季节和原材料涨落变化，Reece 的价格还按邮编（门店地区）加载 [S3]。
- 使用时：超过 3 个月的价格只作量级参考（3 个月是本库的使用约定，不是任何规范要求）；签合同前必须重新取价。
- 材料价格整体走势可参考 ABS 的 PPI（见《建造成本水平与指数.md》，布里斯班房屋建造投入价格 2026-09 季年涨 4.9%）。

## 三、怎么用于估价（配合 05-工具与模板/工程量计算表.xlsx）
1. 在《工程量计算表.xlsx》「住宅」或「高层」表里按图纸算出净工程量，填损耗系数和「包装/订货单位」，表会算出「采购包装数」和「采购数量」。
2. 在本 CSV 里按「品类」和「规格」找到对应材料，**核对单位是否和工程量表的订货单位一致**（例如 DWV 管按 6 m 一根，PEX 按 100 m 一卷，排水沟按米）。
3. 采购数量 × 单价（含 GST）= 材料费；再在《成本估算表.xlsx》里加人工、设备、preliminaries、margin 和应急费（见《成本估算方法.md》）。
4. 价格栏为空（「取不到」）的项目：去产品页 URL 在浏览器里查看，或向供应商要书面报价，把价格、日期、门店填回 CSV，并在「采集状态」写「人工抄录」。
5. 报价单里引用价格时写明：零售商、产品编码、门店/邮编、采集日期、是否含 GST。

## 五、下次更新的方法
### 方法 A：先把网络问题解决
- Bunnings、Stratco：Cloudflare 人机验证拦截自动访问，云端环境放行域名也解决不了。只能在浏览器里人工查看，或请 Bunnings PowerPass 客户经理给书面报价。
- Tradelink：请业主在环境里放行 `tradelink.com.au`（不带 www），再用脚本试一次。
- Reece：如业主或环境管理员同意调用 Reece 网站的价格接口，或用 Reece trade 账户登录查看，再更新；否则人工抄录。

### 方法 B：用脚本重抓（可复用）
脚本：`06-技能清单/脚本/建材价格采集.py`（Python 3 标准库 + curl）。它读本 CSV 中有「产品页URL」的行，先查 robots.txt，再逐条抓页面，按 JSON-LD → meta 价格标签 → `__NEXT_DATA__` 的顺序找价格，写出新 CSV；取不到的写「取不到」和原因。默认每次请求间隔 3 秒（最低 2 秒）、最多 150 次。

```bash
cd 建筑师
# 先试跑：只查 robots.txt，列出要抓的 URL
python3 -I 06-技能清单/脚本/建材价格采集.py --input 03-成本与省钱/建材价格数据库.csv \
    --output 03-成本与省钱/建材价格数据库_2027-02.csv --date 2027-02-01 --dry-run
# 正式抓取
python3 -I 06-技能清单/脚本/建材价格采集.py --input 03-成本与省钱/建材价格数据库.csv \
    --output 03-成本与省钱/建材价格数据库_2027-02.csv --date 2027-02-01
```

### 方法 C：增加新产品
1. Reece：下载站点地图 `https://www.reece.com.au/sitemaps/product_sitemap.xml`（约 35 MB，约 3.7 万个不重复产品 URL），用 grep 按关键词找产品，例如 `grep -i 'dwv-pvc-pipe-100mm'`。注意 Reece 的 robots.txt 不允许抓带查询参数的网址（如 `/search?q=`），所以不要用站内搜索页 [S4]。
2. 把产品名、规格、单位、URL 加到 CSV 新行，价格留空，再跑脚本或人工抄录。

### 人工核对要求
脚本取到的价格要抽查：在浏览器打开同一 URL，核对是否含 GST、计价单位（每根/每米/每包）、门店或邮编、是否是促销价，结果写进「备注」。
