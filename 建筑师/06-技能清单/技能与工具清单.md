# 技能与工具清单

## 摘要
记录本知识库建设过程中使用或安装的 Claude 技能（skill）、软件工具，以及自制的工具和模板。每项写：名字、来源、用途、使用例子。规则：只安装官方或知名开源来源的技能/软件，并在此登记。

适用州：不适用｜资料核对日期：2026-11-20｜状态：持续更新

## 一、使用的 Claude 技能（skill）
| 名字 | 来源 | 用途 | 使用例子 |
|------|------|------|----------|
| anthropic-skills:pdf | Anthropic 官方内置技能 | 生成和检查 PDF | 生成「YYYY-MM-DD 学习报告.pdf」并逐页检查中文显示 |
| anthropic-skills:xlsx | Anthropic 官方内置技能 | 制作和校验 Excel 表格 | 制作 `05-工具与模板/成本估算表.xlsx`，带公式自动汇总 |
| 网页检索与读取（WebSearch / WebFetch） | Claude Code 内置工具 | 查政府、监管机构官网原文 | 在 ABCB 官网核实 NCC 现行版本 |
| 研究子代理（Agent） | Claude Code 内置功能 | 按主题并行检索、写知识文件 | 同时研究 QBCC 合同规定和建造流程 |

本轮**没有安装**任何第三方 Claude 技能：插件目录里搜索「construction / estimating / drawings」，唯一相关的 Avontus Viewer 只能配合该公司的脚手架设计软件用，不适用。替代做法：在知识库里自建 Claude 技能（见 `.claude/skills/`）。

## 一之二、知识库自建的 Claude 技能（`.claude/skills/`，在 F:\建筑师 打开 Claude Code 时自动可用）
| 技能 | 用途 | 使用例子 |
|---|---|---|
| 看图出方案 | 收到图纸后，输出全部步骤、用料、注意事项、时间安排、工地管理五部分 | 业主发来一套 PDF 图纸：先列缺图清单，再按 5 部分出方案，附工程量表和进度表 |
| 工程量计算 | 按图纸尺寸算混凝土、钢筋网、屋面、外墙、石膏板、防水等用量和采购量 | 屋面平面 237.44 m²、坡度 22.5° → 屋面 257.0 m² |
| 法规核查 | 按现行原文核对门槛、时限、条款号、NCC/AS 版本，并写回知识库 | 核对「$20,000 是超过还是及以上」→ QBCC Regulation s45：及以上为 Level 2 |
| 读图量图 | 从 DXF 按图层统计长度、面积、块数量、文字、尺寸；在矢量 PDF 上按比例或两点校准量尺 | `python3 dxf算量.py 平面.dxf 结果.xlsx` → 外墙 60 m、200 m²、门 5、窗 8 |
| 装修平面出图 | 由房间清单和租户区外轮廓自动出商业装修平面概念草图（DXF + A3 PDF），校核面积、走道净宽、门宽，并对疏散距离给出警告 | 300 m² 办公演练：自动出两种布局，发现最远点到租户门约 31.2 m，超过 D2D5 一般 20 m |
| 合同审查 | 逐条比对 QBCC Act Sch 1B，找出违法项、不利项、谈判项 | builder 合同写 10% 定金、合同价 $450,000 → 违反 s33（上限 5%） |

## 二、使用的软件（开源，均为容器预装或官方包源安装）
| 名字 | 来源 | 用途 |
|------|------|------|
| Python 3 + openpyxl | python.org / PyPI（知名开源） | 生成 Excel 成本估算表 |
| Chromium + Playwright | 容器预装（Google/微软开源项目） | 把 HTML 报告转为 PDF |
| 文泉驿正黑 (WenQuanYi Zen Hei) | 开源中文字体，系统预装 | PDF 中文显示，避免乱码 |
| pypdf / pdftoppm | PyPI / poppler（开源） | 检查 PDF 文本和页面渲染；把 PDF 图纸渲染成图片后看图 |
| ezdxf 1.4.5 | PyPI，知名开源 CAD 库（MIT 许可） | 读取 DXF 格式 CAD 图纸的图层、尺寸、文字，用于看图和算工程量（2026-11-21 安装） |
| PyMuPDF 2.1 | PyPI，知名开源 PDF 库（AGPL-3.0 / 商业双许可；个人自用无碍，若将来把工具做成对外分发的软件需注意许可） | 读矢量 PDF 图纸的线段和文字，按比例量尺（2026-11-21 安装） |
| matplotlib 3.11.2 | PyPI，知名开源绘图库 | 已安装备用（2026-11-21） |
| 连带安装：pymupdf4llm、pymupdf-layout、contourpy、cycler、kiwisolver、networkx、psutil、tabulate | PyPI 开源 | PyMuPDF / matplotlib 的依赖 |
| LibreOffice (soffice) | 开源，容器预装 | 重算 Excel 公式，检查有没有公式错误 |

## 三、自制脚本
| 名字 | 用途 | 使用例子 |
|---|---|---|
| `脚本/md转pdf.py` | 把 Markdown 报告转成 A4 PDF，中文字体嵌入，不乱码 | `python3 md转pdf.py 报告.md 报告.pdf` |
| `脚本/dxf算量.py` | DXF 按图层算量，输出 xlsx | 见 `读图量图工具使用说明.md` |
| `脚本/pdf图纸量尺.py` | 矢量 PDF 量尺、渲染、提取文字 | `量尺 --比例 1:100 --纸张 A1` |
| `脚本/建材价格采集.py` | 从零售商产品页提取公开标价（遵守 robots.txt、限速） | `--dry-run` 先试跑 |
| `脚本/测试数据/运行测试.py` | 读图工具自动测试（42 项） | 改动脚本后运行，确认全部通过 |
| `脚本/装修平面出图.py` | 房间清单 → 平面概念草图（DXF/PDF）与自动校核；58 项测试 | `测试数据/装修平面出图/运行装修平面测试.py` |
| `脚本/生成索引.py` | 读取文件夹内各文件的摘要和状态，自动生成 索引.md | 新增知识文件后运行 `python3 生成索引.py 01-法规标准` |
