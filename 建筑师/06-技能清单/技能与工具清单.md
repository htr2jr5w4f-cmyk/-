# 技能与工具清单

## 摘要
记录本知识库建设过程中使用或安装的 Claude 技能（skill）、软件工具，以及自制的工具和模板。每项写：名字、来源、用途、使用例子。规则：只安装官方或知名开源来源的技能/软件，并在此登记。

适用州：不适用｜资料核对日期：2026-11-20｜状态：持续更新

## 一、使用的 Claude 技能（skill）
| 名字 | 来源 | 用途 | 使用例子 |
|------|------|------|----------|
| anthropic-skills:pdf | Anthropic 官方内置技能 | 生成和检查 PDF | 生成「YYYY-MM-DD 学习报告.pdf」并逐页检查中文显示 |
| anthropic-skills:xlsx | Anthropic 官方内置技能 | 制作和校验 Excel 表格 | 制作 `05-工具与模板/成本估算表.xlsx`，带公式自动汇总 |
| 网页检索与读取（WebSearch / WebFetch） | Claude Code 内置工具 | 查政府、监管机构官网原文 | 在 ABCB 官网核实 NCC 现行版本 |
| 研究子代理（Agent） | Claude Code 内置功能 | 按主题并行检索、写知识文件 | 同时研究 QBCC 合同规定和建造流程 |

本轮**没有安装**任何第三方技能。

## 二、使用的软件（开源，均为容器预装或官方包源安装）
| 名字 | 来源 | 用途 |
|------|------|------|
| Python 3 + openpyxl | python.org / PyPI（知名开源） | 生成 Excel 成本估算表 |
| Chromium + Playwright | 容器预装（Google/微软开源项目） | 把 HTML 报告转为 PDF |
| 文泉驿正黑 (WenQuanYi Zen Hei) | 开源中文字体，系统预装 | PDF 中文显示，避免乱码 |
| pypdf / pdftoppm | PyPI / poppler（开源） | 检查 PDF 文本和页面渲染 |

## 三、自制脚本
| 名字 | 用途 | 使用例子 |
|---|---|---|
| `脚本/md转pdf.py` | 把 Markdown 报告转成 A4 PDF，中文字体嵌入，不乱码 | `python3 md转pdf.py 报告.md 报告.pdf` |
| `脚本/生成索引.py` | 读取文件夹内各文件的摘要和状态，自动生成 索引.md | 新增知识文件后运行 `python3 生成索引.py 01-法规标准` |
