# 读图量图工具使用说明

## 摘要
本文说明两个自制脚本的用法：`脚本/dxf算量.py` 按图层统计 DXF 图纸的线长、面积、块（门窗、灯具）数量、文字和尺寸标注，输出 xlsx；`脚本/pdf图纸量尺.py` 在矢量 PDF 图纸上按比例或两点校准量长度和面积、提取文字及位置，并把页面渲染成 PNG。两个脚本都用一套已知答案的测试图验证过（42 项全部通过）。量出的数字是工程量计算表的输入，不能代替读图：口径（中心线还是外包线、单线还是双线墙）要先看图确定。

适用州：不适用（工具类）｜资料核对日期：2026-11-20｜状态：已测试（测试数据为自制图，尚未用真实项目图纸验证）

## 二、dxf算量.py

### 用法
```
python3 dxf算量.py 输入.dxf [输出.xlsx] [--图层 名1 名2 "A-WALL*"] [--单位 mm|cm|m|in|ft|dm] [--展开块]
```
- 省略输出文件时只打印终端摘要。
- `--图层`：只统计这些图层，支持通配符，不区分大小写。
- `--单位`：强制指定图纸单位，覆盖文件里的 `$INSUNITS`。`$INSUNITS=0`（未定义）时脚本按 mm 处理并给出警告，因为澳洲建筑图纸绝大多数用 mm。
- `--展开块`：把块内的线和面积也计入（块内放在 0 层的图元按 AutoCAD 规则继承插入所在的图层）。默认不展开，块只计数量。

### 统计口径
| 项目 | 统计哪些实体 | 说明 |
|---|---|---|
| 线长 | LINE、LWPOLYLINE、POLYLINE（2D/3D）、ARC | 多段线的弧段（bulge）按真实弧长；闭合多段线含收尾段 |
| 圆/椭圆/样条长 | CIRCLE、ELLIPSE、SPLINE | 单独一列，不混进线长（灯具、柱子常画成圆） |
| 闭合面积 | 闭合 LWPOLYLINE/POLYLINE（含弧段）、CIRCLE | 每个图形明细见「闭合图形明细」表，便于逐个房间核对 |
| 填充面积 | HATCH | 边界按嵌套深度奇偶相减，孔洞（岛）自动扣除 |
| 块数量 | INSERT（MINSERT 按行×列计） | 按图层、块名分别计数；块属性（ATTRIB，如门窗编号）计入文字 |
| 文字 | TEXT、MTEXT、ATTRIB | 记录内容和坐标（图纸单位和 m） |
| 尺寸 | DIMENSION | 读取几何实测值；图上文字被手动改写时一并列出，须核对 |

### 输出
- 终端：每图层一行（线长、闭合面积、填充面积、块数、文字数、尺寸数），下面列块明细、尺寸值、文字。
- xlsx：「按图层汇总」（每个图层一行，末行合计）、「块统计」「文字」「尺寸标注」「闭合图形明细」「说明」六张表。

### 例子（测试图 `测试数据/测试平面_mm.dxf`）
```
python3 dxf算量.py 测试数据/测试平面_mm.dxf 结果.xlsx
图层       线长m   闭合面积m²  填充面积m²  块数  文字  尺寸
内墙      27.000      0.000      0.000     0     0     0
地面填充   0.000      0.000      7.250     0     0     0
外墙      60.000    200.000      0.000     0     0     0
...
[尺寸] 尺寸（线性/旋转）：20.000 m
[窗] 块：WINDOW × 8
[门] 块：DOOR × 5
```

## 三、pdf图纸量尺.py

### 子命令
| 子命令 | 作用 | 例子 |
|---|---|---|
| 信息 | 每页尺寸（mm）和纸张、旋转、矢量路径数、文字数；只有图片没有矢量时提示「像扫描件」；列出 PDF 图层（OCG） | `python3 pdf图纸量尺.py 信息 图纸.pdf` |
| 渲染 | 把某页（或某区域）渲染成 PNG，供人工看图、找坐标 | `python3 pdf图纸量尺.py 渲染 图纸.pdf --页 2 --dpi 150 -o p2.png`（加 `--引擎 pdftoppm` 改用 poppler） |
| 文字 | 列出文字及位置，可按关键字、区域筛选；末尾列出像尺寸的纯数字 | `python3 pdf图纸量尺.py 文字 图纸.pdf --页 2 --关键字 BED KITCHEN` |
| 量尺 | 统计区域内线段总长、闭合路径面积和区域内文字，按「图层 \| 线色 \| 线宽」分组 | 见下 |

### 坐标
- 默认坐标单位是 PDF 点（pt，1 pt = 1/72 英寸 ≈ 0.3528 mm），原点在页面左上角，y 向下。
- 更方便的做法：先用「渲染」按某个 dpi 出 PNG，在看图软件里读像素坐标，然后加 `--像素dpi 150` 直接用像素坐标。
- 页面有旋转时，脚本按显示方向（和 PNG 一致）处理坐标。

### 比例设定（二选一）
1. **按标注比例**：`--比例 1:100`。如果 PDF 不是按原纸张大小输出（例如 A1 图存成了 A3 PDF），加 `--纸张 A1`（或 `594x841`），脚本按页面尺寸自动换算。原图纸张看图签（title block）。
2. **两点校准**（更可靠）：`--校准 x1,y1,x2,y2,已知长度m`，两点取一条已标注尺寸的两端（例如总长 20000 的尺寸线两端），脚本反算比例并显示等效比例，可与图签比例互相核对。

### 例子（测试图 `测试数据/测试平面_1比100_A3.pdf`）
```
python3 pdf图纸量尺.py 量尺 测试数据/测试平面_1比100_A3.pdf --比例 1:100 --区域 130,130,720,440 --输出 结果.xlsx
— | 线色#000000 | 线宽1.00   线长 60.000 m（4 段）  闭合面积 200.000 m²（1 个）
— | 线色#0000FF | 线宽0.50   线长 27.000 m（3 段）  闭合面积   0.000 m²（0 个）
— | 线色#FF0000 | 线宽0.50   线长  3.142 m（4 段）  闭合面积   0.786 m²（1 个）
区域内文字 5 行：卧室1、卧室2、客厅、厨房、浴室（附坐标）
```
筛选参数：`--颜色 #0000FF`（只算某线色）、`--最小线宽 0.3`（排除填充图案和细线）、`--图层 A-WALL`（CAD 导出时保留了 PDF 图层的）。`--输出` 可写 .xlsx 或 .json。

## 五、限制（务必知道）
1. **扫描版 PDF 不能提取矢量**：扫描件只有图片，「信息」会提示「像扫描件」。只能渲染后人工看图，用图上比例尺或已知尺寸估量；数字必须标「按扫描件估量」并要求设计方提供矢量 PDF 或 CAD。
2. **DWG 要先转成 DXF**：ezdxf 不读 DWG。转换办法：请设计方直接给 DXF（最好）；或用 ODA File Converter（Open Design Alliance 免费工具）、AutoCAD / BricsCAD「另存为 DXF」。转换后先用一条已知尺寸核对单位。
3. **线长不等于墙长**：墙常画成双线（两侧面层），线长约是墙长的 2 倍；还会混入门窗洞口线、填充图案、家具线。应按图层或线色过滤，并用一面已知长度的墙核对口径。
4. **PDF 没有「图层」时只能按线色、线宽分组**；同一图元可能同时有填充和描边，面积已按外包和面积去重，但嵌套闭合（房间套房间）会重复计入合计，以「闭合路径」明细为准。
5. **PDF 区域只计完全落在区域内的线段**，跨越区域边界的线段不计（不做裁剪）。
6. **比例是否可靠**：图纸常注明「不得量取尺寸（do not scale）」。标注尺寸优先于量取值；量出的值只用于工程量估算和核对，放线和下料以标注尺寸和施工详图为准。PDF 若被缩放打印过，必须用两点校准。
7. **DXF 只统计模型空间**；图纸空间（layout）的视口内容不统计。动态块的匿名块名（`*U…`）可能无法还原成原块名，按块明细逐个确认。
8. **尺寸值**：读取的是几何实测值。若设计者手改了尺寸文字，脚本会列出改写后的文字，以图上标注为准并追问设计方。

## 六、与 `05-工具与模板/工程量计算表.xlsx` 的衔接
计算表「住宅」「高层」两张表的黄色格是参数（单位 m、m²、m³）。读图量图工具的输出按下表填入（填前先确认口径）：

| 工具输出 | 填入计算表 | 注意 |
|---|---|---|
| 外墙图层线长（单线中心线）或外墙闭合多段线周长 | R10「外墙长」、R14「外墙周长」、R9「边梁周长」 | 双线墙要除以 2 或只取一侧图层 |
| 内墙图层线长 | R10「内墙长」、R15「内墙长」 | 扣除重复线和门洞线 |
| 外墙闭合面积（外包） | R3「Slab 面积」、R7「Slab 面积」、R9「Slab 面积」 | slab 按结构图外包尺寸，含门廊、车库要分开 |
| 房间闭合面积 / HATCH 面积（按房间） | R16「地砖面积」、R18「防水地面」、R19/R15「天花面积」 | 按装修表区分材料 |
| 门块、窗块数量 | R12「洞口数」、R22「门樘数」；洞口面积 = 数量 × 门窗表尺寸 → R14、R15 | 门窗尺寸以门窗表为准，块数量用来核对门窗表 |
| 屋面平面闭合面积（投影） | R13「水平投影面积」 | 坡度从剖面读 |
| 尺寸标注测量值 | 用来核对比例和口径 | 与量取值不一致时以标注为准 |

做法：先运行脚本得到 xlsx，把需要的数字复制到计算表的黄色格（不要改计算表的公式列），再在计算表的「备注」列写明来源（例如「dxf算量：外墙图层闭合多段线，中心线口径」）。
