# 商业装修机电与消防改造

适用州：QLD（布里斯班），NCC 部分为全国｜资料核对日期：2026-11-21｜状态：部分待证实（NCC 2022 Volume One 的 F6、E1、E2、E4、J5、J6、J7、J9、Specification 17/20、Schedule 2，以及 Building Fire Safety Regulation 2008、QBCC Regulation 2018、Plumbing and Drainage Regulation 2019、Electrical Safety Regulation 2026、Telecommunications (Cabling Provider) Rules 2025、Business Queensland MP6.1 页面、QFD 收费表和误报单张已读原文；QFD 隔离页面、ACMA、AIRAH、ARC 只有搜索摘要）

## 摘要
本文从 builder 和项目经理的角度写商业装修（办公、零售、餐饮、诊所）里机电和消防改造的做法，包括：暖通（租户区常见系统、末端和风管改动、新增隔墙对回风和温控分区的影响、NCC F6 通风和 J6 空调能效条款、与 base building 机电顾问和 BMS 的接口）；电气（配电、子电表、RCD、照明控制 J7D4、应急照明的安装和维护分工、Certificate of Testing and Safety）；通信布线（ACMA 布线员注册，2025 年新规）；消防（喷淋、探测、EWIS 改动，谁能做，隔离、系统受损期间的管理、测试出证、维护记录，fire engineer 和 Performance Solution）；给排水（茶水间和卫生间属于 notifiable work 还是 permit work）；吊顶内机电综合协调；最后是一张检查清单 [S1]–[S22]。
几处容易判断错：①NCC 2022 的 **J5 是 building sealing（围护结构气密）**，空调和通风的能效条款在 **J6**（NCC 2019 叫 J5）[S2][S3]；②NCC **E4 本身没有定期测试应急照明的条款**，昆州的定期检查测试由 BFSR 2008 s 54 和 QDC MP6.1 规定 [S6][S13][S14]；③只靠分体空调、没有按 AS 1668.2 提供室外新风的封闭房间，**还须有 F6D7 的自然通风**（可开启面积不少于地面面积的 5%）[S1]；④Class 2–9 建筑里新增或移位洁具，**只有 1–2 层的既有建筑才属于 notifiable work**，且不含 sanitary drainage；接 trade waste 或用 Performance Solution 的给排水工作不属于 notifiable work [S16]。
对省钱的用处：在报价和设计阶段把楼宇指定分包（消防、BMS、机械）、隔离和误报费用、回风和分区的改动量算清楚，可以避免开工后增加变更、误报罚款（每次 $1,556.79，2026–27 年）和返工 [S17]。

> 不重复的内容：审批门槛（Sch 1 s 7–9、14）、执照总表、E4 应急照明布置条款、J7D3 照明功率密度、BFSR 疏散条款见 `01-法规标准/商业装修法规与审批.md`（下称「法规文件」）；施工工序、在营楼宇施工、hot works 见 `02-建造流程/商业装修施工工序与工法.md`（下称「工序文件」）；厨房排烟罩、trade waste、隔油池见 `02-建造流程/商业装修专项-餐饮诊所与绿色评级.md`（下称「餐饮文件」）；高层消防系统总体、AS 1851 和 occupier statement 见 `02-建造流程/高层-机电消防与电梯.md`；电工执照和证书见 `02-建造流程/电气规定与实务.md`；给排水表格和 BCC 收费见 `02-建造流程/给排水规定与实务.md`；楼宇许可制度（permit to work、消防隔离许可）、Fire Services Act s 146M/150A 见 `04-现场经验与案例/商业装修楼宇接口租赁与在营施工.md`（下称「楼宇接口文件」）；照明设计和 J7D4 的设计角度见 `02-建造流程/商业装修设计-空间规划与设计流程.md`。本文 NCC 条款号均为 **NCC 2022**，昆州 2027-05-01 起改用 NCC 2025，届时须重新核对。

## 1. 暖通（HVAC）

### 1.1 租户区常见的空调系统（行业做法，具体以 base building 资料为准）
| 系统 | 做法 | 装修时的典型改动 | 谁做 |
|---|---|---|---|
| **VAV（变风量）** | 中央 AHU 送风，经主风管到吊顶内的 VAV box，每个 box 控制一个温控区；常用吊顶空间做回风静压箱（ceiling plenum return） | 加 VAV box 或拆分区，移送风口，加长软风管，移温控器，重新平衡风量 | 楼宇指定的机械承包商较常见 |
| **FCU（风机盘管）** | base building 供冷冻水（有时还有热水），每台盘管带一个区 | 移位或加 FCU，接冷冻水支管和冷凝水管，改风口 | 同上；冷冻水接驳一般要 base building 停水或排空，须楼宇批准 |
| **Base building chilled water / tenant condenser water** | 楼宇向租户提供冷冻水或冷却水接口，供租户自装末端（例如机房、服务器间） | 新接口、计量、阀门、保温 | 接口位置、容量和计费在 lease 和 fit-out guide 中规定 |
| **Split / VRF / 小型 packaged** | 租户自有系统，常用于服务器间、加班时间（after-hours）区或楼宇系统覆盖不到的区域 | 新装室内机、冷媒管、冷凝水管、室外机位 | 租户的机械承包商；室外机位置和结构荷载须楼宇批准 |

- **执照**：mechanical services 工作由持 QBCC **Mechanical services—air-conditioning and refrigeration** 执照（Sch 2 Pt 48A unlimited design、48B limited design）的承包商做，Pt 48A 的范围原文包括「constructing, installing, replacing, repairing, altering, maintaining, testing or commissioning a mechanical ventilation system in a building」；风管安装另有 **Air handling duct installation** 执照（Pt 1：安装空调、空气处理和机械通风系统的风管和封闭箱体）[S15]。在 Type A/B 或 GFA 超过 2,000 m² 的 Class 2–9 建筑里，Builder – Low rise 不能安排 mechanical services 工作（见法规文件 4.1）。
- **冷媒**：接触受管制冷媒（会导致泄漏的操作）须持 Australian Refrigeration Council 发的 **refrigerant handling licence**；据 ARC 资料，受限分体执照只能装单头、制冷量 18 kW 以下的分体机，不含多联机和 VRF，维修涉及冷媒须全证（仅搜索摘要，待证实）[S22]。
- **空调接电**是电气工作，须持照电工（见第 2 节）。
- **审批**：属于楼宇整体系统一部分的空调（例如属于消防或机械通风系统的一部分）不能按 Building Regulation Sch 1 s 14 免批（见法规文件 1.2）。所以改中央 VAV、FCU 和新风系统，要问 certifier 是否需要 building approval。

### 1.2 新增隔墙对回风和温控分区的影响（工程推断 + NCC 原文）
1. **回风通路**：吊顶回风的楼层，新隔墙如果只到吊顶，回风可经吊顶回到 AHU；如果做到楼板底（为了隔声、保密或防火），房间就成了「死区」，须加回风格栅加转接风管（transfer duct，隔声做法带消声弯头）或单独回风管。漏做的常见后果：门缝啸叫、房间正压、送风量不够、温度不达标（行业经验）。
2. **疏散路线的空气**：不得以可能在火灾时让空气从其他空间流入疏散路线的方式安装或改动空调、机械通风；在防火隔离区边界墙上开洞不封堵、撑开防火门也算违规（BFSR s 13，最高 30 penalty units；获批的 building work 除外）[S13]。回风转接口不能开在防火隔离通道的墙上。
3. **温控分区**：原来一个开放区一个温控区，隔成若干小房间后，靠窗（外区）和内区、会议室（人多、间歇使用）和普通办公的热负荷不同。NCC J6D3(1)(b)：空调系统服务**多个热负荷不同的区**时，须**对每个区单独温控**，不得用冷热风混合的方式控温，再热限制在 7.5 K 温升以内 [S2]。所以新增会议室或封闭办公室，一般要加 VAV box 或 FCU，或至少把它们和负荷相近的区放在一起——由机械顾问出图。
4. **送风口分布**：隔墙把原有送风口集中到一间房、另一间没有送风，是装修中最常见的暖通缺陷之一（工序文件 2.5）。

### 1.3 通风条款：F6 和 AS 1668.2（NCC 2022 原文）[S1][S9]
| 条款 | 要求 | 对装修的意义 |
|---|---|---|
| **F6D6** | habitable room、**office、shop**、factory、workroom、卫生间、浴室、洗衣房和其他有人使用的房间，须有 F6D7 的自然通风，或**符合 AS 1668.2 和 AS/NZS 3666.1 的机械通风或空调系统**（NSW 删去 AS/NZS 3666.1，昆州无变体） | 封闭办公室、诊室、员工室等新房间都要落实其中一条 |
| F6D6 的 ABCB 解释 | 服务房间的机械系统**只负责供冷供热、不按 AS 1668.2 提供通风**时，房间还须有 F6D7 的自然通风；**典型的墙挂分体空调就是这种情况** | 只装分体空调的封闭房间，若没有窗或新风，不合规 |
| **F6D7** | 自然通风：可开启的开口、窗、门等，通风面积**不少于房间地面面积的 5%**，开向合适的天井、室外、开敞外廊等，或按 F6D8 向相邻房间借风 | 内区封闭房间一般做不到，须机械新风 |
| **F6D8(b)** | Class 5–9 借风：房间与相邻房间之间的开口**不少于该房间地面面积的 10%**（只计离地 3.6 m 以内的部分），相邻房间的外窗等**不少于两间合计面积的 10%** | 玻璃隔断加百叶或上部开口借风，要按这两个 10% 核算 |
| **F6D9** | 卫生间不得直接开向厨房或备餐间、公共餐厅、公共集会房间、**多于 1 人正常使用的工作场所**等 | 开放办公区边上新做卫生间，门不能直接对着工位区 |
| **F6D10** | Class 5–9：通过面积**不少于 1.1 m²**、所有门**自闭**的气闸（airlock）、走廊或其他房间进入；或卫生间设**机械排风**且门洞有适当遮挡 | 新卫生间方案二选一，影响平面和排风管 |
| F6D12 | 商业厨房排烟罩的功率触发条件 | 见餐饮文件 1.3 |

- **AS 1668.2**（付费标准，规定建筑机械通风的室外新风量、排风等，NCC 引用其 2012 版含 Amendment 1、2）[S9]。Standards Australia 商店显示 2012 版已被 **AS 1668.2:2024**（2024-06-28 发布）取代 [S10]；昆州 2027-05-01 前按 NCC 2022 设计时，合规依据仍是 Schedule 2 列的 2012 版。具体新风量数值本文不写。
- **AS/NZS 3666.1**（付费，空气处理和水系统的微生物控制：设计、安装和调试，NCC 引用 2011 版）[S9]。
- **AS 1668.1**（付费，火灾和烟气控制）：楼宇的排烟、楼梯加压、空调「火灾模式」（报警时 AHU 停机或转排烟）由它规定；租户改动风管、加 VAV 或接驳 AHU 时，不得破坏楼宇的火灾模式联动（工程推断，具体由机械顾问按楼宇消防设计确认）。

### 1.4 Section J：J5 和 J6 对装修的适用（NCC 2022 原文）
- **编号说明**：NCC 2022 的 **J5 = Building sealing（围护结构气密）**，DtS 适用于 Class 2–9 建筑围护结构的构件（例外包括：只用蒸发冷却的气候区 1、2、3、5 建筑；Class 3、5–9 中 F6 要求的机械通风已足以正压防渗的建筑或空间；不能完全封闭的部分）[S3]。普通室内装修一般不改围护结构，J5 很少涉及；改外门、店面、加排风口时才可能涉及（推断）。
- **J6 = Air-conditioning and ventilation**（条款旁注「2019: J5.x」，即 NCC 2019 的 J5）[S2]。J6D3–J6D13 依次为：空调系统控制、机械通风控制、风机和风管系统、**风管保温**、**风管密封**、水泵、**管道保温**、采暖、冷水机组、单元式空调、排热设备 [S2]。
- **J6D3 中与装修直接有关的要求**（原文摘要）[S2]：
  - 空调系统在所服务部分无人时须能关闭；
  - 多区系统每区单独温控（见 1.2）；
  - 风量超过 1,000 L/s 且送风量可变时须用变速风机；
  - 控制死区（dead band）不小于 2 °C（专门用途除外）；
  - 须装平衡风阀和平衡水阀，使各部件的最大设计风量或水量能够达到，且**不超过设计值 15%**；
  - **每个独立运行、面积超过 1,000 m² 的空间和每一层**，须能单独切断风量，以便运行时间不同；
  - 关闭时，未被主动控制的电动新风阀和回风阀须关闭；
  - **J6D3(3) 时间开关**：制冷量超过 2 kWr 的空调系统、超过 1 kW 的空调用加热器须有可按不同时间和日期编程的时间开关（只服务一个 Class 2、3、9c SOU、Class 4 部分或须 24 小时连续空调的空间除外）。
  - 气候区 2（布里斯班）中，总风量**不少于 9,000 L/s** 的空调系统须有室外空气节能循环（economy cycle）（Table J6D3）。
- **装修是否须按 Section J 评估**：NCC 适用于新的 building work；改动部分按什么程度执行 J6、是否触发 Building Act s 61/s 81，由 certifier 决定（法规文件 1.4）。**待证实**：certifier 对租户装修通常要求哪些 J6 文件（风管保温和密封、新 split 的时间开关、温控分区说明）。

### 1.5 与 base building 机电顾问和 BMS 的接口（行业惯例，以 lease 和 fit-out guide 为准）
1. **资料**：开工前向楼宇要机械竣工图、AHU 和 VAV 表、冷冻水容量和接口、BMS 点表、fit-out guide 的暖通章节（指定品牌、控制器型号、指定承包商、审查费）。
2. **设计审查**：租户机械顾问出图后，提交 **base building 机电顾问审查**（常由业主收费），重点：负荷是否超过楼层分配、是否影响楼宇平衡、是否破坏火灾模式和楼梯加压、冷凝水和噪声。
3. **BMS**：新增 VAV、FCU、温控器、加班按钮（after-hours）通常须由**楼宇指定的 BMS 承包商**加点、改图形、改时间表和计费逻辑；租户自装的 split 是否须接 BMS 由 fit-out guide 规定。J6D3(1)(h) 要求空调系统能用末端控制信号直接调节中央设备 [S2]，也是 BMS 联动的理由之一。
4. **调试和交付**：风量平衡报告（每个风口实测值）、水平衡、BMS 点对点测试、温控测试、空调和 FIP 火灾模式联动测试（与消防承包商一起做），交 O&M 手册和竣工图给楼宇。
5. **AIRAH 资料**：AIRAH 网站从本环境打不开。据搜索摘要，AIRAH 的 **DA27 Building Commissioning**（2011 年，约 90 页，含既有建筑重新调试）是澳洲建筑调试流程的常用参考，另有 DA28（楼宇管理和控制系统）、DA24（暖通水系统平衡）等 DA 手册（均为付费资料，仅搜索摘要，版本待证实）[S21]。

## 2. 电气

### 2.1 配电箱、子电表和容量（法规 + 行业惯例）
- **执照**：所有 electrical work（布线、配电箱、接灯和插座、接空调、测试）须由持 electrical work licence 的个人做；builder 可以在总包合同里包电气工作，但要分包给持 electrical contractor licence 的电工（Electrical Safety Act s 55、s 56(3)(b)，见电气文件）。
- **容量**：租户配电箱（tenant DB）从楼层主配电板取电，**容量以 base building 的单线图和楼宇给租户的分配额为准**；增加大功率负荷（商业厨房、服务器间、医疗设备）要先向楼宇申请增容（行业惯例）。最大需量计算和导线选择按 AS/NZS 3000（付费；本文不写数值）。
- **子电表**：楼宇一般规定租户用电须经楼宇认可的子电表计量（计费用），型号和通讯方式见 fit-out guide（行业惯例）。NCC **J9D3**：楼面面积超过 500 m² 的建筑**或 SOU**，须有能记录燃气和电力分时用电的电表；超过 2,500 m² 的建筑还须分项计量空调、照明、设备用电等并接入单一监控系统（个别 SOU 面积小于 2,500 m² 的不适用分项要求）[S5]。装修面积超过 500 m² 的租户区是否须按 J9D3(1) 设分时电表，由 certifier 决定（**待证实**）。
- 停电、接入楼层主配电板须向楼宇申请，通常安排在营业时间以外（工序文件第 3 节）。

### 2.2 RCD（safety switch）
- 商业装修新回路的 RCD 覆盖范围由 **AS/NZS 3000** 规定（付费，**待证实**具体范围）。ESR 2026 s 28–30 的 safety switch 规定针对住宅，不直接适用于商业装修 [S11]。
- **交付后租户（PCBU）的义务**（ESR 2026 Pt 中「Service work or office work」一节，原文）[S11]：
  - **s 139**：工作场所里的固定 safety switch 须在**接上后立即**由 competent person 按 **AS/NZS 3760** 测试，之后按 AS/NZS 3760 规定的间隔测试；不合格的立即挂牌停用。
  - **s 138**：办公用的「specified electrical equipment」（例：给办公设备供电的插线板、延长线）须按期检测挂牌（只用于办公的至少每 5 年一次，其他至少每年一次），**或**接在 safety switch 上。
  - 对 builder 的意义：交付文件里写明各 RCD 的位置和首次测试记录，方便租户履行 s 139。

### 2.3 照明和照明控制（J7，NCC 2022 原文）[S4]
- 照明功率密度（J7D3、Table J7D3a）和装饰、展示照明分开控制（J7D5）已在法规文件 3.6 写过，这里只补 **J7D4 室内照明和电源控制**：
  - 每个房间或空间的照明须能单独开关（开关或其他控制装置）；
  - 开关须设在被控房间内，或设在能看到 90% 被控灯具的相邻空间，位置显眼、易到达；
  - **Class 5 建筑**（办公）：一个开关或控制装置控制的照明**面积不超过 250 m²**；Class 6 等：空间不超过 2,000 m² 时每个开关不超过 250 m²，超过 2,000 m² 时不超过 1,000 m²（礼堂、仓库等单一功能空间除外）；
  - 建筑或楼层面积超过 250 m²（Class 2、3 和 Class 4 部分除外）：**95% 的灯具**须由符合 Specification 40 的**时间开关**或**人员感应装置**（门禁读卡、移动感应器）控制；
  - **Class 5、6、8 建筑面积超过 250 m²**：靠窗的自然采光区（natural lighting zone）照明须与非采光区**分开控制**，除非房间小于 20 m²、采光区灯具少于 4 盏，或房间内 70% 以上灯具在采光区；
  - 防火隔离楼梯、通道的照明须用移动感应器控制；走廊、门厅等单区超过 250 W 且靠窗的，须用日光感应器加调光控制。
- **F6D5**：Class 5–9 建筑中经常使用的房间、无障碍空间、走廊、门厅、楼梯和疏散路线须有人工照明，人工照明系统须符合 **AS/NZS 1680.0**（付费，NCC 引用 2009 版）[S1][S9]。
- 实务：照明控制方案（DALI、感应器分区、时间表）在设计阶段与 J7 计算一起出，交 certifier；隔墙调整后要复核每个开关的控制面积和采光区（推断）。

### 2.4 应急照明和出口标志（AS/NZS 2293）
- **布置要求**以 NCC E4D2、E4D4–E4D6、E4D8 为准，摘要见法规文件 3.3 [S6]。NCC 2022 引用 **AS/NZS 2293.1:2018**（含 Amendment 1）作为系统设计、安装和运行标准 [S9]；商店显示已出 2026 版（法规文件 3.3）。
- **E4 原文没有定期测试条款**：检索 E4 全文（E4D1–E4D9），只有设置和符合 AS/NZS 2293.1 的要求，没有维护或测试间隔 [S6]。
- **定期检查测试**在昆州的依据：应急照明属于 BFSR 的 prescribed fire safety installation 时，occupier 须请 appropriately qualified person 维护，并**按 QDC MP6.1 规定的间隔检查测试**（BFSR s 54，最高 30 penalty units）[S13][S14]。维护标准 **AS/NZS 2293.2**（Routine service and maintenance，付费，2019 版，商店标为 Pending Revision）[S10]；MP6.1 具体引用哪本标准和多长间隔，本轮 MP6.1 PDF 下载失败，**待证实**。
- **谁做**（QBCC Regulation Sch 2 Pt 31，原文）[S15]：fire protection 电气类执照有 **Certify—emergency lighting** 和 **Inspect and test—emergency lighting** 两类；Pt 31 没有「安装应急照明」的执照类别，安装本身是电气工作，由持照电工做（推断：安装归 Electrical Safety Act，出证和定期检测归 QBCC Pt 31；持 electrical mechanic licence 的雇员可检测应急照明，见法规文件 3.3）。
- **装修中的做法**：①隔墙定稿后由电工按 AS/NZS 2293.1 复核应急灯和出口标志的覆盖和可见性；②新灯具接入原有应急照明回路或测试系统（集中监控式要加地址）；③完工做放电测试（时长按标准，**待证实**），记录交楼宇；④更新楼宇的应急照明清单和图纸（供 MP6.1 维护用）。

### 2.5 电工执照和 Certificate of Testing and Safety（ESR 2026，原文）[S11]
- **s 208**：持照 electrical contractor 完成须测试的电气工作后，须**尽快**向委托人交 **Certificate of Testing and Safety**（最高 40 penalty units），写明委托人姓名地址、测试的设备、测试日期、contractor licence 编号，并证明受影响部分的设备电气安全；contractor 保存副本**至少 5 年**（最高 20 penalty units）。
- 新装置首次接电还有 s 217 检查和 s 229 Certificate of Testing and Compliance（见电气文件）；租户装修一般从既有楼层配电取电，是否涉及配电商检查视工程而定（推断）。
- builder 收齐证书后交租户和楼宇（楼宇常要求副本存档）。

## 3. 通信布线：ACMA 布线员注册（Telecommunications (Cabling Provider) Rules 2025，已读原文）[S12]
- **新规**：Telecommunications (Cabling Provider) Rules 2025 自 **2025-03-31** 起施行，取代 2014 版规则。
- **三类注册**：**Lift**（电梯）、**Open**、**Restricted** [S12]。
  - **Open**：可做或监督客户布线终接于电信网络边界的 socket、network termination device 或 **main distribution frame** 的布线工作（s 8）。
  - **Restricted**：只能做终接于 socket 或 NTD 的布线，且场所供电电压不超过一般住宅单相、三相电压（或虽超过但电缆不可接触）；**不得**做终接于 MDF、跳线配线架（jumperable distributor/frame）、**配线架（patch panel）** 的布线，也不得做与其他业务共用护套的线对（s 9）。规则注释说 Restricted 一般用于住宅和小型商业场所。
- **结论**：办公楼结构化布线（工位到楼层机柜 patch panel）须由持 **Open** 注册的布线员做或直接监督（s 21）[S12]。
- **专项布线**：结构化布线、光纤、同轴、架空、地下、宽带布线属于 specialised cabling，布线员须另完成相应的能力单元并通知注册机构；**Open 可做全部专项布线，Restricted 只能做架空、宽带和地下布线**（s 22）[S12]。
- **未注册人员**：只能在持相应注册的布线员**全程直接监督**下工作，监督人对其工作负全部责任（s 21(d)）[S12]。
- **合规标准**：所有布线须符合 **Wiring Rules AS/CA S009:2020**（Communications Alliance 发布，规则注释说可免费下载）（s 23）[S12]。
- **完工声明**（s 25）：除跳线和更换插头、插座等小件外，布线完成后，做或监督该工作的注册布线员须尽快（不论是否已付款）出具声明：姓名、联系方式、注册证明，说明哪些布线已完成并**完全符合 Wiring Rules**，交给其雇主（或发包人）和委托客户；副本**保存至少 1 年**，ACMA 要求时提供。声明可以写在发票上 [S12]。→ builder 要把这份声明放进交付文件。
- **注册要求**（仅搜索摘要，ACMA 网站不通，待证实）：据 ACMA「Categories of cabling registration」页面和行业协会摘要，Open 注册要求至少 360 小时布线经验、Restricted 至少 80 小时，并完成相应培训 [S20]。
- 电气和通信布线的间距、共用桥架隔板等要求在 AS/CA S009 和 AS/NZS 3000 中（本文未读，待证实）。

- QFD 单张原文：业主改动火灾报警系统须**取得 building certifier 批准，由 certifier 转介 QFD**，现场消防员不能批准改动 [S18]。

### 4.2 谁能做：QBCC fire protection 执照（QBCC Regulation 2018 Sch 2，已读原文）[S15]
| Part | 执照类别 | 装修中对应的工作 |
|---|---|---|

| **Pt 31** Electrical stream | Design—fire alarm systems；Certify—fire alarm systems；Certify—emergency lighting；Install and maintain—fire alarm systems（**限特低电压系统**）；Inspect and test—emergency lighting | 报警系统和探测器、EWIS（属火灾报警类，推断）、应急照明出证和检测 |
| **Pt 22A** Passive stream | 防火封堵、防火门、防火墙和防火吊顶等 | 穿墙穿板封堵；builder 执照在 2035-05-02 前有过渡安排（法规文件 4.1） |
| Pt 25 Special hazard | 气体、泡沫等特殊灭火 | 服务器间气体灭火 |
| Pt 29 Portables | 灭火器、灭火毯 | 新增灭火器 |

- **给排水执照的消防背书**（Plumbing and Drainage Regulation 2019 Sch 4，原文）：water plumber—fire protection（commercial and industrial）和 plumbers licence 的 fire protection—commercial and industrial 背书，可以安装、维护、测试商业和工业喷淋系统 [S16]。持 fire protection 执照的人测试给排水属于 unregulated work（Sch 3 s 2）[S16]。
- **喷淋改动同时是给排水工作**：P&D Regulation Sch 1 Pt 2 item 2：与 Building Act 下 building development approval 相关的、在既有 Class 2–9 建筑中**延伸或拆除 fire service** 的工作属于 **notifiable work** [S16]。据此，获批的喷淋延伸在给排水制度下可能还要登记 Form 4——实务中由消防承包商还是 plumber 登记，**待证实**（向 QBCC 确认）。
- **无照罚则**：个人不得亲自做或监督 fire protection work，除非持 fire protection occupational licence（QBCC Act s 42C），fire protection 范围内的工作不论金额都要执照（法规文件 4.2、5.1）。

### 4.3 消防系统隔离（isolation）的流程
**QFD 规定（仅搜索摘要，原页面被网站防火墙拦截，待证实）**[S19]：
- 首选做法是在**火灾报警主机（FIP）上做局部隔离**，只隔离受影响的区，此时**不需通知 QFD 或监控服务商**；隔离须按经风险评估的程序进行。
- 隔离 **alarm signalling equipment（ASE，向 QFD 传信号的设备）** 只用于极端情况；局部隔离不可行时，向 QFD 的报警监控承包商（摘要中为 Johnson Controls）用 **OM129** 表格申请；**隔离超过 12 小时须 QFD 批准**。
- QFD Fire Alarm Management Unit 电话 1800 289 785（摘要）。

**QFD 单张原文** [S18]：
- 楼宇业主应「实施并执行现场施工管理计划，防止工人使用焊机、吹风机等工具引起报警」，在**产生粉尘、烟雾、蒸汽或喷漆的作业时保护和隔离探测器**。
- 「QFD 到场前不要复位或隔离火灾报警主机」——误报发生后不能自行复位。

**误报费用（QFD 2026-07-01 至 2027-06-30 收费表，原文）** [S17]：
- 任意连续 60 天内**第一次**误报不另收费（年度报警管理费已含）；**第二次起每次 $1,556.79**（免 GST）；由 QFD 以外服务商监控的系统，**第一次起**就按次收费。
- 按 Alarm Monitoring Agreement，费用向申请人即**楼宇业主**收取；QFD 单张说不赞成「转嫁」（on-charging）[S18]。但 lease 和 fit-out guide 常约定由造成误报的租户或承包商承担（行业惯例）——报价和分包合同里写清。

**builder 的隔离程序（行业惯例，以楼宇程序为准）**：
1. 前一天向楼宇管理处提交隔离申请：区域、探测器或喷淋阀、原因、开始和结束时间、负责人、hot works permit（如有）。
2. 由**持照消防技术员**（通常是楼宇的消防维护公司）在 FIP 上做局部隔离，或关闭喷淋区阀；builder 自己的人不得操作 FIP 或阀门。
3. 涉及 ASE 或整栋隔离的，由消防公司按 QFD 程序通知监控中心（OM129），超过 12 小时须 QFD 批准（摘要，待证实）。
4. 隔离期间执行受损期间措施（4.4）。
5. 每天收工前恢复：探测器摘罩、FIP 恢复、喷淋阀全开并锁定（或加防篡改监测），消防技术员和楼宇确认，双方在隔离登记簿上签字。
6. 记录：隔离开始和恢复时间、执行人和执照号、恢复后测试结果。

### 4.4 系统受损期间（impairment）的管理和临时措施
- **法规依据**：BFSR 2008 把可能使设施失效、并在火灾时很可能严重影响人员安全的缺陷定义为 **critical defect**（例：使火灾探测报警系统失效、使消火栓泵失效）；维护人员发现后须在维护后 **24 小时内**用批准表格通知 occupier（s 49、s 53）[S13]；维护记录显示需修理的，occupier 须在维护后 **1 个月内**完成（有合理理由除外，s 54(4)）[S13]。这些是维护制度的规定，施工中的计划隔离怎样适用，**待证实**。
- **AS 1851**（付费，消防系统和设备的例行维护标准，2012 版含 Amendment 1，商店标为 Pending Revision）[S10] 是行业处理系统停用（impairment）的常用依据；具体程序本文未读，**待证实**。
- **占用人的持续义务**：Fire Services Act 1990 s 146M 要求占用人随时把每项 prescribed fire safety installation 维持在安全可靠状态（抗辩之一是有同等或更有效的替代措施）；s 150A 禁止故意非法遮盖或干扰报警设备——探测器加罩只能在批准的隔离程序下做（已由楼宇接口文件 3.3 核对原文）。这也是隔离期间要有补偿措施的法律理由。
- **临时措施（行业惯例）**：
  - 隔离范围尽量小、时间尽量短（按区、按天），喷淋关阀前确认其他区不受影响；
  - **fire watch**：隔离区安排专人巡查，配灭火器，知道最近的手动报警按钮和疏散路线；
  - 隔离期间禁止或严格限制热工作业（hot works permit 要和隔离同时考虑，工序文件第 3 节）；
  - 喷淋管排空改管时，当天能恢复就当天恢复；跨夜的，按楼宇要求加强巡查或临时措施，并通知楼宇保险人（是否须通知保险人，以楼宇保险条款为准）；
  - 告知受影响的其他租户和楼宇消防管理人员（fire warden）；
  - 疏散路线和出口在施工全程保持畅通（BFSR s 7、8、11，法规文件 5.3）。

### 4.5 完工后的测试、证书和维护记录
1. **测试**（由持照消防承包商做）：喷淋水压试验、末端试水、喷头位置和遮挡检查；探测器逐点功能测试、FIP 区号和图形更新、EWIS 扬声器和闪灯测试；与空调火灾模式、门禁失效解锁、电梯归首层等联动测试；应急照明放电测试。
2. **出证**：water-based 和 electrical 的 **Certify** 类执照持有人出具安装合规证书；certifier 按其要求收 Building Act 法定表格（例如 Form 12 Aspect inspection certificate、Form 15 Compliance certificate，以 certifier 要求为准，见法规文件 5.1）。
3. **QFR 检查**：涉及 special fire service 安装的，Building Act s 74 要求安装人在安装过程中和完工后、室内表面装修前通知 QFR 检查和测试（见 `01-法规标准/高层建筑-规划审批与消防审查.md` 4.4）。普通租户装修只移动少量喷头和探测器时是否触发 s 74，**待证实**（问 certifier）。
4. **竣工资料**：消防设施清单和位置图交 certifier（Building Act s 102(1)(b)）；装修涉及 special fire service 的，按 BFSR Part 6 付 QFR 评估检查费，**不改动 special fire service 的 fit-out 只付 base fee**（s 59）[S13]。
5. **维护记录（BFSR 和 MP6.1，已读原文）**：
   - **MP6.1** 适用于 Class 1b 和 Class 2–9 建筑（**包括既有建筑**）；有 prescribed fire safety installation 的楼宇，业主或占用人须遵守 MP6.1 [S14]。
   - occupier 须请 appropriately qualified person 维护，按 MP6.1 间隔检查测试（s 54）；维护人员须按 MP6.1 维护（s 50）[S13]。
   - **维护记录**须写明：设施名称；维护人（或监督人）姓名和执照号；维护日期；维护内容；**按 MP6.1 进行的声明**；结果（是否正常工作、需要的修理、已做修理及日期）；维护人签字；如有 critical defect notice 须附上（s 55，最高 20 penalty units）[S13]。
   - **occupier statement**：按 MP6.1 的间隔编制，与维护记录一起保存 **2 年**，须编制之日起 **10 个工作日内**交 QFD commissioner（s 55A）；Business Queensland 说明为**每年**一次 [S13][S14]。
   - **多租户楼宇**（Business Queensland 原文）：通常各租户负责**自己租区内**的消防设施，楼宇管理方负责公共区域和室外的设施；例如餐厅租户负责厨房内灭火器的维护，并与其他租户协调公共区消火栓的维护；分工可通过楼宇管理方或租约约定。租户占用的，由租户确保维护；业主自用的，由业主负责 [S14]。
   - **对 builder 的意义**：交付时把新增和移位的消防设施清单、竣工图、测试记录交给**租户和楼宇管理方**，写明哪些设施归租户维护，便于其纳入 MP6.1 维护和 occupier statement。

### 4.6 Fire engineer 和 Performance Solution 的情形
- **常见触发情形（行业经验，是否须 Performance Solution 以 certifier 判断为准）**：开放办公区隔成房间后疏散距离超过 D2D5（例如 Class 5 到出口 20 m 或到分岔点 20 m 且到其一出口 40 m）；疏散须经过另一租户区；加夹层（mezzanine）；拆除或减少喷头（例如小房间、冷库、服务器间改气体灭火）；超过防火分区面积；改变分类（办公改餐饮、诊所）后原有消防设计不再满足；楼宇原有 fire engineering report（FER）中的条件（例如饰面材料、人数、疏散路线）被装修改变。
- **楼宇原有 FER**：楼宇如采用过 Performance Solution，certificate of occupancy 上会写明所需的材料、系统、管理程序（Building Act s 103，法规文件 1.5）。装修设计前要向楼宇要 FER 和入住证，确认装修不违反其中条件（推断）；如须改动，由 fire safety engineer 出补充报告。
- **审批路径**：消防 Performance Solution 须按 NCC Performance Requirements 评估，属于 Planning Regulation 2017 Sch 9 Pt 3 Div 3 Table 1 的转介情形，转介 Queensland Fire（advice agency，只能给建议）（见 `01-法规标准/高层建筑-规划审批与消防审查.md` 4.2、4.5）。
- **QFR 收费（BFSR 原文）**：申请人请 QFR 评估 fire engineering brief 的，按 Part 6 Division 3 计费（评估检查费 =（base fee + special fire service fee 合计）× 2，另加研究费、FEB 咨询费、每次会议费）（s 61–62）；施工中请 QFR 参加与 certifier 讨论替代方案的 **minor performance meeting**，另付研究费和会议费（s 63）[S13]。具体金额见 Schedule 2，本文未摘录。
- **工期影响**：FEB、FER、转介和 QFR 意见会增加设计周期，报价时列为风险项（推断）。

## 5. 给排水

### 5.1 茶水间、卫生间的新增和改动：notifiable 还是 permit（Plumbing and Drainage Regulation 2019，已读原文）[S16]
- 规则：Sch 1 Pt 2 列出的工作是 **notifiable work**（完工后由 plumber 向 QBCC 登记 **Form 4**）；不属于 notifiable、minor、unregulated 的工作都是 **permit work**（开工前由 plumber 向 council 递交 **Form 1** 申请许可，council 检查后出证）。表格和 BCC 收费见给排水文件。
- **Sch 1 Pt 1：以下情形不属于 notifiable work（即须走 permit）**：接 **combined sanitary drain** 的洁具安装；接 dual reticulated water supply；**trade waste 工作或与 trade waste 相连的工作**；**使用 Performance Solution 的工作** [S16]。
- **Sch 1 Pt 2 中与商业装修有关的几项** [S16]：
| item | 内容 | 适用建筑 |
|---|---|---|
| 1 | 延伸、改动、更换、拆除供水管（消防供水管除外） | 既有建筑 |
| 2 | 延伸或拆除 fire service（须与 building development approval 相关） | 既有 Class 2–9 |
| 3 | 延伸、改动、更换、拆除 **sanitary plumbing**（楼内卫生管道） | 既有建筑 |
| 4 | 同上，针对 **sanitary drainage**（排水管道，combined sanitary drain 除外） | **只限** Class 1、10 |
| 5、6、7 | 温控阀、热水器、testable 回流防止装置的安装、更换、拆除 | 既有建筑 |
| **10** | **安装或移位洁具**（sanitary drainage 部分除外） | **只限 1 层或 2 层的既有 Class 2–9 建筑** |
| 12 | 封堵水表下游的供水管 | 既有 Class 2–9 |
- **builder 的判断（据条文推断，开工前由 plumber 用 QBCC「Is this notifiable work?」工具或问 council 确认）**：
  - 1–2 层商业建筑里加或移茶水间水槽、洗手盆，只改楼内供水和 sanitary plumbing → 一般属 notifiable（Form 4）；
  - 要改 **sanitary drainage**（地下或楼板下排水管，例如首层店铺新卫生间接入地下排水）→ Class 2–9 不在 item 4 范围内 → permit work（Form 1）；
  - **3 层及以上**的写字楼、商场里新增或移位洁具，不在 item 10 范围内 → 很可能是 permit work；但 item 1、3 又把既有建筑的供水管和 sanitary plumbing 改动列为 notifiable，两者如何组合（**待证实**，以 council 或 QBCC 意见为准）；
  - 接隔油池、商业洗碗机等 trade waste → permit work，另须 Urban Utilities trade waste 审批（见餐饮文件 1.4）；
  - 换热水器、装 TMV 或 testable 回流防止装置 → notifiable（item 5–7）；testable 装置还有定期测试要求（见给排水文件）。
- **NCC 配合**：新卫生间的数量（F4）和无障碍卫生间见法规文件 3.4、3.5；卫生间不得直接开向多人工作场所，须气闸或机械排风加遮挡（F6D9、F6D10，见 1.3）；湿区防水按 F2D2 和 Specification 26（工序文件 2.7）。
- **base building 接口（行业惯例）**：立管位置、预留接口、坡度和楼板开洞（后张预应力楼板开洞须结构工程师扫描和批准）在 lease 和 fit-out guide 中确认；楼上加卫生间要在下层租户的吊顶内走管，须提前协调进场。

### 5.2 Trade waste
- 不在本文展开，见 `02-建造流程/商业装修专项-餐饮诊所与绿色评级.md` 1.4（Urban Utilities trade waste 审批、隔油池触发条件等）。注意：trade waste 相关的给排水工作被 Sch 1 Pt 1 排除在 notifiable work 之外 [S16]。

## 6. 机电协调

### 6.1 吊顶内综合协调：优先顺序（行业惯例，不是法规；以项目协调图为准）
1. **先做现场测量**：楼板底、梁底、既有主风管和喷淋主管的标高，算出可用的吊顶空间。
2. **优先顺序**（越靠前越难改）：
   1. **重力排水管**（有坡度要求，最难绕）；
   2. **大截面风管**（主风管、回风和排风管、厨房排烟管，后者还有防火和间距要求）；
   3. **喷淋支管**（喷头位置要服从吊顶板格，支管要为喷头让位）；
   4. **电缆桥架和数据桥架**（相对灵活，但要留出放线和检修空间，与喷淋管、热水管保持间距）；
   5. **灯具、风口、探测器、扬声器等吊顶面设备**（在综合天花图 RCP 上统一定位）。
3. **吊顶面设备的协调**：喷头、烟感、灯具、风口、扬声器、闪灯、出口标志、检修口在 RCP 上一次定位；喷头不得被灯具、bulkhead 或吊柜挡住喷洒，探测器不得靠近送风口（具体距离按 AS 2118.1、AS 1670.1，付费，本文不写数值）。
4. **吊挂**：吊顶龙骨不得挂在喷淋管、风管或桥架上（工序文件 2.4）；各工种各自独立吊挂；在后张预应力楼板上打锚栓前要扫描（行业惯例）。
5. **防火构件穿越**：风管穿防火墙装防火阀，管线穿越用经测试的防火封堵（Pt 22A 执照范围，法规文件 3.1、4.1）。

### 6.2 预留检修口（行业惯例 + 工程推断）
- 须能到达的设备：VAV box 和控制器、FCU（过滤网、冷凝水盘、阀门）、**防火阀和防烟阀**（复位和测试）、冷冻水和给水阀门、电气接线盒和驱动器、BMS 控制器、吊顶内探测器（如有）、给排水清扫口。
- 检修口尺寸要够人和工具进入，位置避开家具和灯具；暗架石膏板吊顶尤其要在 RCP 上标清（明架矿棉板吊顶可直接掀板）。
- **防火吊顶**上的检修口须用经测试的防火检修口，否则破坏吊顶的防火性能（推断，按系统测试报告）。
- 交付时在竣工图上标出所有检修口和其后的设备，交 O&M 手册（MP6.1 维护和日常保养都要用）。

### 6.3 机电图纸审查要点（看图时逐项核对）
| 类别 | 审查要点 |
|---|---|
| 资料完整性 | 有没有 base building 机械、电气、消防、给排水竣工图和 fit-out guide；楼宇是否有 FER、入住证上的条件；指定承包商名单 |
| 暖通 | 每个封闭房间有送风和回风（或转接风管）；新房间的温控分区和 VAV/FCU 表；内区房间的新风是否满足 F6D6（只有分体空调的房间是否另有自然通风）；风管保温和密封（J6D6、J6D7）；新 split 的时间开关（J6D3(3)）；室外机位和冷凝水；火灾模式联动；噪声 |
| 电气 | 租户 DB 容量和楼宇分配；子电表；RCD 分组；照明功率密度计算（J7D3）；开关控制面积不超过 250 m²、95% 灯具受时控或感应控制、采光区单独控制（J7D4）；展示照明分开控制（J7D5）；应急灯和出口标志布置与新隔墙一致（E4） |
| 通信 | 布线员持 Open 注册且有结构化布线能力单元；机柜位置、散热和供电；与强电的间距 |
| 消防 | 喷头和探测器按新隔墙布置、数量变化是否超过 20%（是否须审批）；吊柜、bulkhead 下的覆盖；EWIS 扬声器和闪灯；疏散距离和出口；是否须 fire engineer；消防承包商执照类别（Pt 26、31）；隔离计划 |
| 给排水 | notifiable 还是 permit；接驳点和坡度；楼板开洞是否须结构扫描和批准；trade waste；卫生间门的位置（F6D9） |
| 综合 | 吊顶空间够不够；各系统交叉点；检修口；防火封堵节点；施工顺序（隐蔽前验收、吊顶封板前完成测试和 QFR 检查） |
