# NCC实用尺寸速查-住宅

## 摘要
本文把 builder 在 Class 1a 住宅（含附属 Class 10a 车库）工地上最常用的 Deemed-to-Satisfy（DTS）尺寸，从 **ABCB Housing Provisions（NCC 2022 版）** 原文摘出来，做成一张可以带到现场的速查表。每条都写明条款号，并核对过有没有昆州（QLD）变体。内容包括：楼梯、栏杆、卧室窗户防坠落、房间净高、地板下通风和净空、天沟和落水管、湿区防水范围、防潮层高度、白蚁检查净空、烟雾报警器位置、采光和通风面积、无障碍和宜居设计、车库与住宅的防火分隔、外墙到边界的防火距离。原文没有给数字的项目不写数字，只写「原文未规定」或「见付费标准」。省钱方面：这些尺寸是 frame 检查和 final 检查最常被挑出来的地方（栏杆、楼梯、窗户限位器、烟雾报警器），在放线和定货阶段就按这张表做，可以避免封板后再拆改。

适用州：QLD（全国文本 + 已核对的 QLD 变体）｜资料核对日期：2026-11-21｜状态：已核实（条文均读 ncc.abcb.gov.au 原文）；个别项目标「待证实」

> **版本提醒**：昆州现行 NCC 2022。**NCC 2025 在昆州 2027-05-01 实施后，本文所有条款号和数值都需要复核**（过渡规则见 `01-法规标准/NCC现行版本与住宅要求.md`，差异见 `01-法规标准/NCC2025与NCC2022差异对照.md`）。
>
> **怎么用**：Housing Provisions 是 DTS 做法之一。NCC Volume Two 的 H 部分规定「按 Housing Provisions 某 Part 做即满足某性能要求」，例如 H5D2（楼梯）、H5D3（栏杆）[S1]。设计采用 Performance Solution 或其他标准的，以批准图纸为准。
>
> **QLD 变体核对结果**：本文引用的 Part 4.2、5.7、6.2、7.4、9.2、9.3、9.5、10.2、10.3、10.5、10.6、11.2、11.3 的原文页面里，变体只出现在 NSW、SA、NT 等州；**没有 QLD 变体**（Part 3.3 本次未重新下载核对）。QLD 变体只在 Part 3.4（白蚁）。NCC Volume Two 的 H3、H4、H5 也没有 QLD 变体（H5 只有 SA 变体）[S1]–[S14]。

## 12. 无障碍和宜居设计
- **NCC Volume One 的无障碍要求（Part D4、AS 1428.1）不适用于 Class 1a 独立住宅**。Volume Two（Class 1 和 10）的 H 部分没有通用的残障人士通行条款（只有 SA 有 Part H10 变体）[S1]。
- 但 **NCC 2022 Vol Two H8D2**：Class 1a 住宅要符合 **ABCB Standard for Livable Housing Design**；在没有经车库、车棚或车位的无台阶通道，且同时满足下列任一条件时，可免除该标准第 1.1 条（无台阶入口通道）：通道所在地面平均坡度超过 **1:14**；坡道长度或坡度会超过第 1.1(4) 条的限制；场地空间不够；或从边界或车位到入口门的高差需要超限的坡道。**其他条款仍要满足** [S14]。
- 昆州的配套规定在 **QDC MP4.5**（见 CLAUDE.md 第五节和 `01-法规标准/NCC现行版本与住宅要求.md`）。LHD 标准本身的门宽、走廊宽等数字本文没有摘录（ABCB 另行发布的标准）。

## 13. 车库与住宅的防火分隔（Class 10a 与 Class 1）
- **同一住宅自己的车库（associated Class 10a）**：9.2.1 外墙防火距离不计「与该 Class 1 相关的附属 Class 10」；9.3.1 的分隔墙要求只针对 Class 1 之间，以及 Class 1 与**不相关**（not associated）的 Class 10a 之间。Part 9 中**没有找到**要求住宅与其自用车库之间做防火墙的 DTS 条文（这是阅读结论，以 certifier 意见为准）[S15][S16]。
- **与不相关的 Class 10a 之间的分隔墙**（9.3.1）[S16]：FRL **≥60/60/60**，或 **≥90 mm 厚砌体**；从基础或地坪起；不燃屋面时做到屋面板底，可燃屋面时高出屋面 **≥450 mm**；除 75×50 mm 以下的屋面挂瓦条和 sarking 外，不得有木材等可燃构件穿过；墙顶与屋面板之间的缝用矿棉等防火材料填实；与砖饰面外墙之间的缝 **≤50 mm** 并填实。穿墙电缆开孔：单根电缆 ≤2000 mm²（缝宽 ≤15 mm），其他 ≤500 mm²，距其他管线 ≥50 mm，并填实（9.3.2）。
- **车库位于住宅和边界之间**（9.2.4、9.2.5）：车库离边界 **≥900 mm**；或车库在 900 mm 内的外墙按 9.2.3 做防火；或住宅离车库 ≥900 mm；或住宅对着车库、距离 <900 mm 的外墙按 9.2.3 做（共 9 种方法，见 Figures 9.2.5a–i）[S15]。
- **车库位于住宅和同地块另一建筑之间**（9.2.6）：同样的思路，距离改为 **1.8 m** [S15]。
- **开敞车棚（carport）豁免**（9.2.8）：至少两边开敞、且开敞部分不少于周长 1/3（屋面距其他建筑或边界 ≥500 mm 的一边才算开敞；车库门一边不算开敞）；屋面为聚碳酸酯或不燃材料，吊顶和墙面板（含山墙）不燃；不直接竖向支承住宅；与住宅共用屋面、没有吊顶的，住宅墙顶到屋面板之间要用不燃材料封堵 [S15]。
- **车库上方的住宅（garage top dwelling）**：Part 9.4（本次未摘录数字）；Part 9.5 对位于车库上方、且与车库无关联的住宅另有热感报警器要求（该款出现在 NSW 变体文本中，全国文本此处未见）[S11]。

## 14. 外墙到边界和其他建筑的防火距离（Part 9.2）

| 项目 | 数值 | 条款 |
|---|---|---|
| 外墙须做防火的条件 | 外墙距**邻地边界 <900 mm**（临路或公共空间的边界除外），或距同地块**另一建筑 <1.8 m**（附属 Class 10 和同一住宅的分离部分除外） | 9.2.1 [S15] |
| 量法 | 从边界或另一建筑外墙垂直量；只有距离内的那部分墙需要做；高低不同的建筑从较高的外墙量 | 9.2.2 [S15] |
| 防火外墙构造 | FRL **≥60/60/60**（从外侧测试），或外叶 **≥90 mm** 的砖饰面，或 **≥90 mm** 砌体；从基础或地坪起，做到不燃屋面板底（距屋面板 ≤200 mm 且用不燃封檐板、天沟或泛水封闭也可）或不燃檐口吊顶底 | 9.2.3(1)(2) [S15] |
| 防火外墙上的开口 | 不可开启的防火窗或 FRL ≥–/60/– 的构造；或自闭实心门 **≥35 mm 厚** | 9.2.3(3) [S15] |
| 开口豁免 | 非居住房间的窗，距邻地边界 ≥600 mm 或距同地块建筑 ≥1.2 m：浴室、洗衣房、厕所开口 ≤1.2 m²；其他房间 ≤0.54 m² 且为钢框、不可开启、夹丝玻璃，或玻璃砖 | 9.2.3(4) [S15] |
| 不受开口限制的 | 地板通风口、屋面通风口、weepholes、控制缝、施工缝、管线穿孔 | 9.2.3(5) [S15] |
| 允许伸入 900 mm / 1.8 m 范围内的 | 不燃封檐板、天沟、落水管；灯具、电表、燃气表、天线；花架（无顶）、遮阳帘、水箱；高度 ≤1 m 的无顶平台、台阶和坡道（deck 不算无顶平台） | 9.2.9(3) 及说明 [S15] |
| 允许伸到距边界 450 mm（距同地块建筑 900 mm）为止的 | 可燃封檐板、天沟、落水管；屋面和吊顶都不燃的屋檐；烟道、烟囱、管道、燃料罐、冷暖设备 | 9.2.9(4) [S15] |
| 可燃天窗 | 位于须为不燃屋面的屋面上的：总面积 ≤屋面 20%；距边界 ≥900 mm；距同地块另一建筑的天窗 ≥1.8 m | 9.2.10 [S15] |
- ⚠ 州差异：SA 变体另有「距 brush fence 3 m」等规定，不适用于 QLD [S15]。规划层面的退界（例如布里斯班 MP1.1/1.2）是另一套规定，见 `01-法规标准/布里斯班规划与地块限制.md`；防火距离和规划退界要同时满足。
