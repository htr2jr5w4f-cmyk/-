# 读懂结构图与土壤报告

## 摘要
本文是 builder 拿到一套住宅图纸后，读土壤报告（site classification report / geotechnical report）和结构图（structural drawings）的方法。土壤部分讲：AS 2870 的 A/S/M/H/E/P 场地分类（以 ABCB Housing Provisions 4.2.2 原文为准）、钻孔记录（borelog）怎么看、ys 值是什么意思、填土和软土、分类对楼板设计的影响，以及什么情况一定要工程师设计。结构图部分讲：general notes（混凝土等级、保护层、钢筋符号、搭接、拆模）、楼板平面和剖面、边梁详图、tie-down 和 bracing 平面、钢梁写法、过梁表。最后讲图纸冲突怎么办（RFI，以工程师为准），以及哪些改动必须找 RPEQ。依据是 Housing Provisions Part 4.2 和 Part 6.3、QBCC《Defective residential construction work causing subsidence – Contractor's responsibilities》（2021-01）、Professional Engineers Act 2002 (Qld) s 115 和 Business Queensland 的 competent person 页面。AS 2870、AS 3600、AS/NZS 4671 是付费标准，其中的数值不写或标「待证实」。省钱方面：QBCC 处理沉降类缺陷时，要求 builder 拿出 RPEQ 的书面确认，证明场地识别、分类、设计和按图施工都做到了。这些证据缺一项，返工费就可能落在 builder 身上；而读懂图纸，可以在浇筑前发现冲突。

适用州：QLD｜资料核对日期：2026-11-21｜状态：部分待证实（Housing Provisions、QBCC 沉降政策、Professional Engineers Act 已读原文；ys 分级数值和钢筋/型钢符号的标准定义来自付费标准，标「待证实」）

> 本文不重复 `施工工法要点-builder视角.md`（防潮膜 4.2.8、保护层与搭接 4.2.11、混凝土 4.2.10、填土 4.2.4、H1D4(2) 适用范围）、`混凝土与砌体详解.md`（浇筑、养护、砖墙过梁 5.6.6）和 `木框架详解.md`（AS 1684 的 tie-down 与 bracing 方法）的内容。需要时直接看那三篇。

## 一、土壤报告（site classification report）

### 1.1 法律和政策上为什么必须有
- Housing Provisions **4.2.2**：基础和楼板所在的地基必须按 **AS 2870** 分类 [S1]。
- QBCC 的 Rectification of Building Work Policy（沉降部分）把三件事列为**承包商的责任**：①场地识别；②场地分类和工程师设计；③按设计施工。要满足这项政策，builder 必须从 **RPEQ** 拿到书面确认，证明 Schedule 1 (a)–(f) 各项都做到了 [S2]。
- QBCC 列出的要求（节选）[S2]：
  - builder 要把场地资料交给工程师，包括地址或照片、本地块和邻地块的树木、等高线、现有地表漫流、建筑位置和平台标高、挖填位置、分区填土（subdivisional fill）范围；还要做必要的土地查询（洪水、地下管线、地役权、植被保护、分区填土）。如果是业主自己请的分类人或工程师，builder 也要拿到工程师的证明，说明这些资料已经考虑进去。
  - 工程师或其代表到过现场；土样由工程师或**持 QBCC 执照的 soil tester** 采取。
  - 钻孔（exploration positions / bore holes）位于**拟建房屋的投影范围内**，并深入最终平台标高以下；**至少 2 个**，钻到岩石拒钻，或钻到季节影响深度并低于最终平台标高。
  - 土样按 **AS 1289** 做试验来定分类；**反应性黏土场地的报告要有 Iss 和 ys 值**（由收缩-膨胀试验得出）。
  - 基础落在填土上、而设计没有用墩穿过填土的，不论有没有 Level 1 压实证书，工程师都要写明进一步检测或改良填土的要求，或者书面说明不需要墩的理由。

### 1.2 场地分类（Housing Provisions Table 4.2.2，说明性表格原文）[S1]
| 类别 | 原文描述（意译） |
|---|---|
| **A** | 大部分砂土和岩石场地，含水量变化引起的地面移动很小或没有 |
| **S** | 轻微反应性黏土，含水量变化只引起轻微地面移动 |
| **M** | 中等反应性黏土或粉土，可能有中等地面移动 |
| **H** | 高反应性黏土，可能有较大地面移动（AS 2870 再分 H1、H2，见 1.3） |
| **E** | 极高反应性黏土，可能有极大地面移动 |
| **A to P** | 填土场地，见 AS 2870 |
| **P** | 含软土（软黏土、软粉土、松砂）；滑坡；采矿沉陷；湿陷性土；易受侵蚀的土；含水条件异常的反应性场地；或无法归入其他类别的场地 |

表注原文要点 [S1]：
- M 类还要按预期移动深度细分；设计吸力变化深度 **Hs ≥ 3 m**（干旱气候的深层移动）时必须定为 **M-D**；**M-D 超出 Housing Provisions 范围**，要按 AS 2870 设计。
- 说明部分：**场地为 H、E 或 P 类时，必须按 AS 2870 设计和施工**（Housing Provisions 的楼板和基础表格不能用）。
- ⚠ Housing Provisions 的表格里只写「H」，没有 H1/H2。H1/H2 是 AS 2870-2011 里的细分（付费）。土壤报告会写 H1 或 H2，二者对应的设计不同。

### 1.3 ys 值是什么
- **ys（characteristic surface movement，特征地表移动量）**：在设计条件下，反应性黏土因含水量变化预计产生的地表竖向移动量，单位 mm。分类主要按这个值来定。QBCC 要求反应性黏土场地的报告给出 Iss（shrink-swell index，收缩-膨胀指数）和 ys [S2]。
- 公开土工报告里转引的 AS 2870-2011 分级如下。这些数值来自付费标准，本文只看到二手转引，**标「待证实」**，以 AS 2870 原文和报告本身为准 [S9]：
  - S：0–20 mm；M：20–40 mm；H1：40–60 mm；H2：60–75 mm；E：> 75 mm。
- **读报告时要看**：ys 是在什么假设下算的（土层剖面、Hs、有没有树木影响）；报告是否写了「abnormal moisture conditions」（异常含水条件）；分类旁边有没有附加条件（例如「H1 provided fill is controlled」）。

### 1.4 钻孔记录（borelog）怎么看
钻孔记录的格式按 AS 1726（岩土勘察，付费）。下面是常见栏目和 builder 要看的地方（通用做法，栏目名称以报告为准）：
| 栏目 | 看什么 |
|---|---|
| 钻孔编号和位置（BH1、BH2…） | 是否在房屋投影范围内、是否至少 2 个（QBCC 要求）[S2]；对照场地图上的位置 |
| 深度（m）和地面 RL | 是否钻到最终平台标高以下；挖方地块要核对平台标高和钻孔起点标高的关系 [S2] |
| 土层描述 | **FILL（填土）**、TOPSOIL、CLAY / Silty CLAY（注意塑性高低）、SAND、风化岩；填土要看厚度、成分（有没有垃圾、砖块、有机物） |
| 稠度 / 密实度 | 黏土的 soft / firm / stiff / very stiff / hard；砂土的 very loose / loose / medium dense / dense。出现 **soft** 或 **loose** 就要注意是不是 P 类（QBCC 把承载力低于 100 kPa 的软土列为异常场地条件）[S2] |
| 含水状态 | dry / moist / wet；是否遇地下水（groundwater encountered / not encountered） |
| 现场试验 | 动力触探（DCP）、袖珍贯入仪（pocket penetrometer）读数；用来估算承载力 |
| 取样 | U50（原状样）等，用于收缩-膨胀试验 |
| 终孔原因 | refusal（拒钻，可能是岩石或硬层）或达到目标深度 |

**builder 的检查动作**：
1. 钻孔位置对不对：如果房屋位置后来移动过，原来的钻孔可能已不在投影内，要请工程师复核 [S2]。
2. 有填土：厚度是多少？Housing Provisions 只覆盖 controlled fill 和 rolled fill 的有限厚度（4.2.4，见 `施工工法要点-builder视角.md`）；超出范围要工程师设计 [S1]。
3. 软土或松砂：是否被定为 P 类，基础是否改为墩或桩。
4. 开挖后看到的土和报告不一样（例如遇到未记录的填土、垃圾、软土、地下水）：**停工**，书面通知工程师和 certifier 后再继续（行业通行做法；法定 excavation 检查也是这个时点，见 `审批流程与法定检查阶段.md`）。

### 1.5 填土和软土
- Housing Provisions **4.2.5** 对地基承载力的规定 [S1]：
  - 楼板、承重板块和内梁：天然土容许承载力 ≥ **50 kPa**，或按 4.2.4 压实的 controlled / rolled fill；
  - 与楼板相连的边梁：天然土 ≥ 50 kPa，或按 4.2.4(a)(iii) 压实的 controlled fill，且填土要伸出建筑周边 **1 m**、坡度不陡于 **2:1（水平:竖向）**（Figure 4.2.5）；
  - 独立柱基、条形基础和不与楼板相连的边梁：天然土 ≥ **100 kPa**；A、S 类场地可以落在按 4.2.4(a) 压实的 controlled sand fill 上。
- 4.2.5 说明部分：受施工扰动的土承载力会大幅变化（典型如坡地挖填）；填土超出规定分层深度的，要按 H1D4(1) 处理，也就是按 AS 2870 / AS 3600 设计 [S1]。
- QBCC 列出的**异常场地条件**（沉降政策原文）[S2]：软土（未压实填土、分区开发填土，包括软黏土、软粉土、松砂，承载力低于 100 kPa）；滑坡；采矿沉陷和湿陷性土；易受侵蚀的土；含水条件异常、不能归为 A、S、M、H、E 的反应性场地；以及影响分类的异常含水条件，例如**近期拆除了旧建筑**、要保留或填平的排水沟、池塘、水坝或水箱、施工前**移走了大树**、树木离基础太近（包括邻地块的树）。
- QBCC 在 Standards and Tolerances Guide 里写明，因填土或压实不足造成的基础移动，即使有 Level 1 compaction certificate，也算缺陷（已在 `施工工法要点-builder视角.md` 引用）。

### 1.6 分类对楼板设计的影响
- **能用 Housing Provisions 表格的范围**：A、S、M 类（不含 M-D），并满足 H1D4(2) 的全部限制（板长宽不超过 18 m、最多一个内凹角等，见 `施工工法要点-builder视角.md` 第 3 节）[S1]。
- 同一种做法，分类越差，梁越深、钢筋越多。以加劲筏板（stiffened raft）为例，**Table 4.2.14c（M 类）** 原文 [S1]：
  | 墙体做法 | 梁深 D (mm) | 梁底筋 | 梁最大中距 (m) | 板网 |
  |---|---|---|---|---|
  | Clad frame（轻质外墙框架） | 300 | 3-L11TM | 6.0 | SL72 |
  | Articulated masonry veneer | 400 | 3-L11TM | 6.0 | SL72 |
  | Masonry veneer | 400 | 3-L11TM | 5.0 | SL72 |
  | Articulated full masonry | 500 | 3-L12TM | 4.0 | SL82 |
  | Full masonry | 850 | 3-N16 | 4.0 | SL92 |
  表注：内外梁要形成整体结构网格；某一方向间距比规定小 20% 时，另一方向可加大 10%；外梁宽度超过 300 mm 时，每多 100 mm 要加一根同规格底筋；梁上直接砌筑并与梁连接的配筋单叶砌体墙，梁可减为 300 × 300 mm、配 3-L8TM [S1]。
- A、S 类用 Table 4.2.14a/b，M 类用 4.2.14c；条形基础用 Tables 4.2.15a–c；**填充式楼板（infill floors）只能用于 A、S 类**（4.2.15）[S1]。
- **4.2.21 边梁最小尺寸**：footing slab 的边梁在企口（rebate）底部的宽度不小于 **200 mm**；如果有 R10 或 N10 箍筋 @900 mm（或等效）抵抗竖向力，可减到 **150 mm** [S1]。
- **H、E、P 和 M-D**：要按 AS 2870 由工程师设计。QBCC 原文：异常场地通常由工程师定为 P 类，并注明按 A、S、M、H、E 估计的移动潜力；P 类场地的基础要按 AS 2870 和 AS 3600 的工程原则设计 [S2]。另外，QBCC 引用 AS 2870 第 5.5 条，要求 H、E 类图纸写明附加要求，并要求反应性场地的图纸标出场地分类、所选基础体系、特殊场地工程和场地排水 [S2]（AS 2870 条文本身付费，未读）。

### 1.7 什么时候是 P 类、必须工程师设计（汇总）
按 Housing Provisions Table 4.2.2 和 QBCC 沉降政策 [S1][S2]：
1. 软黏土、软粉土、松砂；未压实填土或分区开发填土（承载力低于 100 kPa）。
2. 滑坡风险；采矿沉陷；湿陷性土；易受侵蚀的土。
3. 反应性场地加上异常含水条件：近期拆房、移走大树、树木太近、保留或填埋的池塘、水坝、排水沟、水箱。
4. 其他无法分类的场地。
5. 另外，**H、E、M-D 不是 P 类**，但同样超出 Housing Provisions 范围，也要工程师按 AS 2870 设计 [S1]。
6. 填土超出 4.2.4 的深度，或基础落在填土上：要工程师处理（见 1.5）。

## 二、结构图（structural drawings）

### 2.1 读图顺序（builder 实务）
1. **图纸目录和修订号（revision）**：确认是最新的「For Construction」版本，而不是「Preliminary」或「For Approval」；和 certifier 盖章批准的版本一致（批准图纸以外的改动见第三、四节）。
2. **General notes**（通用说明，一般在 S-001 / S-01）。
3. 基础 / 楼板平面 → 剖面和详图 → 框架、tie-down、bracing 平面 → 钢构件和过梁表。
4. 和建筑图、水力图交叉核对：标高、开洞、降板（湿区）、管道穿板位置、门窗洞口尺寸。

### 2.2 General notes 里要找的内容
| 项目 | 常见写法 | 要核对什么 | 依据 |
|---|---|---|---|
| 设计依据 | 设计标准（AS 2870 / AS 3600 / AS 1684 / AS 4100）、风级、场地分类、土壤报告编号 | 场地分类、报告编号和你手上的土壤报告是否一致；风级和建筑图、桁架设计是否一致 | QBCC 要求设计考虑全部场地资料 [S2] |
| 混凝土等级 | N20、N25、N32（28 天强度 MPa），最大骨料、坍落度 | Housing Provisions 的 DTS 楼板最低 N20、20 mm 骨料、100 mm 坍落度 [S1]；工程师可以要求更高，**以图纸为准**；下单时照图纸订 | 4.2.10 [S1] |
| 保护层（cover） | 「cover to reinforcement: 40 external / 30 to membrane / 20 internal」之类 | Housing Provisions 4.2.11 的最小值见 `施工工法要点-builder视角.md`；工程师按 AS 3600 暴露等级可能要求更大（沿海、侵蚀性土） | [S1]；AS 3600 付费 |
| 钢筋符号 | **N12-200**：N 级（AS/NZS 4671 的普通延性 D500N 级）直径 12 mm 钢筋，**中距 200 mm**；**6-N12**：6 根 12 mm 钢筋（Housing Provisions 原文示例）；**R10**：光圆钢筋（4.2.21 原文出现「R10 or N10 ties」） | 直径、间距、根数、位置（top / bottom、each way） | 「6-N12」和「R10」见 [S1]；N、R、L 的强度和延性定义在 AS/NZS 4671（付费，待证实） |
| 钢筋网 | **SL82**：方格网，按 Housing Provisions 的写法规则，**SL62 = 6 mm 钢筋 @200 mm**，所以 SL72、SL82、SL92 分别是 7、8、9 mm 钢筋 @200 mm（按同一规则推得） | 网片规格、搭接（两片网最外两根横筋要互相搭过） | [S1] |
| Trench mesh | **3-L11TM**：3 根 11 mm 纵筋的条形网（原文示例）；L11TM、L12TM 可用 RL1118、RL1218 网片代替；L11TM 可用两层 L8TM 代替 | 根数和直径；代用是否经工程师同意 | 4.2.11 说明、Table 4.2.11a 注 [S1] |
| 搭接长度 | 图纸写 lap length（如「laps 500 min」或按钢筋直径倍数） | Housing Provisions Table 4.2.11b 是 DTS 最小值（≤12 mm 钢筋 500 mm 等，见 `施工工法要点-builder视角.md`）；工程师设计的板以图纸为准 | [S1] |
| 拆模 / 加载时间 | 「formwork stripping times」「do not load slab for X days」 | Housing Provisions 的全国文本没有给住宅楼板拆模时间（原文只在 SA 变体里写了浇筑后 7 天内不得堆料）；以工程师 general notes 和 AS 3610 / AS 3600 为准（付费，待证实） | [S1] |
| 检查要求 | 「engineer to inspect reinforcement prior to pour」 | 独立住宅的基础钢筋、楼板模板和钢筋，如果由 competent person 协助检查，**必须是 registered professional engineer** [S4]；工程师要求的检查要提前预约 | [S4] |
| 场地排水、控制缝、管道柔性接头 | 「site drainage to be maintained」「articulation joints」「flexible joints in stormwater and sewer」 | QBCC：不论这些细节画在工程图还是建筑图上，都要由 RPEQ 认证；builder 要照做 [S2] | [S2] |

### 2.3 楼板平面和剖面
- **平面图**看：楼板外轮廓尺寸；内梁位置和中距（对照 Table 4.2.14 的最大中距）[S1]；降板（湿区、车库、门槛）；内凹角处的斜向加强筋（4.2.11(4)：两条 3-L8TM，或一条 3-L11TM，或 3-N12，长不少于 2 m，45° 放置，中点在内角）[S1]；管道穿板位置；控制缝；墩或桩的位置（P 类和 H/E 类常见）。
- **剖面 / 详图**看：板厚、梁深 D、梁宽、梁底筋和板网规格；企口（rebate）尺寸（砖饰面需要，单层框架外墙不需要，见 4.2.9 说明）[S1]；保护层；防潮膜位置；白蚁防护（板边外露或其他系统）。
- 表格里的梁深 D 是从板面量到梁底的总高（以图示为准，读图时核对图上的标注方法）。

### 2.4 Edge beam（边梁）详图
- 核对：梁宽（企口底部 ≥ 200 mm，或有 R10/N10 @900 箍筋时 ≥ 150 mm，4.2.21）[S1]；梁深是否落到图纸要求的持力层（填土地块常要求梁或墩穿过填土落到天然土，见 4.2.5 Figure 4.2.5 的 Option 2、3）[S1]；底筋根数（外梁宽度超过 300 mm 时，每多 100 mm 加一根，Table 4.2.14 注）[S1]；转角和 T 形交接的钢筋搭接（Table 4.2.11b）[S1]。
- 坡地：台阶式基础按 4.2.7（见原文 Figure）；挖填交界处特别注意承载力不均匀（H1D4(2) 要求承载力均匀）[S1]。

### 2.5 Tie-down 和 bracing 平面
- tie-down 平面标出每个连接点用什么连接件或螺栓（例如屋面到墙顶板、墙底板到楼板的锚栓规格和间距）；bracing 平面标出支撑墙位置、类型（按 AS 1684 的类型编号或厂家体系）和长度。设计方法见 `木框架详解.md` 2.3、2.4 节，本文不重复。
- builder 要核对：支撑墙的位置和长度与图纸一致；水电开孔没有削弱支撑板；锚栓在浇筑前预埋或按图纸后锚；连接件型号与图纸一致，不随意替换（替换要工程师书面同意，见第四节）。
- 轻钢框架按 NASH 标准设计（见 `轻钢框架详解.md`）。

### 2.7 门窗过梁（lintel）表
- 图纸上的过梁表一般列：门窗编号或洞口宽度 → 过梁材料和规格（木 LVL/MGP、钢 UB/PFC、砖墙角钢）→ 支承长度 → 两侧加强墙骨（jamb studs）数量。
- **钢过梁**：Housing Provisions 6.3.5 按屋面类型分表（金属屋面 Tables 6.3.5a–c，瓦屋面 6.3.5d–f），按「屋面荷载宽度」和「楼面荷载宽度」查最大跨度。例如 Table 6.3.5a（金属屋面、木楼面、3 m 高外墙、屋面荷载宽度 1.5 m）：150 UB 14.0 在楼面荷载宽度 0 / 1.8 / 3.6 m 时最大跨度分别为 4.4 / 3.0 / 2.5 m；200 UB 25.4 为 6.8 / 4.7 / 4.0 m；250 UB 31.4 为 7.7 / 5.3 / 4.6 m [S3]。上翼缘在加载点要有侧向约束；过梁要由符合 6.3.6 的钢柱支承；用在砌体中的钢过梁还要满足 H1D5 [S3]。
- **砖饰面上的过梁**（角钢等）：按 Part 5.6.6，见 `混凝土与砌体详解.md` B5。
- **木过梁**：按 AS 1684 跨度表（付费）或桁架/框架厂家设计。
- 检查点：过梁支承长度、两侧墙骨数量、过梁和窗框之间留缝（8.2.2 要求窗顶至少留 10 mm，见 `施工工法要点-builder视角.md`）。

## 三、图纸冲突时怎么办

**常见冲突**：建筑图和结构图标高不一致；结构图的梁位和水力图的管道冲突；建筑图改了门窗洞口尺寸但过梁表没改；结构 general notes 的混凝土等级或保护层和规格书不同；土壤报告分类和结构图写的分类不同。

**处理流程**（行业通行做法，合同条款以所签合同为准）：
1. **停下相关工序**，不要现场自己「选一个」。
2. 发 **RFI（Request for Information）**：写明图号、修订号、位置、冲突内容、附照片或标注截图，提出建议做法，并写清最迟回复日期（避免延误）。发给设计负责人；结构问题要发给结构工程师（RPEQ）。
3. **结构问题以结构工程师的书面答复为准**。QBCC 沉降政策要求 builder 遵守设计的全部内容，并由工程师或 certifier 证明设计已被遵守 [S2]；未经工程师同意的现场改动，会让这份证明拿不到。
4. 如果答复改变了已批准的图纸或规格，要交 certifier 判断是否需要修改批准（amended approval）；涉及合同价格或工期的，按合同走 variation（QBCC 合同要求变更开工前要有业主书面同意，见 CLAUDE.md 第五节「合同」）。
5. 记录：RFI 登记表、工程师答复、修订图纸（标新 revision）、照片。这些也是日后应对缺陷投诉时的证据（QBCC 建议保留各阶段照片和书面沟通）。
- RFI 的格式和流程不是法定要求，这里写的是项目管理惯例（RFI 模板见 `05-工具与模板/` 中的沟通记录模板）。

## 四、什么改动必须找 RPEQ 工程师

### 4.1 法律依据
- **Professional Engineers Act 2002 (Qld) s 115(1)**：不是 practising professional engineer 的人，不得提供「professional engineering services」，**最高罚款 1000 penalty units**；例外是在负责该服务的 practising professional engineer **直接监督**下进行（s 115(2)），直接监督指工程师指导、监督并评估该工作（s 115(5)）。s 115(3) 还规定 RPEQ 只能在自己注册的工程领域内执业 [S5]。
- **定义**（Schedule 2）[S5]：
  - *professional engineering service*：需要或基于把工程原理和数据应用于设计、施工等活动的工程服务；**只按「prescriptive standard」提供的服务不算**。
  - *prescriptive standard*：说明设计或施工程序/标准的文件，应用时**不需要高级的科学计算**；法条原文举的例子就是 **AS 1684（木框架规范）**。
- 所以：**照 AS 1684 跨度表、Housing Provisions 表格（prescriptive）选构件不一定需要 RPEQ；凡是要做工程计算的设计或改设计，都必须由 RPEQ 做或在其直接监督下做。**（这是对法条的理解；具体项目是否属于「专业工程服务」，有疑问时问 RPEQ 或 BPEQ。BPEQ 网站本次返回 403，未能读到其指引原文，待证实。）
- **检查**：独立住宅的基础钢筋、楼板模板和钢筋，certifier 只能依靠 **registered professional engineer** 作为 competent person 协助检查（Business Queensland 页面，依据 Building Regulation）[S4]。
- **QBCC 沉降政策**：设计要由 RPEQ 认证；控制缝、铰接缝、特殊场地工程等细节不论画在哪张图上都要 RPEQ 认证；替代基础体系（AS 2870 和 BCA 以外的）要工程师证明满足 NCC 性能要求；最后要由工程师或 certifier 证明 builder 按设计施工 [S2]。

### 4.2 现场常见改动：要不要找工程师（实务判断）
| 改动 | 是否要 RPEQ | 理由 |
|---|---|---|
| 工程师设计的楼板、梁、墩：改梁深、钢筋、混凝土等级、加开洞或降板 | **要** | 改的是工程设计；QBCC 要求遵守设计全部内容 [S2] |
| 场地分类和报告不符、遇到未记录的填土、软土、地下水 | **要** | 设计依据变了 [S2] |
| 房屋位置或平台标高改变，钻孔可能不在投影内 | **要**（工程师复核） | QBCC 要求钻孔在投影范围内并低于平台标高 [S2] |
| 替换钢梁截面、改钢梁支承或连接、在钢梁上开孔（6.3.8 允许区以外） | **要**（Part 6.3 DTS 表格范围内直接按表选可能不需要，但改工程师已设计的构件要） | [S3][S5] |
| 改 tie-down 连接件型号、改支撑墙位置或长度（图纸由工程师出的） | **要**（由工程师出的图）；完全按 AS 1684 自行设计的，可按 AS 1684 重新核算 | AS 1684 属 prescriptive standard [S5] |
| 拆除或开洞于承重墙（改造） | **要** | 需要计算荷载路径 |
| 挡土墙：需要审批的 | 实务上普遍要求 RPEQ 设计；法规是否一律要求**待证实**（见 `场地工程-土方挡土墙车道雨水围栏.md`） | — |
| 按 Housing Provisions 表格选的 DTS 构件改用表格内另一种合规规格 | 一般不要（按 prescriptive standard 选） | [S5] 定义；仍要 certifier 认可 |
| 桁架布置改变 | 找**桁架厂家**重新设计（厂家按 AS 1720.5 设计，见 `木框架详解.md`） | — |

**原则**：任何影响结构的改动，先发 RFI 拿到 RPEQ 的书面答复和修订图纸，再交 certifier，最后才施工。不要用「以前都这么做」或「供应商说可以」代替工程师答复。

## 五、省钱要点（合法）
1. **土壤报告早做、做全**：买地或设计前就做（QBCC 要求的场地资料一次交给工程师，包括邻地块的树木和填土），避免开挖后改设计 [S2]。
2. **设计时尽量留在 DTS 范围**：A/S/M 类场地加规整平面，可以用 Housing Provisions 表格；H/E/P 类场地无法避免工程设计，但请工程师比较墩基和加深梁两种方案的造价（具体价差待证实）。
3. **浇筑前对图**：浇筑前一天按 general notes 和详图逐项核对（梁深、底筋、板网、保护层、马凳、搭接、内凹角加强筋、管道穿板），并让工程师按要求检查 [S1][S4]。混凝土浇下去后才发现问题，代价最大。
4. **RFI 留痕**：冲突书面问、书面答，既避免返工，也是日后应对 QBCC 沉降投诉时的证据 [S2]。
