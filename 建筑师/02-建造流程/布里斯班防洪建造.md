# 布里斯班防洪建造

## 摘要
本文整理在布里斯班洪水影响地块上新建独立住宅的规则和做法：Brisbane City Council（BCC）的 flood planning area（FPA）分级、最低可居住楼面标高从哪里查、Flood overlay 对审批路径的影响；Building Regulation 2021 s 8 和 QDC MP3.5 的州级框架；QRA 和州政府的抗洪设计指南（湿防、干防、抬高、材料、设备抬高）；以及有官方来源的保险费信息。
对省钱的意义：买地前先查 Flood overlay 和 FloodWise 报告，可以提前知道要不要做 DA、楼面要抬多高、高架还是平板；按指南在可能被淹的楼层用耐水材料、把电气设备放到洪水线以上，返修费用和保险费都可能下降（保险降幅只有个案来源，不能保证）。

适用州：QLD（布里斯班）｜资料核对日期：2026-11-21｜状态：部分待证实（BCC 分级、审批触发、州法框架、QRA 指南已读原文；City Plan Flood overlay code 具体数值、QDC MP3.5 正文未能打开）

## 1. 法律框架：谁定洪水标高

### 1.1 州层面：Building Regulation 2021 s 8 + QDC MP3.5（已核实）
- **地方政府可以指定 flood hazard area**，并在 planning scheme、临时规划文件或决议中声明：defined flood level（DFL）、最大流速、inactive flow or backwater area、**高于 300mm 的 freeboard**、该区域内 Class 1 建筑的 finished floor level [S1]。
  - 原文是 "a freeboard that is more than 300mm"，即 council 若声明 freeboard，须大于 300mm [S1]。
  - DFL 指「合理预计洪水可能上涨到的水位」；finished floor level 指成品楼面最上表面，不含地毯、瓷砖等面层 [S1]。
  - inactive flow or backwater area 指最大流速大致不超过 1.5 m/s 的区域 [S1]。
  - council 须登记每个指定的 flood hazard area 及其指定日期 [S1]。
- **QDC MP3.5 – Construction of buildings in flood hazard areas** 适用于在「已指定 flood hazard area 且已声明 DFL」的区域内进行的建筑工作；目的是让建筑抵抗洪水引起的漂浮、倒塌或明显永久位移，保护住户免受洪水相关的疾病和伤害，并防止回流、保护公用设施 [S2]。
  - Building Regulation 2021 Schedule 列明 MP3.5 于 2013-12-12 发布、2013-12-20 起施行（这是现行版本的日期）[S1]。
  - MP3.5 的具体性能要求和可接受方案（例如楼面相对 DFL 的高度、DFL 以下的材料和电气要求）：**待证实**。原因是 PDF 存放在 housing.qld.gov.au，本轮被网站防护拦截（403），未能读到原文。
- **NCC**：NCC 2022 Volume Two 的 Queensland 附录把洪水相关条款（QLD H1P2、QLD H1D10）留空，改由 Building Act 1975 和 QDC MP3.5 管（见 `01-法规标准/NCC现行版本与住宅要求.md`）[S3]。Business Queensland 页面另指向 ABCB 的 National Flood Standard 作延伸阅读 [S2]。

### 1.2 布里斯班：City Plan 2014 的 Flood overlay（已核实分级；具体数值待证实）
- BCC 有两种洪水地图 [S4][S5]：
  - **City Plan Flood overlay map**：用于建房和开发，按「未来洪水风险条件」建模，是审批依据；
  - **Flood Awareness Map（FAM）**：一般信息用途，按「当前洪水风险条件」建模。FloodWise Property Report 从 FAM 下载。
  - 两者模型情景不同。FAM 每隔几年随新的 LiDAR 测量更新；Overlay map 只在 council 完成新的 flood study 并修改 City Plan 后才变，地图变化时会写信通知受影响业主 [S4][S5]。
- **Flood planning area（FPA）分级**：河流和溪流洪水分 5 级 FPA，另有 1 级 local overland flow FPA；风暴潮另行绘图。FPA 规定只适用于新开发（包括扩建、重建、扩大），不追溯现有建筑 [S5]。

| FPA | BCC 描述 | 对开发的含义（BCC 原文意译） |
|---|---|---|
| FPA1 | 洪水非常可能，和/或可能有很深、很急的水 | 新开发适用最严格的评估要求；一般只适合环境和休闲用途 |
| FPA2 | 洪水可能，可能有深和/或急的水 | 可能有额外开发要求，例如高架（high-set）并采用加强的建筑设计 |
| FPA3 | 洪水可能，可能有深和/或中等至急的水 | 可以建，但可能需要调整，例如房子建在桩柱（stumps）上 |
| FPA4 | 洪水可能，可能有浅和/或慢的水 | 能通过小的建筑调整减轻洪水影响的可以建，例如满足最低楼面高度 |
| FPA5 | 近期无洪水记录，但有潜在可能 | **独立住宅不适用 Flood overlay code 要求**；医院等重要社区设施须满足最低楼面高度 |
| Local overland flow | 水位可能上涨快、流速快，但退得也快 | 住宅适用最低楼面高度标准；其他开发须不加重对邻地的洪水影响 |
来源：[S5]

- **审批路径**：地块在 Flood overlay 内时，新建住宅属于 code assessable，需要向 council 提交 DA；不在任何 code assessable overlay 内、且符合 Dwelling house code 可接受结果的，属于 accepted development，不需要规划许可；但**所有住宅都需要 building approval**（Class 1a）[S6]。
- **最低可居住楼面标高（minimum habitable floor level）**：
  - BCC 的说法：按建筑和开发法规（例如 City Plan 或 QDC）要求的最低可居住楼面标高建造。最低标高**并不等于完全防洪**，只是被视为可接受或可容忍的风险水平；高于最低标高建造能进一步降低风险 [S7]。
  - **从哪里查**：FloodWise Property Report 给出该地址的洪水来源、可能性和洪水位，可作为建筑和开发要求的依据（`01-法规标准/布里斯班规划与地块限制.md` 已核实报告内容）[S7]。
  - City Plan Flood overlay code 中「洪水位 + 多少 freeboard」的具体数值和条款号：**待证实**（cityplan.brisbane.qld.gov.au 本轮不可访问）。设计时以 FloodWise 报告和 certifier/水力工程师的意见为准。
- **复核洪水位**：可书面向 council 申请复核 FloodWise 报告中的洪水位，需提供持证测量师的地面/楼面标高、竣工图、RPEQ 认证的水力评估等；「1974、2011、2022 年没淹过」这类观察证据不被接受 [S4]。

## 2. QRA 与州政府的抗洪设计指南（已核实）

### 2.1 现行和旧版指南
- **现行**：*Design Guidance for Flood Resilient Homes*，由昆州 Department of Housing and Public Works 联合 Office of the Queensland Government Architect、QRA 和 JDA Co 编写，属于 2021–22 年洪灾后由昆州和联邦 50:50 出资的 Resilient Homes Fund 成果；QRA 页面最后更新 2026-06-16，PDF 放在 Get Ready Queensland 网站 [S8]。（Get Ready Queensland 网站本轮不可访问，现行版正文**待证实**。）
- **旧版**：*Flood Resilient Building Guidance for Queensland Homes*（QRA，2019 年 2 月，Version 1.0），是 Brisbane River Catchment Flood Studies 的配套成果，回应 2012 年 Queensland Floods Commission of Inquiry 最终报告。以下 2.2–2.4 节内容引自旧版 [S9]。
- 两份指南都是**非强制性**的，不取代 Building Act 1975、Building Regulation、QDC MP3.5、ABCB Flood Standard 和 NCC 的强制要求 [S9]。

### 2.2 三种策略
| 策略 | 指南的说法 | builder 视角 |
|---|---|---|
| **抬高楼面（elevation）** | 历来是昆州减轻洪水影响的主要方法：把成品楼面抬到 Defined Flood Event（DFE）以上；抬高必须满足 QDC 要求；只对一定水位以下的洪水有效，更大的洪水仍有风险；抬高成本有时过高 [S9] | 新建时比改造便宜得多；FPA2/FPA3 本身就可能要求高架或桩柱 [S5] |
| **湿防（wet-proofing）** | 让洪水能快速进出房屋而不造成重大损坏，退水后清洗、晾干即可回住；要点包括结构锚固、开口或可冲毁墙、耐水材料、保护机械和公用设备；进出水开口要保持内外水位一致，避免静水压力作用于墙体，开口大小须咨询 RPEQ 结构工程师 [S9] | 适合高架房屋的底层（车库、洗衣、储物）和不能完全抬高的部分 |
| **干防（dry-proofing）** | 用永久或临时挡水设施阻止洪水进入；水深较大时水压可能反而加大损坏，**指南认为不适合作为防洪措施** [S9] | 不要把「挡水板」当成主要方案 |
- 指南称抗洪住宅适用于降低 1% AEP（1/100）洪水水位以内的影响；抗洪措施的投入回收期视建筑类型、措施和洪水频率而定（指南不同页分别写 1–12 年和 1–14 年，以原文为准）[S9]。

### 2.3 材料选择（按旧版指南和 BCC 资料）
- **框架**：用耐水框架（指南多处推荐硬木 hardwood 或其他耐水材料）[S9]。
- **保温**：在可能被淹的部位用闭孔保温材料，例如 XPS（挤塑聚苯）、PIR（聚异氰脲酸酯）、酚醛板；指南配图对比了闭孔硬质保温与开孔棉毡 [S9]。
- **墙体**：新建宜用单层（single skin）或复合构造，在可能的洪水线以下避免空腔，便于清洗、减少霉菌 [S9]。内衬用耐水板材；BCC 视频中 builder 对比了普通纸面石膏板（纸面吸水剥落）和 FC（纤维水泥）板（晾干后保持形状）[S7][S9]。
- **地面**：用耐水地面，例如硬木、瓷砖或抛光混凝土替代地毯等吸水材料；踢脚用瓷砖或耐水硬木 [S7][S9]。
- **门**：用实心门或铝框玻璃门替代空心门，减少泡水膨胀变形 [S7][S9]。
- **楼梯和柜体**：洪水线以下的楼梯下方不留空腔，可用螺栓固定、可拆卸的耐水踏板，或实心混凝土楼梯；厨柜可换用耐水材料 [S7][S9]。
- **白蚁**：更换材料时要保持白蚁防护系统完整 [S9]。
- **门槛**：去掉妨碍排水的门槛，做平门槛 [S9]。

### 2.4 电气和设备抬高（已核实）
- 电表箱（electrical meter board）、热水器、空调外机、泳池泵及其电源，都装在**可能的洪水线以上** [S9]。
- 室内插座和数据点抬高到洪水线以上 [S9]。
- 底层和上层分设回路（带断路器），水淹底层时上层仍可用电；BCC 视频建议向持牌电工咨询 [S7][S9]。
- 雨水箱锚固，防止被洪水浮起冲走 [S9]。
- 污水和雨水管装止回阀（non-return valve），先咨询供水商 [S9]。Business Queensland 也提供「在受洪水影响的物业安装污水回流阀」的资料 [S2]。
- builder 开工前应了解：河流、溪流、风暴潮或 overland flow 的可能性、深度和流速；现有楼面与建议最低可居住楼面的高差；电箱、空调、热水器相对 council 洪水位的位置；各房间用途是否合理（州政府 Resilient Homes Fund 给 builder 的资料）[S10]。

## 3. 高架（Queenslander 式）与平板的取舍
| 因素 | 高架（桩柱/high-set，底层湿防） | 平板（slab on ground） |
|---|---|---|
| 洪水规划 | FPA2/FPA3 本身可能要求高架或桩柱 [S5]；抬高是最有效的减险方法之一 [S9] | 只有地面标高已满足最低可居住楼面标高时才可行；FPA4/overland flow 区要满足最低楼面高度 [S5] |
| 洪水后恢复 | 居住层在洪水线以上；底层按湿防做，可冲洗 [S9] | 一旦水位超过楼面，整层受损 |
| 成本 | 指南称抬高房屋的成本一般高于做抗洪改造，但能降低实际进水的可能性 [S9]；新建高架与平板的具体造价差：**待证实**（未找到官方数据） | 一般基础成本较低（具体数据待证实） |
| 能效 | NCC 下架空楼板住宅的热工要求为 6 星（见 `01-法规标准/NCC现行版本与住宅要求.md`）[S3] | 7 星 |
| 无障碍 | 高架会增加楼梯；Livable Housing 要求见 `01-法规标准/NCC现行版本与住宅要求.md` | 容易做无台阶入口 |
- 建议：先拿 FloodWise 报告确定最低可居住楼面标高，再比较「填土 + 平板」和「高架」的总成本。填土要注意 overland flow 不得加重对邻地的影响，City Plan 对 filling and excavation 另有规定（Dwelling house code 相关条款待证实）。

## 4. 洪水对保险费的影响（只写有来源的）
- **BCC**：council 无权决定保险公司如何计算洪水保费；洪水风险只是保费因素之一，其他因素还有建筑类型、房龄、安保、对气旋、山火、风暴、地震等的脆弱性；Insurance Council of Australia 认为通胀、建造成本上升、供应链短缺和全球再保险成本是保费上涨的主要原因；保险公司可使用 National Flood Information Database（NFID）等多种数据源，也可能用自己的洪水地图 [S4]。City Plan 不用于保险或估值目的 [S4]。
- **可以做的**：把 council 的洪水资料给保险公司，并要求其考虑已做的抗洪工程 [S4]；QRA 建议向保险公司询问指南中的改造能否降低保费 [S11]。
- **个案（不能推广）**：2011 年 Graceville 一处房屋被淹至地面以上 5 m，业主把房子抬高约 3 m 使楼面高于 1% AEP 洪水位，底层采用抹灰混凝土砌块墙、抛光混凝土地面、可拆卸橱柜。Suncorp 在 2012–2017 年的保费为每年 $5,253.33，2018 年改造后降为每年 $3,133.60，降幅 40% [S9][S11]。
- 全市平均洪水保费水平、在 overlay 内外的保费差：**待证实**（未找到官方数据）。

## 5. 资助项目现状
- **Resilient Homes Fund**（2021–22 洪灾，39 个地方政府区域）：2023-07-30 停止新登记；2025-12-01 资助申请截止；合同完工日期不得晚于 2027-03-31 [S12]。**新建住宅不能再申请**。
- **BCC Flood Resilient Homes Program**：2018–2024 年试点，为合格房屋提供抗洪评估和资助；后续为 Flood Resilient Suburbs，已转入 council 的洪水政策工作 [S7]。目前是否还有新的资助：**待证实**。

## 6. builder 操作清单
1. 买地前：在 City Plan online 查 Flood overlay，下载 FloodWise Property Report，记录 FPA 等级、各 AEP 洪水位、最低可居住楼面标高 [S4][S5][S7]。
2. 判断审批路径：在 Flood overlay 内 → code assessable，需要 DA；所有住宅都需要 building approval [S6]。
3. 请测量师做标高测量；必要时请 RPEQ 做水力评估 [S4]。
4. 设计：楼面 ≥ 最低可居住楼面标高（考虑再抬高）；洪水线以下用湿防构造和耐水材料；电表箱、热水器、空调外机、泳池泵抬高；上下层分设回路；污水管装止回阀 [S9]。
5. 结构：湿防开口、锚固和抗浮由 RPEQ 结构工程师设计 [S9]；同时满足 QDC MP3.5（正文待证实）[S2]。
6. 交付：把 FloodWise 报告、竣工标高、抗洪措施清单交给业主，用于向保险公司申报 [S4]。
