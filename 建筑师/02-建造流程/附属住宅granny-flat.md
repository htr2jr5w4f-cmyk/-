# 附属住宅（granny flat / secondary dwelling）

## 摘要
本文整理在布里斯班建附属住宅（secondary dwelling，俗称 granny flat）的规则：Planning Regulation 2017 的定义及 2022 年修订（不再要求住户与主屋有关系，因此可以出租给外人）；Brisbane City Plan 2014 现行的面积和位置要求，以及 Major amendment package L 拟议的新要求；审批路径、infrastructure charges、分开计量水电；owner builder 不能建相连附属住宅的限制。
对省钱的意义：附属住宅符合 Dwelling house code 时属于 dwelling house 的一部分，可能不需要规划许可，只要 building approval；分清相连和独立两种形式，可以判断能否 owner-build，提前算清能否出租、计量和收费问题。

适用州：QLD（布里斯班）｜资料核对日期：2026-11-21｜状态：部分待证实（州法定义、2022 修订、owner builder 限制、审批触发已读原文；City Plan 现行条款只通过修订文件间接核对；infrastructure charges 和分开计量待证实）

---

## 1. 州法定义与 2022 年修订（已核实）
- **现行定义**（Planning Regulation 2017 Schedule 24）：secondary dwelling 指同一地块上与另一住宅配合使用、但从属于它的住宅，**不论**它是否（a）与另一住宅相连，或（b）由与另一住宅住户有关系或有联系的人居住 [S1]。
- **dwelling house** 指：（a）1 个住宅及其附属外屋；或（b）2 个住宅（其中 1 个是 secondary dwelling）及其附属外屋 [S1]。所以合规的 granny flat 在规划上仍属「独立住宅」用途，不是 dual occupancy。
- **dual occupancy** 定义明确不包括涉及 secondary dwelling 的居住用途 [S1]。
- **dwelling** 指能作为独立居所使用、且有厨房设施、浴缸或淋浴、厕所、洗手盆和洗衣设施的建筑或其部分 [S1]。
- **2022 年修订**：*Planning (Secondary Dwellings) Amendment Regulation 2022*（2022 SL No. 133），2022-09-23 由 Governor in Council 制定并在昆州立法网站公告 [S2]。主要改动 [S2]：
  - 删去原 household 和 secondary dwelling 定义，重新定义 household 为「1 人或多人共同居住在一个住宅中」，并加入上面的 secondary dwelling 新定义；
  - dwelling house 定义删去「for a single household」，(b) 项改写为现行文字；
  - dual occupancy 删去「for 2 households」，multiple dwelling 删去「for separate households」。
  - 该修订规例没有单独的生效条款；按一般规则自公告日生效（推断，未见原文明文）。
- **对出租的影响**：新定义写明「不论居住者是否与主屋住户有关系」，所以在州法定义层面，附属住宅可以出租给与主屋无关的人。修订前的旧定义原文本轮未打开核对（旧定义限制居住者为主屋家庭成员的说法：**待证实**）。
- 出租时还要遵守租赁法（Residential Tenancies and Rooming Accommodation Act 2008）等其他法律，本文不展开（**待确认**是否另写）。

## 2. 布里斯班 City Plan 2014 的要求
### 2.1 现行条款（据 package L 修订文件中的现行文字，City Plan 原文未能直接打开）
- BCC「New house」页面：City Plan 下的 dwelling house 包括「2 个住宅，其中 1 个是 secondary dwelling」；dual occupancy、multiple dwelling 等不属于 house [S3]。
- Dwelling house code 中关于 secondary dwelling 的现行可接受结果（AO1.1、AO1.2），在 Major amendment package L 修订文件中作为被修改的原文出现 [S4]：
  - 不超过 1 个主住宅和 1 个 secondary dwelling 或 auxiliary residence，各由 1 个 household 居住；
  - secondary dwelling **总建筑面积（GFA）最大 80 m²**；
  - **位于主屋 20 m 以内**。
  - 对应的性能结果要求：与主屋配合使用并从属于它、规模小于主屋、外观像主屋的附属建筑 [S4]。
- 说明：PDF 转文字丢失了删除线，无法完全区分哪些是现行原文、哪些是拟删文字；上述 80 m² / 20 m 也与其他资料一致，但仍应在 City Plan online（现行 v37.00）核对 Dwelling house code 原文（**待证实**条款号和现行文字）。

### 2.2 Major amendment package L（拟议，未生效）
- 内容涉及小地块住宅、secondary dwelling / granny flat、rooming accommodation 等 [S5]。BCC 列出的拟议方向 [S5]：
  - secondary dwelling 面积按地块面积设上限；
  - 总 site cover 50%；
  - secondary dwelling 为 1 层；若与 2 层主屋相连，可为 2 层；
  - 调整侧面和后面退让，包括贴边界墙。
- 修订文件中的拟议条文（未生效）[S4]：
  - 总室内面积最大 80 m² 或地块面积的 10%，取较小值（「总室内面积」按外墙外皮计算，包括所有楼层的可居住和非居住房间）；
  - 最多 2 间卧室、1 个厨房、1 个室内起居空间；
  - 总 site cover 最大 50%（主屋、附属住宅、外屋合计）；
  - 独立设置或与 1 层主屋相连时，最大 1 层。
- **进度**：公众咨询 2025-11-03 至 2025-12-01；council 正在审阅意见，并考虑包括 Queensland Housing Code 在内的法规变化；预计 2027 年年中采纳并生效 [S5]。
- builder 建议：在 2027 年前申请的项目，按申请当时的 City Plan 版本评估；设计时可以同时对照拟议条文，避免将来扩建受限。

### 2.3 Queensland Housing Code
- QHC（新 QDC MP1.1/MP1.2）于 2026-08-14 发布；布里斯班截至 2026-11 未见采用（详见 `01-法规标准/布里斯班规划与地块限制.md`）。QHC 对 secondary dwelling 的具体规定：**待证实**。

## 3. 审批路径
1. **规划**：若地块不在 code assessable overlay（如 Flood、Bushfire、Heritage、Traditional building character、Landslide 等 13 种）内，且符合 Dwelling house code（小地块用 small lot code）的可接受结果，则属于 accepted development，不需要 council 书面批准，业主自行对照 code 即可；否则需要向 council 提交 DA [S3]。
   - 不符合某项可接受结果（例如超过 80 m²）时，一般要走 code assessment（据第三方资料，**待证实**）。
   - package L 修订文件说明拟澄清「prescribed accepted development 不适用于 secondary dwelling」，现行适用情况**待证实** [S4]。
2. **建筑**：附属住宅作为可居住住宅，需要 building certifier 发 building approval（所有 house 都是 Class 1a，都需要 building approval）[S3]。可居住的附属建筑不能归为 Class 10（见 `01-法规标准/NCC现行版本与住宅要求.md`）。
3. **退让放宽**：如需放宽边界退让等，certifier 向 council 申请 referral agency response [S3]。
4. **管道**：管道和排水工作按昆州管道法规另行审批（见 `02-建造流程/审批流程与法定检查阶段.md`）。
5. **相连附属住宅的防火分隔**：两个 Class 1a 住宅相连时，NCC Volume Two 对分隔墙有防火和隔声要求，具体条款**待证实**（本轮未核对 NCC 原文）。

## 4. Infrastructure charges（待证实）
- Brisbane Infrastructure Charges Resolution (No. 15) 2026（2026-07-01 起）对 dwelling house 按卧室数收费：1–2 卧 $13,423.83，3 卧以上 $18,793.33（每个住宅）[S6][S7]。
- 该决议中**未找到专门针对 secondary dwelling 的条目** [S6]。附属住宅是否另收一份、按几卧计、能否用地块原有需求抵扣，本轮未能确认：**待证实**，应向 council 的 infrastructure charges 部门书面询问。
- Urban Utilities 是否对附属住宅另收水和污水基础设施费：**待证实**（Urban Utilities 网站本轮无法读取）。

## 5. 能否分开计量水电（待证实）
- **电**：Business Queensland 的「Electricity sub-metering」规定只要求新建 Class 2（多户住宅）每个单元、Class 5（办公）每层装电力分表，依据 QDC MP4.1 [S8]。附属住宅属于 Class 1a，**该强制分表规定不适用**；是否可以另设独立电表（独立 NMI）由 Energex 和电力零售商决定：**待证实**（Energex 网站本轮被拦截）。
- **水**：Urban Utilities 是否允许为附属住宅装独立水表或分表、如何收费：**待证实**。
- 出租时水电费如何向租客收取，受租赁法约束：**待确认**。

## 6. Owner builder 限制（已核实）
- QBCC Act s 43D：owner-builder work 不包括「building work for a multiple dwelling」；multiple dwelling 定义为「由 2 个或以上居住单元组成的建筑」[S9]。
- QBCC「About owner-building」页面明确：owner builder **不能**建造或翻修 multiple dwellings，例子包括 duplex、**相连的 granny flat（attached granny flats）**、寄宿屋、单元楼或其中的单个单元 [S10]。
- **独立（detached）附属住宅**是单独一栋建筑，不属于「一栋建筑内有 2 个以上居住单元」，按法律定义推断可以 owner-build；但 QBCC 页面未明文说明，**待确认**（建议向 QBCC 书面确认）。
- owner builder 仍须遵守其他规则：工程价值超过 $11,000 要申请 permit；不能自做管道、排水、燃气等须执照的工作；没有 Home Warranty（见 `01-法规标准/QBCC执照与业主自建.md`）。
- 由持牌 builder 建造时：附属住宅与主屋同一合同，属于 Home Warranty 的可保工作；同时签约建 3 个以上居住单元的没有保险（QBCC Act s68(2)），2 个住宅（主屋 + 附属住宅）不受此限（见 `01-法规标准/QBCC家庭保修保险.md`）。

## 7. builder 操作清单
1. 查 overlay 和地块面积，判断 accepted 还是 code assessable [S3]。
2. 按现行 City Plan 控制 GFA ≤ 80 m²、距主屋 ≤ 20 m（核对原文），并参考 package L 拟议条文 [S4]。
3. 决定相连还是独立：相连 → 不能 owner-build，需处理分户防火；独立 → 注意退让和 site cover [S10]。
4. 向 council 书面确认 infrastructure charges；向 Energex 和 Urban Utilities 确认分开计量的条件和费用。
5. 出租前确认租赁法义务和保险。
